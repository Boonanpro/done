# チャットセッション機能 要件仕様書

## 概要

ユーザーがダン（AI秘書）との会話を複数のセッションに分けて管理できる機能。

## 現状の課題

- ユーザーごとに1つのダンルームしかなく、会話履歴が混在する
- 「新しい会話」ボタンが機能していない
- サイドバーにチャット履歴が表示されない

## 設計方針

既存の`chat_rooms`テーブルを活用し、ユーザーごとに複数のダンルームを作成可能にする。

### データモデル

```
users
  └── chat_rooms (type='dan', 複数可)
        └── chat_messages
```

- `chat_rooms.type = 'dan'` のルームをセッションとして扱う
- `chat_rooms.name` にセッションタイトル（最初のメッセージから自動生成）
- `users.dan_room_id` は現在アクティブなセッションを指す

## API一覧

### 1. セッション一覧取得
```
GET /api/v1/chat/dan/sessions
```

**レスポンス:**
```json
{
  "sessions": [
    {
      "id": "uuid",
      "title": "明日の天気について",
      "last_message": "お住まいの地域を教えて...",
      "last_message_at": "2026-01-03T09:00:00Z",
      "message_count": 5,
      "created_at": "2026-01-03T08:00:00Z"
    }
  ],
  "current_session_id": "uuid"
}
```

### 2. 新規セッション作成
```
POST /api/v1/chat/dan/sessions
```

**レスポンス:**
```json
{
  "id": "uuid",
  "title": "新しい会話",
  "created_at": "2026-01-03T10:00:00Z"
}
```

- 新規ルームを作成し、`users.dan_room_id`を更新
- 古いセッションは保持される

### 3. セッション切り替え
```
POST /api/v1/chat/dan/sessions/{session_id}/activate
```

**レスポンス:**
```json
{
  "success": true,
  "session_id": "uuid"
}
```

- `users.dan_room_id`を指定セッションに更新

### 4. セッション削除
```
DELETE /api/v1/chat/dan/sessions/{session_id}
```

- セッションと関連メッセージを削除
- 現在アクティブなセッションは削除不可

### 5. セッションタイトル更新
```
PATCH /api/v1/chat/dan/sessions/{session_id}
```

**リクエスト:**
```json
{
  "title": "新しいタイトル"
}
```

## フロントエンド変更

### サイドバー（sidebar.tsx）

1. **セッション一覧表示**
   - ナビゲーション下部にセッション一覧を表示
   - 各セッションにタイトル、最終メッセージ日時を表示
   - 現在のセッションをハイライト

2. **新しい会話ボタン**
   - クリックで新規セッション作成API呼び出し
   - 作成後、チャット画面をリフレッシュ

3. **セッション切り替え**
   - セッションをクリックで切り替え
   - チャット画面のメッセージを更新

## テストケース

### API テスト
1. セッション一覧取得（認証済み）
2. セッション一覧取得（未認証 → 401）
3. 新規セッション作成
4. セッション切り替え
5. 存在しないセッション切り替え → 404
6. 他ユーザーのセッション切り替え → 403

### UI テスト
1. サイドバーにセッション一覧が表示される
2. 「新しい会話」クリックで新規セッション作成
3. セッションクリックで切り替え、メッセージ更新
4. 現在のセッションがハイライト表示

## 注意事項

- 既存の `get_or_create_dan_room` は現在のセッション取得に使用
- セッション作成時に自動でタイトル生成（最初のメッセージから）
- セッション数の上限は設けない（将来検討）
