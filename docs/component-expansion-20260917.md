# 部品の量と多様性を増やす目標

開始時：編集可能な演出6種類、既存参考21点。

1. 新たに48点以上、8系統以上。色違いを数合わせに使わない。
2. 実際に再生できる見本・固定リビジョンの編集用ソース・出典・再利用条件をセットで保存する。
3. 全点の再生を確認。代表例は画像で目視し、壊れたものを検索対象にしない。
4. 新しい表現が必要な12要求で10以上適切に選択。文字起こし済み要求から実物表示までp90が5秒以内。
5. ダンが元ソースと調整項目を読める。既存6部品へ無理に作り直さない。

これは素材の追加と選択・表示の検証。制作全体の完成品質や音声会話の合格とは区別する。

## 今回言えること／まだ言えないこと

以前の少数部品では示せなかった具体的な表現を、約1秒台で取り出し、その元コードまで渡せるようになった。今回の12要求では、参考が揃っていれば選択にAstraを使わずJevだけで処理できた。

70点から数千・数万点への速度と精度、複数部品を組んだ長編の品質、声だけでの通し制作は別途検証が必要。共通部品の少なさは減らしたが、高品質な独自作品を常に出せるという結論ではない。
