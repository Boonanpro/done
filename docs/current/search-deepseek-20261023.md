# 検索を DeepSeek に替え、話し終わる前に検索を始める（2026-10-23）

付箋 search-deepseek。測った材料と生の結果は `/Users/mikihonda/dan-workspace/search-deepseek-bench/`（questions.txt・results*.json・utter*.json・judge_results*.json・call/run_*.json）。

## 1. 検索の中身: 日本語20問を5通りで比べた

| やり方 | 正しさ（採点できた18問） | 秒数 中央値 / 最大 |
|---|---|---|
| 今の OpenAI 検索（gpt-5.6-terra＋検索） | 17.5 | 5.0 / 18.4 |
| DeepSeek 検索＋まとめ（要約だけ読む） | 15.5 | 1.9 / 2.6 |
| DeepSeek 検索（本文つき）＋まとめ | 15.5 | 2.2 / 3.0 |
| DeepSeek 検索＋上位2件の本文取り（Fetch）＋まとめ | 16 | 11.6 / 15.1 |
| **DeepSeek 検索語2つ（日付を具体的に）＋本文つき検索＋まとめ（採用）** | **17.5** | **3.1 / 3.6** |

採点は ○=1、△=0.5、✕=0。「今日の大阪の最高気温」（予報元で22〜25℃に割れた）と「iPhone 17 Pro の価格」（Apple のページが18 Pro に替わり確かめられない）は採点から外した。

DeepSeek が落とした所:
- 「明日の尼崎の天気」: 要約だけだと別の日の予報（28〜31℃）が混ざった。検索語を「10月24日 尼崎 天気」にすると正しい予報（21〜24℃・雨）になった。
- 「今週末の尼崎のイベント」: 要約だけだと「見つからなかった」。日付入りの検索語で、つかしんのフリマや立花のハロウィン音楽祭などが出た。
- 「Next.js の最新版」: 4通りとも 16.4.1（npm の最新は 16.4.2）。数日前に出た版はまだ載っていないことがある。OpenAI は 16.4.2 を答えた。
- 本文取り（Fetch）は1ページ数秒かかり、合計6〜15秒で OpenAI より遅いので採らなかった。

費用の目安（1回）: 採用した形は DeepSeek 検索2回（$0.0015）＋ deepseek-flash 約8,800トークン（$0.0013〜0.0027）で約0.5〜0.6円。OpenAI 検索は入力約1.1万トークン＋検索手数料で、通話と同じ OpenAI の残高から出ていた。

## 2. 話の途中で「調べものか」を見分ける係

途中で切った日本語の話30個（調べもの／ダンの持つ情報を読む／作業／相談・雑談／言い始め）を2組。2組目は1組目を見た後に書き直していない別の言い回し。

| 係 | 1組目 | 2組目 | 調べものの当たり | 調べものでない話を調べものと取った | 1回の速さ（中央値） | 検索語を作れるか | 費用 |
|---|---|---|---|---|---|---|---|
| **Jev** | 30/30 | 28/30 | 20/20 | 0 | 0.15秒 | 作れない（選ぶだけ） | 約0.004円 |
| OpenAI Decisions（gpt-6-luna） | 28/30 | 26/30 | 20/20 | 1（アメックスの引き落とし額） | 0.20秒 | 作れない（選ぶだけ） | 約0.005円・OpenAI の残高から |
| deepseek-flash | 26/30 | 27/30 | 19/20 | 0 | 0.9秒 | 作れる | 約0.006円 |
| 言葉の決まり（正規表現） | 29/30 | 13/30 | 11/20 | 1 | 0秒 | 作れない | 0 |

- 言葉の決まりは1組目を見ながら書いたので1組目だけ高い。知らない言い回しには効かない。
- Decisions の通話連携（transcript triggers）は、OpenAI の説明に「Transcript triggers run independently of delegation」とあるだけで、今の Responses 方式の通話と一緒に使えるとは書かれていない。選択肢を選ぶだけで検索語も作れない。ダンのサーバーは通話の途中の文字起こし（session.input_transcript.delta）をもう受け取っているので、通話の設定を変えずにサーバー側で見分けられる。そこで Decisions の通話連携は使わなかった。
- 採用: Jev。検索語は作らず、聞こえた言葉そのものを質問として検索に渡す（検索の側で検索語を2つ作る）。Jev が使えない時は deepseek-flash が代わりに見分ける。

**Mac の Jev は止まっている。** Jev の予算ファイル（`~/.dan/jev-browser-budget.json`）が Mac に無いので、Jev の判定はすべて「使えない」で返る（保存情報の読み出し・ブラウザの候補選びも同じ）。予算ファイルの鍵が Windows 専用（msvcrt）だったので、Mac でも動くようにした（`jev_browser_budget._lock`）。予算ファイルを置けば Jev が使える。下の通話の試験は Jev が使えないまま行ったので、見分けたのは deepseek-flash（約0.8秒）。

## 3. 試験用の通話

本物の gpt-live-1 の通話に、Mac の読み上げ（Kyoko）で本人の声の代わりに5問を話させた（`scripts/check_voice_prefetch_call.py`、テスト用アカウント・部屋なし・本番の受け口を通らない）。秒数は、本人の声が終わってから、ダンが答えを話し始めるまで。

| 質問 | 変更前（OpenAI 検索） | DeepSeek 検索 | DeepSeek＋話し終わる前に検索 |
|---|---|---|---|
| 明日の尼崎の天気って分かる？ | 8.4 | 8.6 | 6.5 |
| 尼崎駅の近くでおいしいラーメン屋さんを教えて | 20.2 | 11.8 | 7.9 |
| 今のドル円っていくら？ | 9.5 | 7.3 | 6.8 |
| USJの1デイ・スタジオ・パスっていくらだっけ？ | 9.3 | 7.6 | 4.3 |
| Next.jsの最新バージョンって何？ | 8.1 | 7.6 | 5.9 |
| 中央値 | 9.3 | 7.6 | 6.5 |

- 声は3通りとも普段どおり答えた（「調べるね」→答え）。誤りは DeepSeek の Next.js が 16.4.1 だった1件（上の1と同じ）。
- 裏のモデルが web_search を頼むのは、本人が話し終えて1.6〜6秒後。その間に先回りの検索がほぼ終わっている。5問とも先回りの結果が使われた（最後の版で5/5。直す前の版では、文字起こしがダンの「調べるね」の後ろに遅れて届いて別の発言に見えた、「いく｜ら」で区切れた、裏のモデルが「ドル円」を「USD JPY」と言い換えた、の3つで外れていた）。
- 先回りの検索は1問に1〜3回（言葉が伸びると検索し直す）。外れても1回約0.6円。

## 4. 変えたもの

- `app/services/web_search.py`: 検索の本体。DeepSeek（検索語2つ→本文つき検索→deepseek-flash でまとめ）を既定にし、DeepSeek が失敗・空の時は OpenAI に戻る。`.env` の `DAN_WEB_SEARCH_ENGINE=openai` で OpenAI に戻せる（再起動不要）。
- `app/services/voice_responses.py`: 通話の裏側の検索の写しを消し、上の本体を使う。
- `app/services/api_job_worker.py`: 裏で作業するモデルに `search_results`（検索の一覧）と `fetch_page`（ログイン不要のページの本文）を直接渡す。
- `app/services/voice_prefetch.py`・`voice_sideband.py`: 話し終わる前の検索。`DAN_VOICE_PREFETCH=0` で止まる。記録は回数と秒数だけ（言葉は残さない）。
- `app/services/jev_browser_budget.py`: 予算ファイルの鍵を Mac でも動くようにした。
