# 全体像から始める参考相談の修正

## 変更

- 全体像の参考と細部の参考を区別するJev判断を追加。候補の評価を、作品の全仕様への一致から、相談中の方向性を判断するための有用性へ変更。
- 主題が似た工作動画等に寄りすぎないよう、作品の形式・見せ方を先に評価する。
- 舞台のラベルを「生活環境」に限定。撮影の豪華さや参考作品名で自宅という設定が変わらないようにした。映像表現も主な見た目として扱い、写実的なCGを含むだけで別の表現に分類しない。
- LIVE1の指示を更新。ヒアリングと参考提示を並行し、全体から細部へ進む。具体化前に必要な目的・公開先・尺・素材の不足を確認し、既知の回答は聞き直さない。参考選びを他の相談に進むための必須関門にしない。
- 長編映画予告編の不足を補うため、配給元等のURL13本を追加。うち3本を動画分析し、検索情報へ反映。検索時の関連ジャンルを確率とは別に持てるようにした。
- Coreの管理APIは、直近の音声イベントがある場合、停止・再起動を409で延期する。終了イベントで解除し、クライアント消失時は90秒で失効。forceでも通話を無視しない。OSからの直接終了を防ぐものではない。

## 検証

- 元のユーザー会話、方向の修正、アプリ広告、料理解説の4ケースを実APIで確認。修正過程では、工作動画を選ぶ・設定を豪華な環境へ変える問題が再現した。最終のテキスト再生試験では全4ケースで参考を選び、自宅設定を維持。
- 実音声の3発話試験 `scratch/overall-discovery-voice-final` では、初回から参考を表示し、トップガンという変更後も普通の自宅を保持。最後は既知の公開先を聞き直さず、尺・素材について質問。実画面も確認。
- 発話終了からカード表示まで初回10,143ms、次の提示2,776ms。検索部分は2,671ms / 1,553ms。初回の待ち時間は依然改善余地があり、全体1秒を達成したとは言わない。
- この録画では比較の言い方が「実写／複数の表現」に偏ったため、その後さらに主な見た目のラベルとLIVE1の比較指示を修正した。この最後の調整を含む音声試験は成功確認できていない。
- 更新後の本番試験 `scratch/overall-discovery-deployed` はJevの503・ReadTimeoutにより速さの試験として失敗。小さな独立リクエストも503を返した。その後CLIへの委譲が1回発生し、最終的にはカードが出たが発話終了から122,539msかかった。未入力の英語文字起こしも1件あり、この試験を自然な会話の合格とは扱わない。外部障害時の委譲・待機の扱いも残課題。
- 本番の試験通話中に再起動APIを呼び、409とPID維持を確認。Core・sandbox更新済み（sandbox PID32356）。
- 関連Pythonテスト32件合格。
