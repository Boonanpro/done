# マイルストーン②：相談から最初の実物へ

## 目標と区切り

ユーザーは目的・好み・良し悪しを伝える。Danが制作方法と次に判断する実物を提案・実行する。

1. ヒアリングと参考選定：過去の本人テストで改善を確認済み。今回の対象外。
2. 最初の実物：今回の対象。見た目・動き・空間・話の流れの異なる相談4件で、ユーザーが道具名を言わず適切な案に進む。画像と短い見本は実表示を確認する。通しコンテは今回、依頼内容と範囲を確認し全編は制作しない。
3. 実物を見た反応から狙いへ近づける：次の確認対象。今回の初回提示だけで達成扱いにしない。
4. 一本を仕上げる：題材を変えた安定性と品質は別の通し試験。

## 変更

- editor_first_artifact.GUIDANCEを相談担当と制作担当へ共通で渡す。ジャンルによる固定ルートは設けない。
- 会話側の「画像でなければ通しコンテ」という偏りを除去。LIVE 1は提案・委譲、具体的な手順判断はバックエンド。
- show_consultation_visualを、静的説明だけでなく短い動く見本・空間配置の確認にも使えると明示。不要な別制作担当の起動や動画レンダリングを省ける。
- GenHQ調査から得た、見た目と動作のガイドを分離する考え方、参考の特徴を別内容へ応用する考え方を接続。特定の画調や3Dを必須にしない。
- 手順の説明だけで終わらず、具体案への了承後は実行。既存の制作許可を引き継ぎ、短い見本を全編制作に拡張しない。

## 実モデルと画面の確認

`scripts/check_first_artifact_decisions.py`：GPT-6 Astra、実運用の相談指示と道具。完成した8項目をfixtureとして渡す。初回発言は好み・不確かな点のみで、期待する成果形式はモデルへ渡さない。次の発言はDanの提案への了承。

| 翼付き自動車の映画、顔や作業場が想像できない | 一枚の完成イメージを提案、了承後look_frame | 実制作・表示まで |
| メモアプリ、情報が集まる動きが気持ちよいか不明 | 4秒の文字・図形composition | 実エディター表示、24.16秒で最初の応答処理終了 |
| 倉庫研修、人と台車・棚の位置関係 | 8秒の白黒Three.js scene | 実エディター表示、30.4秒で最初の応答処理終了 |
| 電気普及の解説、全体の話が退屈でないか | 3分の仮音声付き通しコンテを提案 | 7.56秒で提案。了承後vconteに委譲する内容まで。全編制作は未実行 |

上記の秒数は単発観測でP50/P95ではない。初回のツール保存だけの試験は画面への表示を確認できないため、動き・空間の2件は実ブラウザで再試験した。テスト専用の部屋・作品で実行。ユーザー作品は変更していない。

`scripts/check_first_artifact_handoff.py`：モデルが選んだ画像依頼を、実ブラウザのrun_editor_taskから実CLI制作担当へ渡した。GPT Image 2.5 Flareで1枚生成。画像生成約19秒、ブラウザ開始から表示79.15秒。画像の保存・表示、担当の完了、タイムラインへクリップを追加しないことを確認。生成物の顔・手元・車・作業場が読めることを画面で確認した。全翼・車体全体は画角に入っていないため、それが必要なら構図の修正が必要。ユーザーによる見た目の採用は未確認。

結果：`scratch/first-artifact-milestone/`。API画像の過去の実測速度だけを、この引き渡し全体の速度として報告しない。

`scripts/check_first_artifact_live.py`：実際のLIVE 1 WebRTC接続へ、テキストで「色とかは良いけど、動いた時に気持ち良いかはまだ分からんな」と入力。get_consultation_state→show_consultation_visualを自ら選び、6秒の動く見本が18.97秒で画面に現れた。道具や画像生成を要求する発言は与えていない。エラー0。実画面を確認し、セッションを閉じた。これはLiveの委譲と実表示の検証で、マイク入力・聞き取り・会話音声の自然さの試験ではない。

反映：稼働中の通話と制作ジョブがないことを確認してsandbox 8000のみ再起動。正常応答確認。Core 9000は再起動していない。相談・Liveセッション構築・制作担当への共通指示の読み込みを含む16テスト合格。

判定：②の基本動作は上記の範囲で確認。全ジャンルの最適判断、すべての制作経路の完成品質、③の好みへの収束までを合格扱いにしない。

## 残る検証

- マイクで話し、声の返答を聞く一連の自然さは、このテキスト入力による判断試験とは別。
- コンテの品質、長編への展開、好みへの収束は②だけでは証明しない。
- 初回の実物が出るまで24〜79秒。必要な生成時間と、引き渡し・設計時間を分けて短縮を検討する。今回は秒数の達成目標を後付けして合格にしない。
