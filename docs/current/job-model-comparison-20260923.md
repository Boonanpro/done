# 作業モデルの比較（2026-09-23）

音声から起こす作業（API ワーカー `app/services/api_job_worker.py`）で、同じ3作業・同じ道具・同じブラウザを、モデルだけ替えて走らせた。
手順の記憶（flow）は外し、モデルの実力だけを見た。各1回。費用は各社の公表単価（キャッシュ込み）で計算。

| モデル | 題名を読む | 気象庁で天気 | EX検索（ログイン→検索→3便） | 3作業の費用 |
|---|---|---|---|---|
| deepseek-flash | ✅ 6秒・1手・$0.003 | ✅ 9秒・2手・$0.001 | ✅ 76秒・15手・$0.015 | $0.019 |
| deepseek-v4-pro | ✅ 10秒・1手・$0.004 | ✅ 15秒・3手・$0.006 | ✅ 146秒・17手・$0.048 | $0.059 |
| claude-opus-5-5 | ✅ 14秒・2手・$0.107 | ✅ 10秒・1手・$0.023 | ✅ 401秒・21手・$0.635（押し直し修正の前・試験者の割り込み1回） | $0.77 |
| gpt-6-astra | ✅ 38秒・5手・$0.246 | ✅ 12秒・Web検索のみ・$0.032 | ⚠️ 53秒・7手・$0.236（1便目の到着を 12:25→12:55 と誤読） | $0.51 |
| gpt-6-sol | ✅ 102秒・4手・$0.045 | ✅ 26秒・3手・$0.049 | ❌ ログイン画面へ進めず（押し直し修正の前） | $0.31 |
| gpt-6-luna | ✅ 8秒・1手・$0.002 | ❌ 今日の予報を「明日」と回答 | ❌ ログイン画面へ進めず（押し直し修正の前） | $0.009 |

決定: 音声起点の作業の既定を `deepseek-flash` に（`.env` の `DAN_API_JOB_MODEL`、ワーカーが作業ごとに読む）。

比較中に見つけて直した欠陥（全作業に効く）:
- メールの確認コード抽出が、本文の宛先アドレス（0aw325171@…）の6桁を拾っていた → 英字・@ に接する数字は除外
- SMS コードをサービス名で絞ると、サービス名を判定できなかった SMS（「【スマートEX】」）を落としていた → 空欄も候補に、「スマートex」を判定語に
- クリックが「覆われている／まだ表示されていない」で拒否されると、モデルが諦めていた → 道具の側で1秒おきに3回押し直す
- Chat Completions で画面写真を返す時、tool メッセージの間に user メッセージを挟んで API に拒否されていた

残り: 作業の種類と回数を増やした比較（同じ bench で）。
