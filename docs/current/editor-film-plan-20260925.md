# 映画の制作相談から場面へ：接続の進捗

## 保存・反映済み

- シートと別に作品単位のfilm_planをcontents.jsonへ保存。物語、合意状態、場面ID、行動・台詞・カメラ・音・長さ、実物ID、変更根拠。更新はリビジョン照合とファイルロックを使い、全変更の検証後に保存する。
- LIVEのResponses側へupdate_film_planとrevise_consultation_visualを追加。シート完了から自動で長編生成へ送る旧指示を削除。展開を持っているか確認し、未定なら提案する。
- 会話の制作委譲と実際の制作ランタイムの両方へ最新の制作案を渡す。過去の停止ジョブを最新の制作方針として扱わない。
- 提示済みのscene/compositionを差分修正可能にした。場面に結び付いた実物の更新は自動でfilm_planにも反映し、ID付け替えのためだけの追加モデル呼び出しを不要にした。
- 画面に折りたたみ式「物語と場面」を追加。保存した場面順、尺、関連見本を見返せる。作品切り替え時に旧作品の表示を破棄。
- 音声セッションと制作ジョブがないことを確認してsandboxを再起動。最終バックエンド変更反映時PID34348、ポート8000。静的JSは同サービスから配信。新しい会話で新ツールが有効になる。

## 未達（重要）

実際のネイティブウィンドウ内での操作、音声付き全編Vコンテ、本番生成への通し検証は未実施。今回の描画検証はネイティブと共有するWeb描画部分と書き出し用動画化であり、最終合成器までのエンドツーエンド検証ではない。

sceneのレイヤー順と通常映像との重なり、トリミング・速度変更への追従も追加検証が必要。現在のscene描画はプレビュー上のWebViewを使うため、あらゆる既存クリップ操作と同等とはまだ言えない。初回提案34秒・3D提示45秒はユーザーが求める即時性に届いていない。制作案の保存・部分修正・タイムライン接続を実装したことは、本番品質の映像完成を証明しない。
