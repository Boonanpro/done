# 語尾・会話の追加によって未開始依頼が消える件

## 変更

先読みdelegationが発話の途中までしか見ていない時、古い操作は従来どおり拒否する。拒否したfunction_call_outputへ、受信済みの本人の発話断片（順序保持）と直近の会話を添える。同じresponseの全toolが終わり、全outputを送信できた後だけ、次の推論が読んだrevisionをそのスナップショットへ更新する。既存のresponse.createの一往復を使い、新しい問い合わせを増やさない。

「実行拒否」と「本人が依頼を撤回」を区別し、未受付の仕事も含めて全文で道具を選び直す。語尾・相づちの許可語や判定閾値は変更しない。送信失敗ではrevisionを更新せず、新発話が送信中に来てもその新発話まで読んだ扱いにしない。承認・外部操作の条件は従来の道具が維持する。本文が12000文字を超える場合は切り捨てず従来の拒否を維持する。
