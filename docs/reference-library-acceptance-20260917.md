# 参考提示と絞り込みの合格基準

今回の範囲は「登録済みの実物を見ながら、言語化しづらい好みを絞る」。制作全体や音声の自然さの合格とは区別する。

## 固定する目標

- 4分野（イラスト・実写・字幕・動き）で各3ケース、計12ケース。各ケースは最大3回の比較。目指す特徴は評価側だけが持つ。
- 12ケース中10ケース以上で目標の特徴に到達。明示的に拒否した特徴の再選択、動画要求への静止画代用、制作の無断開始は0件。
- 文字起こし済み指示から実物の表示完了まで中央値3秒以内、p90が5秒以内。選択後の表示は0.5秒以内。ネットワーク待ち・CLI起動・描画を含める。欠品の応答時間は別集計。
- 過去の案を保持し、説明の長文や詳細ボタンを足さない。途中で指示が変わった場合、古い判断を表示しない。
- ライブラリ外の要求、変更/制作、単なる質問は別途負例として確認。勝手にWeb検索・生成に進まない。

## 事前に固定する評価対象（モデルには非公開）

1. イラスト：深刻な体験談、漫画風、困った人物、陽気な笑顔を避ける。
2. イラスト：大人向けの落ち着いた再現、写実寄り、緊張した複数人物。
3. イラスト：人物紹介、白黒の大胆な似顔絵、場面全体でなく顔。
4. 実写：静かな自然、固定の観察映像、人物やCGなし。
5. 実写：現実の場所を感じる屋外映像、カメラ/被写体の動きが確認できる。
6. 実写：物の動きが分かる短い実写、静止画や架空3Dは不可。
7. 字幕：落ち着き、柔らかい出現、読める日本語、跳ねない。
8. 字幕：比較案から強調がある方を選ぶ。派手な全面装飾は避ける。
9. 字幕：文字が主役、動きは控えめ、前の候補と異なる処理を比較。
10. 動き：何度も往復する状態と一度で伝わる状態を見比べる。
11. 動き：複数の情報が集まってから相手へ届く。
12. 動き：同じ説明内容で動きの速さを比較。人物映像を選ばない。

テストで見つかった失敗を直した場合、同じケースの改善結果と未知の言い換えによる再確認を分けて報告する。タイトルやラベルだけの一致を映像品質の合格にしない。全体の合格率は実物の確認を含めて判断する。

## 測定の限界

音声API残高切れが直近ログにあるため、まず会話原文の再生と実ブラウザーで検証する。発話終了からの時間・音声会話の自然さは未検証として残す。追加チャージはしない。

## 実施結果

2026-09-17、`scratch/reference-library-acceptance/calibrated/summary.json`。

| 目標の参考へ絞り込む | 10/12以上 | 12/12、各2ターン |

| 同p90 | 5秒以内 | 1.021秒 |

検証対象は21点の登録済み参考。イラスト11点、字幕4点、図解4点、実写2点。実ブラウザー（Edge）で画像・日本語・動画再生・動く図解を確認した。Python回帰テスト71件、JavaScript20件通過。選択中に発言が変わる場合の古い結果の抑止もテストした。

単に選択を急がせる指示ではなく、参考の内容と形式を直接評価し、登録済みの実物を既存の表示器へ渡す。強い一致があるときは弱い案で候補数を埋めない。曖昧な判断だけAstra CLIに渡し、その読み取り専用処理では制作に必要な全スキル等を読み込まない。思考深度はmediumを維持した。

途中の言い換えテストでは10/12や11/12の失敗、p90が11秒を超える結果もあった。誤った内容ラベル、候補を番号だけで参照する評価、不要な二段階判定を修正。広い参考探しを最終制作の完全一致として扱いすぎる選択基準も調整し、欠品の負例を増やして確認した。最終値は開発中に繰り返したケースの回帰確認であり、未知の要求全般の性能推定ではない。

### 残る範囲

- 欠品と判断する要求には最大8.201秒かかった。表の表示速度には混ぜず別集計した。
- 2ターンの用意した自然文による検証。音声認識・発話終了検出・自然な質問生成を含む自律的なアキネーター会話は未検証。
- 有効な参考が少ない場合は1点だけ出る。常に複数の十分異なる案を出せる規模にはなっていない。
- 新しい動画の演出品質や長編制作の合格を意味しない。参考を速く選び、表示し、変更要求を反映する部分の検証。
- メディアは`uploads/reference-library/`に保存。別PCへ移す場合はこのファイル群も必要。
