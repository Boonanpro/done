## 失敗防止

- HTMLやJSONの応答をメディアファイルとしてアップロードする前に拒否。
- VimeoページのURLをmp4として分析サービスへ送らない。
- 同一プロセス内の同一素材・同一質問の並列分析は一度にまとめ、成功結果を共有。
- 参考の取得・提示はタイムラインの編集ロックを保持しない。
- 前回HTTP400だった元の質問を再実行：126.89秒で成功。元動画に条件を満たす連続区間が見つからないという分析結果。400の原因自体は再現できず未確定。外部エラー解消済みとは主張しない。
