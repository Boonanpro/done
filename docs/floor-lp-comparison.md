# Image 2 LPの同内容再構成（2026-09-07）

比較URL: http://localhost:3001/preview/floor-lp-compare

## 比較対象と実施内容

既存「コンセントで使える床暖房」実写LPの冒頭2タイル:
`frontend/public/artifacts/oku-yukadanbou-real/tiles/n1.webp` と `t2.webp`。
元タイルは変更せず比較用ディレクトリへそのままコピーした。

写真・文言・順序を維持して、見出し、本文、CTA、比較表をネイティブな要素で再構成。
画像を読み、コードを書き、ブラウザーの比較画像を見て字体・サイズ・折返し・余白を
調整した。別デザインのLPを作っただけの前回サンプルとは異なる。

写真は元の画素を使う。元画像をimgのobject-fit/object-positionで写真領域に限定して
表示するため、人物や写真の構図は変わらない。元画像内の見出し・ボタン・比較表の
画素は表示されない。写真を非表示にしても、再構成した文字・ボタン・表が残る。
素材の元ファイルがタイル画像であることは隠さない。写真領域の表示はクロップであり、
写真内部の人物や物体まで編集可能なレイヤーに変換したものではない。

写真のみを生成モデルで取り出す方法も2枚試したが、人物・構図が変わったため不採用。
使用したツールはbuilt-in imagegen。入力はn1/t2、指示は写真領域だけを取り出し、
人物・部屋・照明・構図を維持して見出し/CTA/表を除くもの。生成出力は
`C:/Users/Owner/.codex/generated_images/01a07968-b2f9-7733-a164-b66e95261d27/` に残し、
成果物は参照しない。実際に採用した素材は `frontend/public/floor-lp-comparison/`。

## 編集

比較画面の編集版をクリックして、文章・文字サイズ・文字色・画像URLを変更できる。
元に戻す、全変更リセット、再読み込み後の復元を備える。変更はブラウザーの
localStorageに比較サンプル専用キーで保存。顧客の元LPやDBには書かない。
CTAは外観・テキスト編集の検証対象で、登録処理は接続していない。

描画は既存のEditableText/EditableElement/EditableProviderと公開リビジョン形式を使う。
比較画面の編集パネルはこの試験専用。ダンのチャット成果物タブへの統合や自動生成
全工程の検証を完了したものではない。

## 実測と残る差

574px幅で元の2区間は2030px、再構成は約2040px（最終値はresults.json参照）。
これは高さの比較で、画質やデザインの合格点ではない。
元画像・再構成・モバイル・写真を隠した状態を実ブラウザーで撮影し目視確認した。
フォントの字形、字間、太さ、比較表のアイコン、平坦な背景の質感には差がある。
写真・主要配置・文章を残して編集できることは確認したが、完全一致とは言わない。
