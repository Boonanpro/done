# Reference library expansion, 2026-09-21

## Delivered

- URL metadata index: 1,191 → 6,753 unique references (+5,562), 33 primary categories.
- Search collection: 97 queries, 70 results requested per query; 6,582 distinct discovered IDs. Existing references preserved. No search failures; all new entries classified.
- Sources include launch films, commercials, narrative films, anime, animation, documentaries, travel, tutorials, production breakdowns, games, architecture, interviews and events.
- Video bodies are not downloaded. The index stays server-side; the editor receives selected presentation data, not the full catalog.
- Read-only index snapshot is cached and refreshed after atomic replacement. Measured cached read median: approximately 0.03 ms (50 reads).
- Initial proposals now use multi-family routing too. Uncertainty retains full search; no supported routed result falls back to full search.
- Secondary genre threshold is 0.1; zero-probability categories no longer enter routing merely to fill a minimum count.
- Jev batches have at most 200 candidates plus none, four concurrent requests per search, recursive finalist reduction. A 12,000-candidate mocked test verifies coverage and the 255-choice limit.
- Explicit format conflicts are checked separately before results and shortlist are returned. Known unavailable references are excluded from embedded results.

## Verification and limits

- 36 affected code tests passed. No assistant voice tests.
- Final six real retrieval calls: 1.155–2.703 seconds. These measure retrieval, not the full voice-to-display experience.
- Actual running `/visual-decision` endpoint: HTTP 200, compare, handled; 6.341 seconds including intent/comparison work. This run used full-index fallback. The end-to-end one-second target is NOT established.
- 16 returned URLs answered YouTube oEmbed with HTTP 200. This is not actual player playback validation or a guarantee against future expiry.
- Additional entries have metadata-only labels. No claim that their aesthetics, scenes, audio or licensing were inspected. Medium remains unknown rather than being invented from a query.
- Matching is still imperfect: the anime case can include a science explainer; a related commercial appeared in an earlier architecture run. More data alone does not solve ranking or preference preservation.
- Category coverage remains uneven (e.g. software launch 23, creator ads 10). Raw count is not proof that every request is covered.
