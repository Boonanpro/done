## タブ構成の改訂案（2026-09-23・試作のみ）

最新版の試作は Home / Projects / Collab の3タブ。成果物の独立タブを廃止し、プロジェクト内の成果物への導線は維持する。Projects右上のコラボ入口を下部の独立タブへ移動。Collabでは部屋名・最終メッセージ・時刻・未読を一覧し、部屋を選ぶと会話を開く。

## 依頼と到達点

現行UIは仮の姿であり、機能開発を優先してきた段階から、見た目と操作構造を刷新する。対象はまずAndroid APK。既存の機能・データ・通話の継続を保ち、依頼→作業確認→成果物→修正依頼を一続きにする。英語・日本語を提供し、依頼者の端末は英語が既定。目的を伝えられる箇所は言語より視覚を優先する。

試作：同じディレクトリの `index.html`。3構成 × 2言語。ホーム、プロジェクト検索、会話、詳細、作品プレビュー、機器選択、音声画面、添付、言語設定を触れる。会話・作品・進捗は架空のサンプルで、APIを呼ばない。

## 現行の問題

- ホームの会話カードとAtom説明が初期画面の大半を占有。プロジェクト一覧が下に追いやられる。実機画像 `scratch/dan-ui-implementation-20260923/phone/user-current.png` で確認。
- 未読・作業中・成果物が別々の場所にあり、開く前に何を優先するか判断しづらい。会話の履歴と仕事の状態が同じ情報のように見える。
- プロジェクトのピン留めと削除、音声機器選択が長押しにも依存。既知の利用者だけが見つけられる。可視のメニューを併設する。
- 入力欄の横に添付・制作物・送信を詰め、文字入力の横幅が狭い。入力欄を上段、補助操作を下段に分離する。
- 表示言語が日英混在。利用者のコンテンツとUI文言が同じ翻訳対象にならないよう分ける。

## 機能棚卸しと新しい置き場所

| 現行機能 / 根拠 | 再設計での配置 | 実装上の注意 |
|---|---|---|
| 全体相談 `hub`、`startHubVoice` / App.tsx | 常設の入力入口とマイク | タップ時に開始。画面を開いただけではマイクを起動しない |
| プロジェクト一覧、検索、未読、ピン / App.tsx の projects 画面 | Projects とホームの最近の会話 | ピンと未読を保持。フィルタ0件と初回0件を区別 |
| `has_active_run`、`streamingProjects` | ホームの進行中 | 未読を完了や承認待ちに変換しない。作業0件なら枠ごと消す |
| `/projects/{id}/current-run` と execution-events | 仕事の詳細、会話内の簡潔な状態 | 作業中の全プロジェクトを高頻度ポーリングしない。詳細は選択時に取得 |
| テキスト・添付・制作物参照・下書き / handleSend | 二段の入力欄 | 送信失敗時の本文と添付復帰を保持。UI言語で本文を翻訳しない |
| `/chat-artifact?project_id=…` と登録URL | プロジェクトの成果物、プレビュー | 公開とプレビューを区別。URLが未登録なら公開済みを装わない |
| `VoiceHost` と `VoiceOverlay` | 音声画面、全画面共通の最小化バー | 通話は開始した部屋に所属。移動先に切り替わらない |
| AtomRelayControl | 機器選択・設定、通話中の接続状態 | ホームの説明文を減らすが、接続停止・再開・エラーの導線を残す |
| 共同ルーム / collab.tsx | Projects 内の個人 / 共同、未読表示 | サンプル試作の共同ルームは説明のみ。実装では既存ルートを再接続 |
| 通知・OTP・ログイン / App.tsx | Settings | 表示言語変更で認証・権限・通知登録に触れない |
| タイムライン参照 / openTimelineSheet | 入力欄の添付メニュー | 制作物参照を画像添付と混同しない |

## デザイン方向

### A：仕事を見渡す（推奨）
明るい緑がかった白、深いグリーンの主操作。余白・文字階層・行の整列で仕事を整理する。ホームは進行中→最近の会話→閲覧できる成果物。声と文字は下部の一貫した入口。昼間の携帯利用を想定した明るさは設計仮説。独立したダーク配色も実装時に用意する。

長所：頼む前にも後にも使える。履歴が増えても入口が埋もれない。
弱点：会話だけを使う人にはホームが一段増える。最後の会話への復帰と通知直通で補う。

### B：会話から始める
深い青、淡い青の操作色。マイクと短い問いを中央に置き、文字入力と直近の続きを隣接させる。個人アシスタントに話しかける体験が入口。

長所：新しい依頼の起点が明快。夜間の音声利用に合うという仮説。
弱点：現行同様に会話が大きく、並行作業を見渡すには一覧へ移動が必要。

### C：作ったものから
淡い青白、インディゴの主操作。サムネイルと作品名を入口にし、関連する会話へ戻る。制作物が利用者の記憶の手掛かりになる。

長所：制作中心の利用で再開しやすい。
弱点：成果物を持たない相談には向かない。横断一覧・サムネイルの安定したデータ契約が必要。

3案とも同じ機能を削らず、優先順位を変えて比較する。色だけ変えた同一配置にはしない。現時点の推奨は設計判断であり、ユーザーの利用頻度を測定した結論ではない。

## 英語・日本語と視覚言語

単一のコンポーネント構造と意味別トークンを使い、文字列辞書だけを差し替える。設定で保存し、ユーザー指定の端末ではEnglishを既定。OSロケールからの推測で明示設定を上書きしない。

| 表現 | 使い方 |
|---|---|
| 戻る・検索・閉じる・再生・添付・マイク | 一貫した線幅のアイコンを主表示。ローカライズ済みaccessibilityLabelを必須 |
| 主ナビゲーション | アイコンと短いラベル。選択は背景・形・読み上げのselected状態で示す |
| 作業中・エラー・停止・公開 | アイコンと短い状態名を併記。色やアニメーションだけでは伝えない |
| 動画・Web・文書 | 実際のプレビュー、種類アイコン、作品名。画像がない場合は種類ごとのプレースホルダー |
| 機器選択 | スマホ・ヘッドホン・端末アイコンに名称を添える。Atomを未知の人にも区別可能にする |
| 削除・承認 | 対象と結果を短く明示。普遍的と断言できないアイコンだけで判断させない |

翻訳対象：UIラベル、権限の説明、エラー、空状態、動的な時刻・件数、読み上げ名。翻訳しない：ユーザーの名前、プロジェクト名、メッセージ、作品本文。英語は短い動詞、日本語は簡潔な自然文。固定幅の文字ボタンや強制大文字を避ける。複数形・日付はlocale対応のフォーマッターに寄せる。

## 操作と状態の契約

- 戻る：シート→詳細→元の一覧の順に戻る。検索条件・下書き・スクロール位置は保持する。`rule/preserve-user-input`
- 依頼：送信先の部屋を明示。送信中、追加指示待ち、失敗、再接続の各状態を分ける。停止は該当作業のみ。`rule/name-object-scope-consequence`
- 通話：開始先・機器・ミュートを明示。最小化と終了を別操作にする。未知の端末へ自動切替しない。`rule/cover-reachable-states`
- 削除：実装に復元機能がない場合は対象名つき確認。Undoを装わない。ピン変更は即時・可逆。`rule/undo-only-when-honest`
- 初回：会話開始を提示。検索0件：検索解除を提示。オフライン：保存済みと表示し更新を保証しない。`rule/empty-state-action`、`rule/error-states-recovery`
- 読込：初期と部分更新を区別。部分更新で既存表示を消さない。並行作業の推定進捗%や完了時刻は出さない。`rule/cover-reachable-states`
- 片手操作、48dp以上、フォント倍率、IME、Back、読み上げ、Reduce Motion、テーマの明暗はAPK実機で検証。試作ブラウザの合格を代用しない。`rule/accessible-name-required`

## 本実装の単位と検証

1. 言語辞書、設定保持、意味別色・文字・余白トークン、アイコンボタン・一覧行・状態表示の部品を分離。
2. 選んだ方向のホームとProjectsを既存データへ接続。複数の画面を一括で変更せず、既存の会話・認証・VoiceHostを維持。
3. 二段の入力欄、仕事の詳細、成果物、機器選択をつなぐ。全機能の新旧導線の対応表で欠落を確認。
4. VoiceOverlay、共同ルーム、設定、エラーの表示文言を含めて辞書化。自動生成文章の日本語を置換で壊さない。
5. 日英両方・狭幅・長い題名・空/多件・通常/拡大文字・IME・オフラインを検証。保存中のデータを触らないテストで送信失敗時の復帰を確認。
6. バージョンとruntimeをそろえ、同一署名でAPKを上書き。依頼者端末はEnglish。ホーム、会話、通話の最小化と戻る、通知からの復帰を実機確認して初めて反映済みと報告。

横断Libraryを最初から提供する場合は、一覧とサムネイルの契約を先に確認する。既存APIをプロジェクト数だけ一斉に呼ぶ実装は避ける。承認Inboxは未確認のため今回の完成機能に含めない。
