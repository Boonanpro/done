# エディター内の制作会話

配布先は `.done/bin/native_ui_editor.exe`。API起動とdone://ランチャーで同じ会話対応版を使用する。旧版native_ui.exeの再配置では上書きされない。サーバー再起動時は終了済みジョブと動画の状態を同期して、処理のない動画の編集ロックを解除する。

2026-09-06: ネイティブエディターの入口を「ダンに指示」に統一。

- 「新しい作品」で空の編集可能な作品を開き、意図やテイストを相談できる。
- 既存作品は「部分を修正」が既定。テキストは明示的なクリップ選択・画面の範囲選択を使用し、マウスの動きから対象を推測しない。
- 音声は発話時の映像・再生時刻・マウス位置と直近5秒の軌跡・画面要素の位置を共有する。明確な対象はresolve_targetで結び、そのまま編集する。曖昧な場合だけpropose_targetで確認用の枠を表示し、次の発話で確認する。
- 確認用の枠と範囲選択はUI表示のみで、動画や出力へ焼き込まない。
- 認証は読み込み時の一回きりのコピーを廃止。ネイティブとのready/auth通知で更新し、401では認証情報を取得し直す。
- 「作品全体を制作」は明示的に選ぶ。作品を切り替えると選択部分の修正に戻る。
- 「選択部分を承認」はAIによる変更を保護する。解除と取り消しは人がパネルから行う。
- 文字と音声は同じRealtime接続・編集APIを使う。マイクはボタンを押したときだけ取得し、終了・パネルを閉じる操作で停止する。
- 重い制作は既存の制作ジョブに渡し、結果をパネルに表示する。
- 高度な編集は部屋で選択したモデルを使う。Claude系はClaude CLI、GPT系はChatGPTログインのCodex CLIで実行する。RealtimeのAPI利用枠とは別。ジョブ開始時に使用モデルを記録する。
- Codexの編集ジョブは読み取り専用の環境で実行し、専用タイムラインMCPに下書きの変更を渡す。モデルを変えても対象外変更・承認済みの保護・同時変更チェックを共通にする。
- 認証済みのアプリからエディターを起動すると更新用トークンをデスクトップに保存する。期限切れ時は通常のrefresh APIで更新する。旧版のアクセス用トークンしかない場合は、最初の一度だけアプリから起動し直す必要がある。

## 2026-09-06の試用ログへの修正

- 字幕の分割・結合・語句の移動は、元音声の発話位置を測って1回の変更にまとめる。文言を保持する指示では、助詞を含む文字の欠落を拒否する。音声と字幕が一致しない場合は推測の時刻で反映しない。
- BGMは元素材への範囲参照で配置し、話し声と音楽の音量を測って初期音量を決める。曲の好みや全編の聴感まで検証したことにはしない。
- 編集情報は選択範囲と再生位置周辺に絞り、古い重複情報・画像を会話から除く。一時的なAPI制限時は指示を保持して再開し、新しい発話では古い再試行を取り消す。
- 会話・操作・API使用量を部屋のassistant/eventsに記録する。キーや音声本体は保存しない。
- 実接続の連続試験で、字幕時刻合わせ→BGM追加→音量半減→変更点の説明を完了。応答あたり入力は2,617〜7,756トークンだった（この試験の実測であり、全制作の上限保証ではない）。
- GPT-6 AstraとFableの実行試験で、指定字幕だけの変更と隣の承認済み字幕の保持を確認。
- 更新用トークンのある期限切れログインをネイティブ実機で更新し、マウス位置からの音声字幕変更、対象外保持、Undoまで確認。利用者自身の旧ログインへの更新用トークン追加は、認証済みWeb画面からの初回起動が必要。

## 保存と編集の境界

`creative_brief`をコンテンツに保存し、次の会話と制作ジョブで参照する。
`assistant/{turn_id}.json`は発話時点の対象・タイムラインのハッシュ・反映した変更の記録。
直接編集と制作エージェントの両方で、元のシーケンスとの比較・対象外変更の拒否・同時編集の上書き防止を行う。
承認済みの時間帯への追加や変更も拒否する。手編集そのものは利用者が行える。
エディター会話からの制作ジョブは専用タイムラインMCPと読み取り・調査ツールに限定し、シェルで保存データを書き換える経路を与えない。
外部更新を取り込む際にUndo履歴を保持する。

## 未検証・制限

本人の肉声を使った操作性、さまざまなジャンルでの長編制作の品質と所要時間は未検証。
今回の新規制作試験は、意図の保存から短い無音の字幕動画の編集可能な下書きまで。
生成モデルで画像の一部を直す際の画素単位の保持までは保証しない。
会話中の軽い編集は逐次実行。処理中もマイクを有効に保ち、割り込み時は音声応答と旧発話の追加操作を停止する。既に反映した変更はUndoで戻す。重い制作を依頼した後は会話を続けられる（発話への割り込みは、受付済みの制作ジョブそのものの中止ではない）。
画面共有は発話に合わせた静止画と操作情報であり、連続した全フレーム映像の視聴ではない。指し示しだけで複数の重なった要素を常に正しく特定できるとは保証しない。
画面の範囲選択はその場所にある編集要素を対象にする。一本の素材の時間途中だけを変更する場合は、カットの分割・範囲の確定が必要。
吉川のv9に報告済みの映像範囲・モザイクの問題は、この実装作業では修正していない。

## 2026-09-06 字幕サイズと会話の文脈

- `set_clip` は未知のスタイル項目や不正数値を、文言も含めた変更前に拒否する。相対サイズは `resize_captions` の倍率から現在値を計算する。
- 高速編集と一括編集ともに、差分ゼロなら保存せず `committed=false` を返す。成功には変更した要素の文言・時刻・変更前後を添える。
- パネルは同じ作品の直近6発話の依頼・操作結果と、最後の実変更を引き継ぐ。現在のUI選択とは分けて提示し、話題の継続か切替かはモデルが解釈する。音声文字起こしは音声item_idに対応する発話へ記録する。
- 音声の明確なclip_id指定は、発話の最初の編集で対象を同時に結ぶ。一度結んだ範囲を同じ発話で黙って広げない。テキストの明示選択と承認済み保護は保持する。
- 編集後の時刻省略 `timeline_frame` は実際に変更した位置を検品する。字幕の有無はレーン名ではなくクリップ内容で判定し、実フレーム寸法で合成する。字幕合成失敗を検品成功として返さない。
- `python -m scripts.test_editor_size_conversation` は実Realtimeモデルへ文字起こし相当の発話を渡し、拡大・画面移動後の追加修正・文言確認・新しい対象への切替を検証。マイク認識の試験とは区別する。
- `python -m scripts.test_editor_assistant_native --size` は実ネイティブ画面で文字領域の拡大・隣の字幕保持・Undoを検証する。

会話の一般的な理解を保証するものではない。多様な制作依頼や長い会話、素材の探索・復元を含む一連の品質保証は引き続き実地検証が必要。

## クリック後のキーボード操作

会話パネルのボタンをマウスで押した後はフォーカスをタイムラインへ返す。入力欄では文字入力を維持する。パネル側にスペースが届いた場合も、入力・IME変換中以外はボタンを起動せず再生停止へ渡す。ネイティブ側のマウス操作でも、文字入力中以外の残留フォーカスを解放する。

`python -m scripts.test_editor_assistant_native --keyboard` で実エディターのマイクを有効にし、OSのスペースキーによる再生・停止、マイク状態維持、別ボタンのクリック後、入力欄の空白入力を検証する。試験は無音マイクと独立した作品を使う。
