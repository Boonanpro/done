# 演出部品から別目的の作品へ：実装と検証

## 目標

- 同じ事実から目的の違う6本（3題材×2目的）を作り、色・文言だけでなく構成・動き・尺配分を変える。
- 事実や数字の追加、文字切れ、意図しない空白を避ける。
- 構成が決まってから実物表示まで2秒以内。演出推薦・構成決定の時間は別集計。
- 一場面の修正で未指定の場面と元タイムラインを保持する。

## 実装

`docs/direction-patterns.json`に演出の狙い・向かない条件・調整箇所を保存。6部品は段階的な提示、対比、情報の集合、手順、視点の集中、言葉のリズム。ジャンルから制作方針を固定するルールではない。

`find_direction_patterns`が会話原文を元にJevの推薦を返す。`preview_direction_plan`が任意の順序・内容・時間・配色から、既存エディターのsceneで直接描画する。コードとparamsを保存し、既存の`revise_presentation`で部分変更可能。タイムラインには自動追加しない。通常の自由なscene作成や他の制作手段も残る。

## 実測

`scripts/test_direction_transfer.py`で実JevとAstra CLIを呼び、構成を生成。構成には期待する部品ID・順序を与えていない。各12秒、3〜5場面で尺配分はモデルが決定。

| 題材・目的 | 構成決定（Jev＋CLI含む） | 構成後のAPI保存＋実描画 |
| --- | ---: | ---: |
| 問い合わせ・安心 | 9.997秒 | 0.236秒 |
| 問い合わせ・興味 | 11.878秒 | 0.152秒 |
| 喫茶店・安心 | 7.963秒 | 0.150秒 |
| 喫茶店・気分転換 | 10.123秒 | 0.209秒 |
| メモ・手順理解 | 12.639秒 | 0.176秒 |
| メモ・発見 | 15.321秒 | 0.164秒 |

例：問い合わせの安心案は3/6/3秒、興味案は2.5/2/5/2.5秒。最初から情報を示す案と、問いを挟んで後で明かす案に分かれた。喫茶店は3場面の余韻と4場面のリズム、メモは手順と発見で演出順序が変化した。

6本すべて実際のEdge上のエディターで再生・複数時刻の描画を確認。部分修正で他場面と元タイムラインが保持された。関連回帰テスト44件通過、引数仕様修正後に新規9件を再確認。普段のport8000へ反映後も実画面を確認：表示0.214秒、部分修正から表示1.122秒。

## 検証中に直した問題

- 明るい背景でも部品が暗い固定色になり文字が見えづらかった：作品の配色から面の色を算出。
- 集合途中のカード重なり：各項目が固有の列を持って集まる動きへ変更。
- 長いラベル：幅に合わせて折り返し。
- 短い場面で動きが終わらない可能性：場面内に動きと読み取りの静止時間を収める。
- 最初のテストは3場面×4秒に固定していた：3〜5場面・合計12秒へ変更。
- 新しい構成生成6件中1件で必要なlabelsが不足し検証で拒否された。ツール仕様に部品ごとの必要項目数を明記し、当該1件を再実行して通過。初回成功率100%とはしない。

## 評価の限界

目的に応じた構成と尺の作り分け、高速描画、編集可能性は確認できた。ただし外観には共通部品の特徴が残り、プロのAfter Effects作品と同等の品質や、一般的な独創性の合格ではない。画像・実写・人物・音声は今回の部品に含まない。自然な音声会話や、自由な要求からモデルが自発的に適切な道具を選ぶ通し会話は今回未検証。

Jevだけで作品を完成させたわけではない。推薦はJev、構成と文言はAstra CLI、描画はローカル。API残高の追加・動画生成API・本編変更は行っていない。大規模参考庫のスケーリング検証も今回の範囲外。

次の品質改善は、部品数だけでなく、実素材を使う構図やカメラ・場面間のつながりを、完成見本と編集可能な実装をセットにして加えること。既存6本と比較し、単なるテンプレート差し替えを超えたか確認する。
