# 動画設計書: 吉川特装 HP 提案動画

## 全体設計
- **視聴者**: 吉川特装の経営者・担当者（特装車製造業、中小規模）
- **核心メッセージ**: 「御社用に作った HP を、そのまま受け取れます」
- **尺**: 45秒目安
- **ゴール**: 採用判断をもらう（「これ使わせてもらおう」の返事）
- **トーン**: 丁寧、落ち着いた、謙虚
- **BGM/ナレーション方針**: BGM 静かめ、ナレーション無し、テロップで補足

### シーン 5: フォーム入力

**秒数**: 23-39秒（16秒）
**物語上の役割**: タスク遂行（問い合わせ完了までの流れ）
**視聴者に感じさせたいこと**: 「入力が楽、すぐ終わる」
**そのために映すもの**:
- 画面: /contact（お問い合わせフォーム）
- スクロール位置: **フォーム全体（会社名〜送信ボタン）が 1画面に収まる位置**
- 中心の要素: 全フォームフィールドと送信ボタン

**操作の流れ**:
```
fit_elements_in_viewport([
  'input[name="company"]',
  'input[name="name"]',
  'input[name="phone"]',
  'input[name="email"]',
  'select[name="vehicle"]',
  'textarea[name="message"]',
  'button',
])
wait(1s)
type(selector='input[name="company"]', value="サンプル運送株式会社")
type(selector='input[name="name"]', value="山田太郎")
type(selector='input[name="phone"]', value="090-1234-5678")
type(selector='input[name="email"]', value="yamada@sample.co.jp")
select_option(selector='select[name="vehicle"]', label="ダンプカー")
type(selector='textarea[name="message"]', value="ダンプカーの修理をお願いしたいです。")
```

**前シーンからの繋がり**: 問い合わせページに辿り着いた直後、実際に記入する様子
**編集演出**:
- ズーム: フォーム中央 / 1.4倍 / 16秒間保持（入力中ずっと）
- テロップ: "わずか数項目で送信完了" / 画面上 / 30-35秒
- 効果音: タイピング音 / 各 type 中、クリック音 / select 時
- トランジション: なし

**検証チェック**:
- ズーム回数: 1
- テロップ数: 1
- クリック: 1（select）
- タイピング: 5
