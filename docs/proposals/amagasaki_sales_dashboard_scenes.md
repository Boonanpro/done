# amagasaki_sales_dashboard — シーン設計書

**説明**: 尼崎B2B AIセールスパイプラインの運用ダッシュボード。AIが毎朝5,000社を診断し、みきさんは承認するだけで1日が回る、を示す提案動画。

**物語の軸（1タスク完遂）**: 朝ダッシュボードを開く → 今日やることを見る → 重点候補の田中精密工業を開く → AIの課題仮説とHP診断を確認 → プロトタイプHPを自動生成 → AIが書いたメールを承認して送信 → KPIで全体の進行を俯瞰

**総尺**: 約92秒（3分以内）

**操作の流れ**: 操作なし。カーソル非表示。テキストアニメーションのみ
**前のシーンからの繋がり**: 動画の入り口
