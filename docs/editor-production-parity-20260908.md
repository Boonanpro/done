# 制作判断・Google直結・エディター反映の確認

## 修正

- 音声・制作で共有する制作費用の契約を `editor_production_contract.py` に集約。過去の「有料動画禁止」を固定する代わりに、今回のユーザーの許可・上限・課金先を読む。許可のない支出を認める変更ではない。
- 制作側は音声側の作業案を再検討し、参考・会話を必要時に読んで、演出・手段・品質判断まで担当する。
- `conversation_history` は双方の発言を役割付きで返す。作品の識別、過去ページの取得、途中書き込みの扱い、文字指示へのフォールバックを実装。通常チャットは混入しない。
- `generate_video` の無条件拒否を撤去。省略時はGoogle API直結、Higgsfieldは明示時のみ。Omniのstyle参照とedit入力を区別し、実測出力尺で素材登録する。
- Googleの依頼・結果・使用量・ファイルを保存。同一依頼は成功結果を再利用、結果不明の再送を防止。作業用素材はキャッシュから無再エンコードでコピーし、ドラフト破棄で再利用元を消さない。
- 提案採用ボタンが一律に「通しの下書き」を指示する文を除去。
- 新規の空タイムラインでもクリップ選択を要求していた不具合を修正。既存作品の選択範囲・承認保護は維持。

## 検証

- 関連Pythonテスト47件（重複実行を除く）合格。Google接続はモックでREST形式・参照モード・登録・再利用・通信失敗後の重複防止を検証。
- Google実接続の映像生成実績は前のA/B各1本。この変更後の追加の有料動画生成は行っていない。
