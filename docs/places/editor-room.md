# エディターの中の「ダンと制作」

動画を作る時にダンと話す場所。本体のチャットから動画の話を分け、エディターの画面を見ながら話す。

## 中にある物

- `library` 制作ライブラリ。左に「新規作成」・作品の一覧・素材のフォルダ、真ん中に作品の絵の一覧と大きな「新規作成」。作品の絵を押すと、その絵の上に「開いています」が出て、組み立て終わるとタイムラインに切り替わる（長い作品で0.1秒ほど。2026-11-19）。会話は無い（前にあったライブラリの部屋の会話は兄弟の部屋として読める）。
- `content-chat` 作品を開いた画面（タイムラインとプレビュー）の右の欄。作品ごとに1つの部屋。この部屋のダンはその作品のタイムラインの道具（mcp__timeline__*）を持ち、再生位置と選んだクリップが「ここ」「これ」になる。
- `card-thumb` ライブラリの動画の札の右下に出るサムネ（PC はマウスを乗せた時、スマホはいつも）。押すとエディターより先にサムネのページ。サムネだけの札は一覧に出ない。
- プレビューのテロップをダブルクリックすると、映っている文字に直接入力できる。プレビューか右の本文欄で文字を選び、右の「文字色」「大きさ」を動かすとその部分だけが変わる。タイムラインで隣り合うテロップの端を左右に引くと両方の長さが変わる。
- `thumb-button` 動画の画面の上の道具の並びの「サムネ」（小さな絵つき）。サムネが無い動画では「サムネを作る」。
- `work-sections` サムネのページの上（スマホは動画の画面の上にも）の「動画／サムネ」の切り替え。案が何枚あっても札は「サムネ」1つで、案はサムネの下の帯で選ぶ（11/24 本人「上のタブでサムネ2と増えていく必要は無い」）。サムネのページの「動画に戻る」でその動画のタイムラインへ。
- `thumb-layers` サムネの部品の一覧（上が手前）。名前の文字ではなく、その部品だけを切り抜いた小さな絵が並ぶ（名前はマウスを乗せた時だけ）。右クリックの「ここにある部品」と選んだ部品の欄も同じ絵。タイムラインの動画・画像のクリップも、端から端までその所のコマで埋まり名前の文字は出ない（11/24 本人「実物で見せられるものは全部実物で見せろ」）。
- `thumb-patterns` サムネのページの下（スマホはサムネのすぐ下）の案の帯（2026-11-24 本人「canvaみたいに増やせるように」）。案が小さな絵で並び、押すとその案を開く。先頭の「表」が動画に使うサムネ。「＋」で白紙の案を足す。複製は部品を選んでいない時の Ctrl+D か、案の「…」の「複製する」。「…」で 表のサムネにする・消す（控えに回すだけ・最後の1つは消せない）（11/24 本人「案を足すのテキストいらない。＋は白紙、複製はCtrl+Dと…だけ」）。本人が足した案は本人の物で、ダンは頼まれない限り案を増やさない。
- `thumb-comment` 部品を選ぶと右上に「コメント」が出て、押すとその場にコメントの欄が出る（Enter で送る）。ペンの「書き込む」で丸や矢印を描くと、線の横に同じ欄が出る。送ったコメントは番号の印としてサムネの上に残り、右の欄の「コメント」に、ダンが直している様子と直した結果が出る（11/24 本人「要素を選択したらコメントできるように。台本エディターみたいに」）。ダンには並行作業として届き、thumb.py で直す。
- `thumb-board` サムネの枠の外も作業台。はみ出た部品は枠の外に薄く見え、選ぶ・つかむ・動かすができる。部品の一覧の絵も切らずに全部を見せる。上の「仕上がりで見る」で書き出される形（枠で切った形）だけに切り替え、「枠の外も見る」で戻る（11/24 本人「アスペクト比はあくまで表示するウインドウ」）。
- `thumb-select` サムネの部品の選び方: 選んでいる部品は四角の中なら透けた所でもつかむ。動かさずに離すと、その上に重なって見えている部品へ選び替える。下の部品は右クリックの「ここにある部品」か ⌥/Alt＋クリック。「画像」ボタン・貼り付け・サムネへ落とすで画像を足せる。
- `toggle` 上の「ダンと制作」のボタンで欄を開け閉めする。
- `voice` 欄の上の「話す」で、この作品のダンと通話する（2026-11-17）。みきさんが話している間の再生位置・選んだクリップ・プレビューでマウスを置いた所が、言葉ごとに記録され（app/services/voice_editor.py）、直す作業（チャットで頼んだ時と同じ作品の部屋の作業）に、その時の完成画面の絵（指した所に赤い丸）と一緒に渡る。作業は直す場所と中身を一言で言ってから直し、直す様子はタイムラインの上にダンの手として見える。話している間は画面全体のふちが声に合わせて光る（チャットの地図の voice-mode と同じ）。

## 行き方（みきさんから見て）

本体の部屋の上の「制作」を押す → すぐ「ダン 制作」の起動画面の窓が開き、続けて制作ライブラリが出る。「新規作成」を押すと空のタイムラインの作品ができて開く。作品を押すとタイムラインの画面になり、右の欄がその作品の部屋になる。素材のフォルダの中の絵を押すと、その素材が大きく開く。

## 道具で動かす

- 前提: 本体の部屋に素材（uploads/production-assets/<本体の部屋>）がある
- 作品の部屋で「ここの字幕消して」→ timeline の道具で直す → 左のタイムラインがその場で変わり、ダンの手（青い光と矢印）が見える
