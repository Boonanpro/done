# 音声テスト後の修正と検証

2026-09-08。対象は会話・制作停止・通知・部分編集・参考からの演出応用。

## 変更

- Realtimeのassistant履歴挿入をoutput_textに修正。マイク接続中のテキスト入力にも音声で返答する。正常な応答で古いエラー表示を解除。
- 中断された未発話の通知を再送待ちへ戻す。新しい制作が始まった後の古い結果を現在の状態として通知しない。通知を待つ理由と待ち時間をログへ記録。
- 通信が無期限に固まらないようリクエストに45秒のタイムアウト。発話開始をログ送信の完了待ちから分離。
- stop_productionを追加。作品内のジョブに限定し、会話だけの待機とは別に停止する。停止マーカーとタイムライン保存を同じロックで調停し、停止後の遅れた保存を拒否。
- 発話の中断は古い検索等のロックが解けるまで待たない。取消意図を別ファイルへ直ちに保存。
- Codexの外部操作の開始・終了を制作表示へ渡す。以前は開始時のイベントを終了扱いしていた。
- motion書き出し中も独立した編集を受け付け、素材登録時は最新の下書きへマージ。GPUの生成処理は従来どおり直列。
- 参考から別題材へ応用する制作判断、試作の選び方、対象に応じた検証、既存素材・分析・編集元の再利用を制作の共通指示へ追加。本人の指定とAIの提案を区別する。
- 音声ツールのローカル固定・固定所要時間の説明を、実際の設定済みバックエンドと実測値に修正。
- 保存済み本作品のbriefから、本人が指定していなかった顔・ロゴ禁止だけを除去。変更前後はuploads/editor-brief-correction-20260908.json。映像は変更していない。
