# 編集元を保持するモーショングラフィック接続

ユーザー承認済みの reference-01-finish を品質の出発点として、任意のHyperFramesプロジェクトをDanの制作担当が扱える。

## 制作と修正
- prepare_motion_project(project_dir) は任意の編集元、asset_id は過去の保存版、template=true は承認済み見本から編集用コピーを作る。
- HTML・CSS・GSAPは通常のファイル操作で修正。型や効果を固定の選択肢に制限しない。
- render_motion_project は独立した保存版を作成→HyperFrames check→render→映像素材登録を実行。素材 metadata.motion_source に元データ、各ファイルハッシュ、CLI版、所要時間が残る。
- 新規はadd_clip、部分変更はset_clip_propsでその場面のasset_idを更新。タイムライン全体や比率は書き換えない。前版は変更しない。
- 通常の制作担当と同じMCPに追加され、テキスト・音声のどちらから委譲されても利用する。

## 表示上の限界
ネイティブエディターでは合成された場面が一つのクリップになる。内部の文字・光・動きはHTMLの編集元で保持し、Danがそこを直して差し替える。内部要素をネイティブの個別クリップとして直接つかんで編集する機能ではない。

## 品質と予算
参考の録画を見本映像として流用しない。見本テンプレートの比較用音声は新規制作へのコピー時に除去。未知の参考も調査して独自プロジェクトを作れる。作品ごとに全編下書きと短い仕上がり見本を選ぶ。
