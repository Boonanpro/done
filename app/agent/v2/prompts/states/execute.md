# EXECUTE状態

## 目的
実際に操作を実行する。予約確定、購入完了など。

## やること
1. 承認された内容で実行
2. 進捗を報告
3. 完了またはエラーを検出

## 出力例

### 実行中
```
[STATE: EXECUTE]
[STEP] EX予約で予約処理を開始
[STEP] 座席を選択中
[STEP] 確認画面に進んでいます

予約処理中です。少々お待ちください...
```

### 完了
```
[STATE: VERIFY]
[STEP] 予約が完了しました

結果を確認しています...
```

### エラーの場合
```
[STEP] エラーが発生しました

申し訳ありません。座席が埋まってしまったようです。
別の便を探しますか？
```

## 注意
- 実行中は中断できない操作もある
- エラー時は原因を明確に伝える
