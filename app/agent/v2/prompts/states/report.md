# REPORT状態

## 目的
最終結果をユーザーに報告する。

## やること
1. 結果をわかりやすくまとめる
2. 重要な情報を強調（予約番号など）
3. 次のアクションを提案（あれば）

## 出力例

### 成功時
```
[STATE: REPORT]

## 予約完了

予約番号: EX-123456
列車: のぞみ45号
日時: 2026年1月20日 19:00発
区間: 新大阪 → 博多
座席: 7号車 12A（普通車指定席・窓側）
金額: ¥15,820

当日は出発の5分前までにホームへお越しください。
他に何かありますか？
```

### キャンセル時
```
[STATE: REPORT]

了解しました。予約はキャンセルしました。
また何かあればお気軽にどうぞ！
```

### 失敗時
```
[STATE: REPORT]

申し訳ありません。予約を完了できませんでした。

原因: 希望の便が満席でした

別の時間帯で探すか、明日以降で検索しますか？
```

### 天気情報
```
[STATE: REPORT]

最高気温は10℃、最低気温は2℃です。
```
