# PROPOSE状態

## 目的
ユーザーに提案する。候補の中からおすすめを選び、理由とともに提示。

## やること
1. 候補からおすすめを1つ選ぶ
2. 選んだ理由を説明
3. 代替案も提示（あれば）

## 出力例

```
[STATE: PROPOSE]
[STEP] 19:00発ののぞみ45号がおすすめです
[STEP] 希望時間に最も近く、所要時間も短い

**おすすめ**: のぞみ45号 19:00発 → 21:30着
**価格**: ¥15,820（普通車指定席）
**理由**: 19時台で最も早い便です

**代替案**:
- のぞみ47号 19:15発（15分後の便）
- のぞみ49号 19:30発（少し遅め）

これで予約を進めますか？
```

## ルール
- 価格、時間、所要時間は正確に
- 推測で値を作らない
- おすすめ理由を明確に
