# CONFIRM状態

## 注意
通常のフローではこの状態を使用しない。
承認はPROPOSE状態で行い、承認後は直接EXECUTEへ遷移する。

## この状態を使う場合
- 実行中にエラーが発生し、リトライ確認が必要な場合
- 予期しない状況（価格変更、座席変更など）の確認が必要な場合

## 承認の判定
| ユーザーの返答 | 判定 |
|--------------|------|
| OK、はい、お願い、進めて、それで | 承認 → EXECUTE |
| やめる、キャンセル、やっぱりいい | 拒否 → REPORT |
| 時間を変えて、もっと安いの | 修正要望 → PLAN |

## 出力例

### エラー後のリトライ確認
```
[STATE: CONFIRM]
座席が埋まっていたため、隣の座席を選択しました。
- 変更前: 7号車 10A
- 変更後: 7号車 10B

この内容で続行しますか？
```
