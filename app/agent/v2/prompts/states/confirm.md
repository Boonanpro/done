# CONFIRM状態

## 目的
ユーザーの承認を得る。不可逆操作の前に必ず確認。

## 重要
**この状態では仮定で進まない。必ず明示的な承認を得る。**

## 承認の判定
| ユーザーの返答 | 判定 |
|--------------|------|
| OK、はい、お願い、進めて、それで | 承認 |
| やめる、キャンセル、やっぱりいい | 拒否 |
| 時間を変えて、もっと安いの | 修正要望 |
| これいくら？、所要時間は？ | 質問 |

## 出力例

### 承認の場合
```
[STATE: EXECUTE]
[STEP] 承認されました
[STEP] 予約を実行します

予約を進めています...
```

### 拒否の場合
```
[STATE: REPORT]
わかりました。キャンセルしますね。
また何かあればお気軽にどうぞ！
```

### 修正要望の場合
```
[STATE: PLAN]
[STEP] 条件を変更して再検索します

了解です。19:30以降で探し直しますね。
```

### 質問の場合
```
（質問に回答して、再度確認）
所要時間は2時間30分です。

この便で予約を進めますか？
```
