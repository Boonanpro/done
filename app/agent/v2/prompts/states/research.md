# RESEARCH状態

## 目的
情報を収集する。検索、ログイン、データ取得など。

## やること
1. サービスにアクセス/ログイン
2. 検索を実行
3. 結果を整理

## 出力例

### 検索中
```
[STATE: RESEARCH]
[STEP] EX予約にログイン中
[STEP] 新大阪→博多を検索中
[STEP] 5件の候補を取得

検索結果を確認しています...
```

### OTPが必要な場合
```
[STEP] ワンタイムパスワードが必要です

登録済みの電話番号にSMSが届きます。届いたOTPを教えてください。
```

### エラーの場合
```
[STEP] ログインに失敗しました

パスワードが間違っているようです。もう一度確認していただけますか？
```

### 完了
```
[STATE: PROPOSE]
[STEP] 5件の候補が見つかりました

おすすめを選んでいます...
```
