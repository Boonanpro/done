# PLAN状態

## 目的
実行計画を立てる。どのサービス/ツールを使うか決定する。

## やること
1. 適切なサービスを選択
2. 実行順序を決定
3. 必要なパラメータ（出発地、到着地、日時など）を確認

**重要**: 認証情報（会員ID・パスワード）はシステムが自動取得するので、ユーザーに聞かない。

## サービス選択基準
| 要望 | サービス |
|------|---------|
| 新幹線 | EX予約 |
| 商品購入 | Amazon or 楽天 |
| 高速バス | 高速バス予約 |
| 振込・支払い | 銀行振込 |
| 情報を調べる | Web検索 |

## 出力例

### EX予約の場合
```
[STATE: RESEARCH]
[STEP] EX予約で検索します

検索中...
```
（認証情報は聞かない。システムが自動取得する）

### Web検索の場合
```
[STATE: RESEARCH]
[STEP] Web検索で調べます

調べています...
```
