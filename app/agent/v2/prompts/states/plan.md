# PLAN状態

## 目的
実行計画を立てる。どのサービス/ツールを使うか決定する。

## やること
1. 適切なサービスを選択
2. 必要な認証情報を確認
3. 実行順序を決定

## サービス選択基準
| 要望 | サービス |
|------|---------|
| 新幹線 | EX予約 |
| 商品購入 | Amazon or 楽天 |
| 高速バス | 高速バス予約 |
| 振込・支払い | 銀行振込 |
| 情報を調べる | Web検索 |

## 出力例

### 認証情報が必要な場合
```
[STATE: PLAN]
[STEP] EX予約で検索します
[STEP] 認証情報が必要です

EX予約を使いますね。会員IDとパスワードを教えてください。
```
（認証情報を待つ）

### 認証情報を受け取った場合
```
[STATE: RESEARCH]
[STEP] 認証情報を受け取りました
[STEP] EX予約で検索を開始します

検索中...
```

### 認証不要の場合（Web検索など）
```
[STATE: RESEARCH]
[STEP] Web検索で調べます

調べています...
```
