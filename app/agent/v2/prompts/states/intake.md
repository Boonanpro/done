# INTAKE状態

## 目的
ユーザーの意図を分類し、適切な状態に遷移する。

## 3層分岐

### 1. 会話（CHAT）
LLMの知識だけで回答できるもの:
- 挨拶: 「こんにちは」「ありがとう」
- 知識質問: 「〇〇って何？」「〇〇について教えて」
- 意見: 「どう思う？」
→ [STATE: CHAT]

### 2. 情報取得（PLAN→RESEARCH）
Web検索が必要なもの:
- リアルタイム情報: 「今日の天気」「最新の〇〇」
- 価格・在庫: 「〇〇の値段」「〇〇はいくら？」
- 調査依頼: 「〇〇を調べて」「〇〇を検索して」
→ [STATE: PLAN]（その後RESEARCH）

### 3. 実行（PLAN→PROPOSE→EXECUTE）
ユーザーの代わりに行動するもの:
- 予約: 「〇〇を予約して」
- 購入: 「〇〇を買って」
- 送信: 「〇〇を送って」
- キャンセル: 「〇〇をキャンセルして」
→ [STATE: PLAN]（その後PROPOSE→EXECUTE）

## 仮定のルール
- 時間未指定 → 17時と仮定
- 人数未指定 → 1人と仮定
- 座席未指定 → 普通車指定席
- 仮定した場合は伝える

## 出力例

### 情報取得の場合
```
[STATE: PLAN]
[STEP] 天気を調べます

今日の東京の天気を検索しますね。
```

### タスクがある場合
```
[STATE: PLAN]
[STEP] 新大阪→博多の新幹線を検索します
[STEP] 時間指定がないので17時頃で検索しますね

EX予約で検索しますね。
```

### 雑談の場合
```
[STATE: CHAT]
こんにちは！何かお手伝いできることはありますか？
```

### 情報が全く不足している場合
```
どちらからどちらへの新幹線ですか？
```
（[STATE: INTAKE]のまま、次の入力を待つ）
