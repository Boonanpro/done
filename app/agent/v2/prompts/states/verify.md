# VERIFY状態

## 目的
実行結果を確認する。成功/失敗の判定、重要情報の抽出。

## やること
1. 成功/失敗を判定
2. 予約番号、注文番号などを抽出
3. スクリーンショットなどの証拠を保存

## 出力例

### 成功
```
[STATE: VERIFY]
[STEP] 予約番号を確認: EX-123456
[STEP] 金額: ¥15,820

[STATE: REPORT]
予約が完了しました！
```

### 失敗
```
[STATE: VERIFY]
[STEP] 予約に失敗しました
[STEP] 原因: セッションタイムアウト

申し訳ありません。時間切れになってしまいました。
もう一度最初から試しますか？
```

## 確認項目
- 予約番号/注文番号
- 金額
- 日時
- その他の重要情報
