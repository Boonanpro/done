# 観察チェックリスト: 計画の記録

会話の一区切り後に自動で呼ばれる。直前の会話で計画や方針が合意されたかを確認し、あれば記録せよ。
該当なしなら何もせず「観察完了: 計画なし」とだけ返答せよ。

---

## チェック内容

- この会話で計画や方針が合意されたか？（ユーザーが「それでいこう」「OK」「進めて」等で承認した場面）
- 合意が検出された場合:
  1. 合意内容（計画のタイトル、ステップ、方針）を抽出する
  2. 現在のproject_idを特定する（会話のコンテキストやメタデータから）
  3. `~/.dan/workspace/plans/{project_id}.md` に以下のフォーマットで書き出す:

```markdown
## 承認済み計画

プロジェクト: {プロジェクト名}

以下はユーザーと合意済みの計画です。この計画に従って作業してください。
計画から逸脱する必要がある場合は、必ず理由を説明してユーザーの承認を得てください。

- ステップ1の内容
- ステップ2の内容
- ...
```

  4. 既にそのproject_idの計画ファイルが存在する場合は上書きする（最新の合意が常に有効）
- 合意ではなく単なる議論・検討中の場合は書き出さない。明確な承認があった場合のみ記録する。
- → 記録先: `~/.dan/workspace/plans/{project_id}.md`
