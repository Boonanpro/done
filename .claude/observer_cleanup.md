# 観察チェックリスト: 記録の整理

1日1回、自動で呼ばれる。RULES.mdとスキル内learned.mdの内容を整理する。
変更がなければ何も返答せず終了。（「変更なし」等の返答も不要）

---

## 手順

### 1. 現状を読み込む

以下のファイルをすべて読む:
- `~/.dan/workspace/RULES.md`
- `.claude/skills/design/learned.md`
- `.claude/skills/studio/learned.md`
- その他 `.claude/skills/*/learned.md` が存在すれば読む
- `.claude/skills/*/SKILL.md`（手順5で使用）
- `.claude/skills/*/actions/*.md`（手順5で使用）

### 2. RULES.md → スキルのlearned.md への移動

RULES.mdの各ルールについて、以下の手順で1つずつ評価する。

**手順: ルールごとに以下を判断する。**

1. このルールは**特定のスキルを使う時だけ**必要か？ → 該当スキルのlearned.mdに移動
2. **ダンの全ての振る舞いに常に適用**されるべきか？ → RULES.mdに残す

移動先の判断:
- デザイン・UI・HP・提案書に関する学び → `.claude/skills/design/learned.md`（該当セクションA/B/Cに振り分け）
- 動画制作に関する学び → `.claude/skills/studio/learned.md`
- その他のスキルに関する学び → `.claude/skills/{該当スキル}/learned.md`（なければ作成）

**迷ったら移動する。** RULES.mdは常にコンテキストに注入されるのでコストが高い。learned.mdはスキル実行時だけ読まれるので、移動しても忘れることはない。

移動時の作法:
- learned.md側の既存フォーマット（仮説パターン H{番号} 形式）に合わせて追記する
- RULES.mdから該当ルールを削除する
- 経緯（「なぜこのルールができたか」）も一緒に移動する

### 3. 重複の統合

**統合してよいもの:**
- 完全に同じことを言っているルール同士（表現が違うだけで場面も行動も同一）

**統合してはいけないもの:**
- 抽象ルール + その具体例のペア。抽象ルールだけでは具体場面で守れないから具体ルールが追加された経緯がある。両方残す。
  - 例: 「質問に即座に答える」と「URLを聞かれたら即座に出す」→ 統合禁止。URLの方は具体場面で繰り返し指摘された結果追加されたもの。

統合時の作法:
- 個別の経緯は代表的なものを1つだけ残す
- 統合したことをサマリーに含める

### 4. 陳腐化ルールの削除

以下に該当するルールは削除する:
- **前提が崩れている**: ソースコードを確認し、ルールの前提となる構造・実装が既に変わっている
- **コードで対策済み**: ルールが警告している問題がコードレベルで解決されている
- **アクションが曖昧**: 具体的な行動指針が一切なく「注意する」「気をつける」だけで終わっているルール。ただし「〜の場合は〜する」という具体的な条件+行動が書かれていれば、見出しに「注意」が含まれていても削除しない

削除前に必ずコードを読んで確認すること。推測で削除しない。

### 5. スキルファイルの具体/抽象バランスチェック

`.claude/skills/*/SKILL.md` と `.claude/skills/*/actions/*.md` の内容について、ルール・ガイドライン部分が特定案件に不当に偏っていないかチェックする。

**チェック対象**: ルール、手順、ガイドライン、判断基準として書かれている部分
**チェック対象外**: 具体例・参考事例として書かれている部分（例は特定案件に寄っていて正しい）

**判断基準**:
- そのルールやガイドラインを、全く別の案件（例: HP制作、SaaS開発、動画制作など異なるジャンル）に適用しても意味が通るか？
- 通らない場合、特定案件の文脈が混入している。汎用的な表現に修正する

**修正の作法**:
- 自動で修正する。ただし元の意図を変えない
- 具体例として残すべき部分は「例:」の形式にして残す
- 修正したことをサマリーに含める

## 記録のルール

- 何も変更しなかった場合: 何も返答せず終了
- 変更した場合のみ: 日本語箇条書き3行以内で要約を返答
  - 例: 「- RULES.mdから2件をdesign/learned.md(セクションB)に移動」「- RULES.md内の重複3件を1件に統合」
