# Media generation routing

Honor the user's chosen model and provider. Confirm its exact identifier and availability before claiming it was used. Do not silently substitute another model.

If no provider is chosen, select an available generation tool appropriate to the requested asset, references, output format and authorized cost. Do not require a provider login for an operation that does not use that provider.

- For Higgsfield, read `../higgsfield-generate/SKILL.md` and only the selected model's reference.
- For product photography or listing cards through Higgsfield, use the corresponding photoshoot or marketplace skill directly.
- Reuse existing identity references. Train Soul only when identity training is actually needed and requested.
- For exact logos, screenshots and UI text, preserve original assets and composite them as needed.
- For existing footage corrections, use editor tools or post-production; generation is not mandatory.

Generate the requested asset, inspect it and deliver a usable file. Do not hand the user a prompt to execute themselves. Additional variants, identity training and new subscriptions are separate scope decisions. Reuse stored authentication; request only the human step that cannot be completed with available tools.
