# 売り方のパターン

YouTube から LINE（とメール）に集めて、高い商品を売る流れを、パターンごとにまとめた物。台本・LINE の配信文・LP・メールを書く前に読み、書く物が流れのどこにあるかを決める。

使い方：台本の「◎前提と狙い」の2行目に書いた「パターンの名前と何本目か」の欄を開く。その欄の「見る人がもう知っていること」「話すこと」「言わないこと」「見た後の行動」を作業メモに写し、書いている間はそれに従う。台本には写さない。

材料はえるさんのローンチ（2022〜2026年の0〜5期と、会社向けの代行の募集2回）の台本・LINE の配信文・LP・日程表と、おさるさんの講座。出どころは最後の節。

## 1. どのパターンにも通る決まり

どの決まりも「次の段階に進む人を、前の段階で選ぶ」ことから出ている。段階ごとに、見る人がそこまでに知ったことと、次にしてもらう1つの行動が決まっていて、その行動をした人だけが次の段階に進む。

1. **高い商品は、興味を示した人にだけ案内する。** LINE の登録者全員にいきなり高い商品を出すと、「金に走った」と反発され、通報で LINE が止められる。買えない人は買えない理由を正当化して離れる。だから案内の前に「興味ありますか？」のボタンを挟み、押した人だけを次へ進める。
2. **金額は、受けたいと決まった人にだけ出す。** 1本目の動画では金額を言わない。えるさんの理由は「興味がない人に金額を伝えても意味がない」「動画は1人で見ているので、一瞬で無理な理由を考えてしまう」。審査に通った人への動画（2本目）で、相場と比べてから出す。審査フォームを書き、合格までした人は「ここまでやったのに受けないのはもったいない」と感じる。例外は2つ。前回の案内で中身をもう知っている人への再募集（4の B）と、相手の売上に連動した値段で売る会社向けの代行（4の C）。
3. **次の段階が解決する悩みは、前の段階で解決しない。** 特典動画は役に立つ内容で信用を作るが、商品が解決する所は「長くなるので今回は話さない」と予告して残す。無料で解決したと思わせると、商品の案内を聞く理由が消える。
4. **LINE は顧客管理に使い、定期配信しない。** LINE で送るのは、登録時の振り分け、特典の受け渡し、ローンチの案内だけ。めったに連絡しない人から来た連絡は読まれ、毎週来る連絡は聞き流され、そのたびにブロックの機会になる。長い教育はメールで送る。
5. **特別扱いと限定を言葉にする。** 「最後まで見た人だけを抽出して送っています」「VIP 専用」「全員僕が直接やり取りをします」「審査制」「この内容での募集は最初で最後」。誰でも買える物は売れないので、見る人が選ばれた側だと分かる言葉を、案内の最初の連絡から入れる。
6. **小さな行動を重ねてもらう。** 感想フォーム、ボタン、審査フォーム、面談の希望日。行動を重ねた人は、自分は受けるつもりだから行動したと考えるようになる。ただしフォームは選択式を中心にし、自由に書く欄は2つまでにする（重いと、買うはずだった人が途中でやめる）。
7. **念押しは、まだ行動していない人にだけ送る。** 押した・見た・出したを記録し、まだの人にだけ、その人の状態を言い当てて（「リンクは押したけど、最後まで見ていない…ということもあると思います」）、期限で失う物を言う。もう行動した人には、申込が多く盛り上がっていることと、次の日時を送る。案内専用の LINE では念押しを重ねてもブロックはほとんど出ない（0期は念押し中のブロック0件）。
8. **この段階まで自分が話してきた言葉を、次の段階の納得に使う。** 特典動画や YouTube で「広く浅くではなく、狭く深い関係を作りたい」と言っておくと、高い少人数の案内が来た時に「前から言っていたこと」になる。

## 2. 全体の流れ

```
YouTube 動画 → LINE 登録（合言葉）→ 名前とメールの登録 → 特典動画（期限つき）→ 感想フォーム
   ここまでが「入口」。いつも動いている
→ 興味ありますか？ → 準備の様子 → 日時の告知 → 案内専用の LINE へ → 1本目の動画 → 審査フォーム
→ 審査の様子 → 合格の通知と2本目の動画（金額）→ 申込・面談 → 終わりの挨拶
   ここからが「ローンチ」。期間を決めて1回ずつやる（エバーグリーンローンチでは、同じ流れを登録した日から一人ずつ自動で流し、期限も一人ずつ付ける）
```

## 3. 入口（いつも動いている部分）

| 段階 | 見る人がもう知っていること | 話すこと | 言わないこと | 見た後の行動 |
|---|---|---|---|---|
| YouTube 動画 | タイトルとサムネだけ。話し手は知らない | 悩みの代弁、見た後の結果、なぜこの人か、やり方。本編の山場の後に LINE の特典を短く1回 | 商品・金額・販売の予告 | LINE で合言葉を送る |
| LINE 登録直後の自動返信 | 動画1本と特典の名前 | 名前を呼んだお礼、特典の受け取り方。次に何か（セミナーなど）があるなら「このLINEで先に案内する」と予告だけ | 商品の中身・金額 | 特典を受け取る（名前とメールを入れる） |
| 特典動画（[型](references/line-gift-video.md)） | 話し手と特典のテーマ | 役に立つ核心のやり方を1つ、具体的に。深い所は「今回は話さない」と2〜3回予告して残す。締めで「準備中のサービスがある。一部の人に先に案内するかもしれない」「狭く深い関係」 | 商品名・金額・日程・申込の方法。商品が解決する所の答え。「今日で解決」と思わせる言葉 | 感想フォームを出し、最後まで見た人だけが分かる選択肢を選ぶ |
| 特典の念押しのメール | 特典を受け取ったこと | 期限（5日など）、倍速なら何分で見られるか、一定時間見た人への追加特典。送るのは約30分後・翌日・2日後・期限の前日・当日の朝で、2日後と前日はスタッフの名前で「まだ見ていない人にだけ」の形 | 販売の話（「セールスは一切ない」と言い切る） | 特典動画を最後まで見る |
| 感想フォーム | 特典動画の中身 | 満足度、感想、隠しの選択肢、今後の案内への興味のチェック | — | 出す（ここで出した人が、ローンチで最初に案内する相手になる） |

登録時に、性別・学生かどうか・どの動画から来たか（合言葉）を取っておく。ローンチの案内を送る相手をここで絞る（高い商品なので学生は外す、など）。

## 4. パターン

### A. 審査制ローンチ（初めて案内する人へ）

使う場面：本人の変化を売る高い講座・コンサル（えるさんは49.8万円＋税）を、LINE に登録している人に初めて売る時。えるさんの0〜3期と5期。0期は特典の感想を出した709人に興味を聞き、447人が「興味がある」を押し、69人が買って3,800万円売れた。

日程はえるさんの日程表のとおり。興味を聞いてから合格の通知まで、およそ2〜3週間。

| 段階 | 届け方と時期 | 見る人がもう知っていること | 話すこと | 言わないこと | 見た後の行動 |
|---|---|---|---|---|---|
| ① 興味ありますか？ | メインの LINE。期限つき。押していない人へ前日と当日に念押し | 特典動画と話し手 | 「突然の個別 LINE」、なぜこの人に送っているか（感想を出した・最後まで見た）、少人数の募集をすること、「全員僕が直接やり取りをします」、「現時点で伝えられるのはここまで」 | 金額・期間・中身の詳細・日程 | 「興味がある」を押す |
| ② 準備の様子 | 押した人へ。①の3〜5日後 | 自分が「興味がある」と押したこと | 想像以上に良い内容になったこと、案内の動画を撮り終えたこと | 中身・金額 | 待つ（日時の告知を楽しみにする） |
| ③ 日時の告知 | 押した人へ | ②まで | 動画を送る日時、「この内容での案内は最初で最後」、どんな人に良い機会か | 中身・金額 | 日時を覚えておく |
| ④ 案内専用の LINE へ | ③の数日後（0期は3日後）。押していない人へ当日・前日・12時間前・5時間前・1時間前に念押し | ③まで | 「VIP 限定」、3日だけの公開、審査制にした理由（手厚すぎて応募が殺到するから） | 金額・中身 | 案内専用の LINE を追加する |
| ⑤ 1本目の動画 | 追加した時に自動で届く。審査フォームの締切は3日後。締切までに土日を入れる | 話し手、案内が限定であること | 悩みの共感 → 独学では時間がかかる → 恥ずかしい過去 → 自分では気づけない → 課題は少数（えるさんは4つ）→ 理想の未来 → 商品とサポートの中身 → 特典 → 審査制と、金額は合格者にだけ伝えること → 締切と合格発表の日時 | **金額・支払い方法・分割**（「相場を壊す値段」とにおわせるだけ）。合格者だけの特典 | 審査フォームを出す（「受けたいじゃなくていい。興味があれば」） |
| ⑥ 審査の様子 | 出した人へ（フォームに書いた名前で）。出していない人へは締切の12・5・1時間前の念押し | 1本目の中身 | 予想を超える数が出していること、一人ずつ読んでいること、合格発表の日時、「合格者だけへの動画の原稿が長くなった」 | 金額 | 合格発表を待つ |
| ⑦ 合格の通知と2本目の動画 | 締切の2〜3日後。申込の期限は3日。まだ選んでいない人へ前日・当日・3時間前・1時間前に念押し | 1本目の中身、自分が審査に通ったこと | 合格の祝福と、フォームの悩みへの一言 → 絞り込んだ割合（「総フォロワーの0.01%」）→ 中身の振り返り → 動画で金額を言う理由 → 相場 → 金額（月額 → 総額の順）→ 1本目で言っていない特典 → 支払い方法 → お断りする人 → 3日だけ | — | 3つのボタンから選ぶ（受ける・面談で相談する・辞退する）。「辞退する」の言葉にして、やめることを重く感じさせる |
| ⑧ 面談 | 締切から1週間〜10日のうちに（気持ちが冷める前に） | 金額とサポートの中身 | 不安に淡々と答える。受けたい理由となりたい姿を聞く。最後にサポートと振込を確かめる | 売り込み（「僕からセールスをすることは一切ありません」）。悩んでいる人には「悩んでいるなら辞めた方が良い」と言ってよい | 振り込む |
| ⑨ 終わりの挨拶 | 案内専用の LINE の全員へ | 全部 | お礼、「狭く深い関係を作る約束の第一歩」、受けなかった人にも何か用意すること | 次の販売 | — |

期ごとの違い（同じ骨組みに足せる物）：

- 3期：1本目を LP に置き、動画の下に審査フォームと残り時間を置いた。締切を2回、1日ずつ早めた。「YouTube 復活の前の最後の案内」という期限の理由を付けた。
- 5期：動画をどこまで見たかで念押しの文を分けた（30%以上見た人には「自分なんかが応募していいのか」の不安を消す文、30%未満の人には「10分だけ時間ないでしょうか」）。面談をやめ、2本目の LP のボタンから直接申し込む形にした。金額は24回の分割で月額と1日あたりの額から見せた。
- 0期：特典の感想を出した人だけに絞った（プリローンチ）。1期からは LINE の登録者の中から性別・学生・前回の行動で絞った。

### B. 再募集（前回の案内で興味を示した人へ）

使う場面：A を一度やった後の次の募集で、前回案内の LINE に入った人と審査に通った人のうち、今回の「興味ありますか？」で「興味がある」を押した人へ送る。新しい人への1本目より先か同じ時期に送り、締切は新しい人と同じにする（えるさんの1期・2期）。2期では「枠が余ったらメインの LINE に回す」と言った。

| 段階 | 見る人がもう知っていること | 話すこと | 言わないこと | 見た後の行動 |
|---|---|---|---|---|
| 募集の動画（1本） | 話し手と、前回の1本目で聞いた悩みの話と商品の中身。前回の金額を知っているのは、合格して2本目を見た人だけ | 優先して受けられる理由（「1秒でも早く行動し、早くから信頼してくれた人に」）→ 前回の受講生の成果と満足度の数字 → 前回から変えた所と理由 → 前回断った理由への答え（えるさんは「9割が今お金が無い」だったので、カードの12回払いを足した）→ 金額と支払い方法（前回の金額を知らない人もいるので、5の順番で出す）→ 締切 | 悩みの共感・恥ずかしい過去・不安を大きくする段（前回聞いている）。審査（無い） | 申込フォームを出す（その後に30分の面談） |

### C. 成果報酬の募集（会社や発信者に、売上を上げる代行を売る）

使う場面：買う人が自分の売上のために払う物（ローンチの代行・コンサル）を、売上に連動した値段で売る時。

- **金額を最初から言う。** 安い着手金と「売れた後に一度だけ」が、損をしないという売り文句そのものになっているから。えるさんの「ローンチ丸投げ」は LINE の1通目で「着手金9.8万円（税別）と売れた後のレベシェアだけ」と書き、「興味がある」を押させ、期限まで2回念押しした。決済のリンクは LINE に流さない。
- **信用の材料は売上の数字にする。** 「0期は709人中447人が興味を示し、3,800万円」「興味がある1人あたり平均約67,000円」のように、相手が自分の名簿に当てはめて見込みを計算できる形で言う。本人の変化を売る A とは、ここが違う。
- **中身の一部を見せる。** えるさんの「2024年ローンチコンサル」は、事前に審査を通った人に1本の動画で、売る流れの全体と LINE の4段をそのまま見せ、「言っていない重要な所がかなりある」で止め、サポート・金額・審査フォームへ進めた。見せたやり方そのものが、腕の見本になる。
- **相手を絞る条件を先に言う。** 「名簿を一定数持っている人だけ」「恋愛系は今回は外している」。

## 5. 金額を出す順番（A の2本目・B の募集）

えるさんの「金額の伝え方」と0〜5期の2本目に共通する順番。

1. 動画で金額を言う理由（「動画では金額を言わないのが鉄則。でも、この金額で無理だと思うなら本気じゃない」）
2. 世の中の相場（同じ分野の講座、有名なジムの料金を期間に合わせて直した額）
3. サポートを1つずつ金額にして合計する（えるさんの例では341万〜465万円）
4. 感謝や理念を理由に、大きく下げる（2段階で下げることが多い）
5. 分割した月額か1日あたりの額 → 総額の順で言う
6. 元が取れる計算と、安くできる理由（オフィスや広告にお金をかけていない）
7. 1本目で言っていない特典を重ねる
8. お断りする人、締切

安すぎる値段は付けない（「5万円や10万円で人生は変わらない。覚悟が生まれない」）。

## 6. まだ見本が無い売り方

次の2つは、見本の資料がまだ無い。書く必要が出たら、売れている同じ形の物を2つ以上読んで、この資料に欄を足してから書く。

- **エバーグリーンローンチ**：ローンチの流れを、見込み客一人ひとりが LINE やメールに登録した日を起点に、決まった順番で自動配信する形。全員が同じ日に始まるローンチと違うのは始まる日だけで、フォームの提出や申込には「登録から◯日後まで」のように一人ずつの期限を同じように付ける。いつでも買える形ではないので、台本でも期限と限定の言葉は削らない。中村ひろきさんの今の販売がこの形。
- **セミナー型**：無料のセミナーやオープンチャットに集めて、その場で売る形。えるさんの2026年11月のセミナーの先行案内（入口の自動返信で予告している）と、おさるさんのセミナー（LINE・メール・SMS の3つで案内し、SMS で参加率が約10%上がった）が手がかり。

LINE を何個に分けるか（えるさんはメインと案内専用の2つ、おさるさんは集める・売る・申込者を守るの3つにメールと SMS）は、`dan-workspace/marketing-reference/line-multi-account-design.md`。

## 7. 前提の3行の書き方の例

特典動画：

- 見る人：YouTube から LINE に登録し、名前とメールを入れた人
- 売り方とこの動画の場所：入口の特典動画
- 見た後にしてもらうこと：感想フォームで隠しの選択肢を選んで出す

審査制ローンチの1本目：

- 見る人：特典の感想を出し、「興味がある」を押して案内専用の LINE に移った人
- 売り方とこの動画の場所：審査制ローンチの1本目（⑤）
- 見た後にしてもらうこと：審査フォームを出す

審査制ローンチの2本目：

- 見る人：1本目を見て審査フォームを出し、合格した人
- 売り方とこの動画の場所：審査制ローンチの2本目（⑦）
- 見た後にしてもらうこと：「受ける」か「面談で相談する」を押す
