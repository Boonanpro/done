# 1文ずつの書き換え

どの型の台本でも、書き終えた後と直しを受けた時に、私が書いた文を1文ずつ見直すために読む。型（話の順番と各段の技）は型のファイルが先に来る。本人が書いた文は書き換えの対象にしない（[SKILL.md](SKILL.md) の「本人の言葉を残し、平均的な言い方に寄せない」）。

台本のゴールは、見た人に「自分の悩みを解決できるのはこの人だ」と確信してもらうこと。文が分かりやすいだけだと、見た人は満足して終わる。1文ごとに、見る人が次の文を聞く理由があるかで直す。

元にした物：える（YouTubeプロデューサーL）の特典動画「100再生→10,000再生 YouTube台本 超添削」（文字起こしは `dan-workspace/marketing-reference/youtube-producer-l/videos/`）と、そのビフォーとアフターの台本（`docs/特典_解説ドキュメント/超添削_ビフォーアフター.docx`）、える会員サイト「YouTube MASTER KIT」の「視聴者の心を動かすライティング」の章（`master_kit/lessons/32〜47`）。抜き出しの全文は `dan-workspace/script-craft/える台本添削_抽出.md`。読み取りの記録は `sources/generalization-log.md` の 2026-10-29 の項。

YouTubeの型にある技（1行目の代弁・見た後の結果・「なぜなら」・指示語を使わない・2択）は、ここに重ねて書かない。各技の「目印」は、書き上がった台本を見て、その技を使ったかを判定する所。「保留」は出どころが1か所だけの技で、本人の台本で使って合格したら外す。

## 技

### 1. 弱気な言葉を消して言い切る
- 何を：「少し」「以前よりは」「〜かもしれません」「〜も関係するけど」「ある程度は」
- どこに：主張・結果・手軽さを言う文
- どういう形で：弱気な言葉を消して言い切る。手軽さは「たった〜だけ」「一切」を付け、時間か手順の数で言う（「この動画を見終わる頃には」より「このたったの32分の動画を見るだけで」）
- なぜ効くか：言い切られると、見る人は話し手が自信を持っていると感じ、自分にもできそうだと思って残る
- 良い例：「センスや性格は一切関係なく、たったの3ステップだけで、誰でも身につきます」
- 悪い例：「センスや性格も関係しますが、練習すればある程度は上手くなるかもしれません」
- 目印：主張の文に上の5つの言葉が1つも無く、手軽さの文に数字がある
- 出どころ：超添削の「再現性の提示」「ベネフィットの提示」の書き換え

### 2. 何も言っていない文を消す
- 何を：次の4つの形の文。①疑問文で、見る人全員の答えが「はい」になる文 ②具体的な行動が入っていない励まし ③「今回の動画では〜をお話しします」の概要 ④「お願いします」
- どこに：全文。特に冒頭と、段の終わりのつなぎ
- どういう形で：消しても次の文の意味が変わらないかを確かめ、変わらなければ消す。言いたいことが残る時は、具体的な場面か行動の文に置き換える
- なぜ効くか：何も起きない文が1つあるたびに、見る人はこの動画を見続ける理由を1つ失う
- 良い例：「大切なのは勇気を出して一歩踏み出すことです」を消し、次の体験談にそのままつなぐ
- 悪い例：「仕事でもプライベートでも、会話が上手い人は得をすることが多いと思いませんか？」を残す
- 目印：台本に①〜④の形の文が無い
- 出どころ：超添削の「掴み」「言い訳への対応」の書き換え、会員サイト「刺さる一言」（冒頭の概要は3秒の無音と同じ）

### 3. 悩みは相反する2つの気持ちで言い当てる
- 何を：見る人の悩み
- どこに：悩みを言う段（YouTubeなら冒頭の代弁の後、LINE特典なら共感の段）
- どういう形で：「〜したいと憧れる気持ち」と「でも自分には〜が身の丈だと諦める気持ち」の2つを、見る人の心の声を「」に入れて並べ、「この2つで苦しんできたはずです」で受ける。「〜で悩んでいませんか？」「気持ちは分かります」は使わない
- なぜ効くか：自分でも言葉にしていなかった気持ちを2つに分けて言われると、見る人は「この人は本当に分かっている」と思う
- 良い例：「あんな風になれたら人生楽しいだろうなって憧れる気持ちと、『いやさすがに、自分はそういうキャラでもないし』って諦める気持ち。この2つで苦しんできたはずです」
- 悪い例：「複数人での会話が苦手で、黙ってしまった経験はありませんか？私もそういう経験があるので、気持ちは分かります」
- 目印：悩みの段に、向きが逆の気持ちが2つ「」付きで並んでいる
- 出どころ：超添削の「悩みの言語化」の書き換え、会員サイト「悩みへの共感」

### 4. 見た後に起きることを、場面とセリフで上まで言う
- 何を：この動画のやり方を使った後に、見る人に起きること
- どこに：冒頭の結果を言う所と、本編の最後
- どういう形で：3段で上げる。①悩みが消える（「二度と〜しなくなる」）②周りの人に言われるセリフ（「」で書く）③人から相談される・頼られる。どれも場面が浮かぶ言葉にする。胡散臭くなる所は1段下げる
- なぜ効くか：悩みが消える所で止めると見る人の気持ちは少ししか動かない。周りに言われる自分まで想像できると、そのために最後まで見る
- 良い例：「二度と冷や汗をかいて固まることはなくなります。それどころか『今日の会、あなたがいたから一番楽しかった』って言われて、会話について人からアドバイスを求められるのも時間の問題です」
- 悪い例：「悩みが少し解消されて、人間関係がより良くなるかもしれません」
- 目印：結果の段に、周りの人が言う「」のセリフが1つ以上ある
- 出どころ：超添削の「ベネフィットの提示」の書き換え、会員サイト「ベネフィットの再提示」（目線を上げる）

### 5. 疑いを先回りして答える
- 何を：言い切った直後に、見る人が思う「でも〜でしょ」
- どこに：言い切った結論や結果の直後の1〜2文。YouTubeの型では本編の「言い切りと反論の代弁」がこれにあたるので、そこでは型の技を使い、ここでは冒頭とLINE特典など型にその段が無い所で使う
- どういう形で：「でも、〜って思いましたよね」と疑いを言い、手順の数・かかる時間・誰でもできる理由で答える
- なぜ効くか：浮かんだ疑いに先に答えられると、見る人は疑ったまま離れずに続きを聞く
- 良い例：「でも、それって才能ある人の話でしょって思いましたよね。具体的な手順があって、たったの3ステップだけです」
- 悪い例：言い切った後に疑いに触れず、次の話題に移る
- 目印：言い切りの次の文が、見る人の疑いの言葉になっている
- 出どころ：超添削の「再現性の提示」「言い訳への対応」の書き換え

### 6. 裏づけは「実は」と、ありそうな言い方で
- 何を：主張を支える事実
- どこに：結論を言った後の裏づけの文
- どういう形で：「実は」で、見る人が知らなかった事実として言う。「全員が知ってやっている」のような言い切りすぎは「知ってか知らずか、全員〜を使っていただけ」のように、本当にありそうな形にする
- なぜ効くか：知らなかった事実は驚きになり、ありそうな言い方なので嘘っぽく聞こえない
- 良い例：「あなたが見てきた会話上手な人たちは、実は、知ってか知らずか全員、特定の法則を使っていただけなんです」
- 悪い例：「彼らも無意識のうちに、基本的な法則を使っていることが多いのです」
- 目印：裏づけの文に「実は」があり、「全員が知っている」の形が無い
- 出どころ：超添削の「再現性の提示」の書き換え（特典動画 20:24）

### 7. 理由は「なぜ」を最後まで掘って、最後の答えを先に言う（保留）
- 何を：結論の理由
- どこに：結論の直後
- どういう形で：結論に「なぜ」を、見る人の誰もが知っている事実（体の仕組み・本能・お金の計算）に着くまで重ねる。一番深い答えを「なぜなら〜」で先に言い、その後で掘った順に浅い方からたどる。たどる時は、前の文の言葉をそのまま次の文の主語にする
- なぜ効くか：先に深い答えで驚き、たどる間に筋が通るので、驚きと納得が同時に来る。前の言葉を受けてつなぐと、耳で聞いても迷わない
- 良い例：「なぜなら、女性の生存本能として、謙虚すぎる人は受け付けないからです。謙虚すぎる人は、自信がなさそうに見えます。自信がなさそうに見えると、頼りなく見えるんです。頼りなく見える人を、女性は好みません」
- 悪い例：「謙虚すぎると自信がないように見えるからです。それはモテない原因になります」
- 目印：理由の段の各文が前の文の言葉で始まり、「それは」「これは」で始まる文が無い
- 出どころ：会員サイト「納得感のある理由」（掘り方とバックトラッキング）。1か所だけ

### 8. 気持ちを上げ下げする
- 何を：見る人の気持ち
- どこに：冒頭の共感の後と、本編で同じ調子の段が3つ以上続いた所
- どういう形で：共感させた直後に一度突き放し（「あれは才能です」）、次の文で味方に戻る（「……って、僕も思いたかったんですよ」）。焦らせた直後に「でも大丈夫です」で救う形も同じ。場面を見せたい所では「ちょっと想像してみてください」と言ってから場面を言う
- なぜ効くか：次の文が予想と違うと、見る人は次も聞きたくなる。一度下げてから上げると、上げるだけより気持ちが大きく動く
- 良い例：「ああいう人はもう才能です。……って、僕も思いたかったんですよ」
- 悪い例：「ああいう人にも、実はコツがあります」（予想どおりの文が続く）
- 目印：冒頭に、前の文を打ち消す文が1つある
- 出どころ：超添削の掴みの書き換え、会員サイト「一言でベネフィットを提示」（一度−10に落としてから＋10を見せると20動く）

### 9. 体験談は、見る人と同じ性格の行動と、見る人が自分で認められる言葉で
- 何を：話し手の昔の体験
- どこに：型が体験を置く段（1か所だけ）
- どういう形で：見る人と同じ性格を、形容詞ではなく具体的な行動で言う（「あらゆる会へのお誘いも秒で欠席申請する」）。見る人を指す言葉は、①見る人を一言で表す強い言葉（陰キャ・非モテ・貧乏）を書き出し、②見る人が人前の自分では否定するが本音では当たると思う形に変える（「隠れ〜」「根は〜」「普段は〜だけど、〜の時だけ〜」）。うまくいった後も、すぐ完璧にはならなかったことを1文入れる。数字は見る人に現実的な大きさにする
- なぜ効くか：自分と同じ人の話だと思えると、自分にもできると信じる。うまくいきすぎていない話は本当に聞こえる
- 良い例：「かなり周りの目を気にするタイプで、会へのお誘いも秒で欠席申請する『隠れ陰キャ』でした。最初の1回目は完璧じゃなかったけど、数回で一切困らなくなりました」
- 悪い例：「元々は人前で話すのが得意な方ではありませんでしたが、このやり方ですぐに話せるようになりました」
- 目印：体験の段に、動詞で書いた昔の行動と、「最初は〜だったけど」の1文がある
- 出どころ：超添削の「体験談」の書き換え（特典動画 29:39 の言葉の選び方）、会員サイト「信憑性のある根拠」（自分の実体験が一番効く）

### 10. 結論は極端に言い切ってすぐ補足し、やることは1つの行動にする（保留）
- 何を：本編の結論と解決策
- どこに：本編の最初の言い切り
- どういう形で：普通と逆の結論を極端に言い切り、次の文で「厳密には〜」と補足する。解決策は、見る人が迷わずすぐできる1つの行動で言う（「小さいことから伝えてみたら？」ではなく「まず、分からないことを1つだけ質問してみたら？」）
- なぜ効くか：極端な言い切りで驚き、補足で筋が通る。行動が1つに決まっていると、見る人は見終わってすぐ動ける
- 良い例：「謙虚な人はモテません。厳密には、謙虚"過ぎる"人がモテないんです」
- 悪い例：「謙虚さも大事ですが、行き過ぎるとよくない場合もあります」
- 目印：結論の次の文が「厳密には」で始まり、解決策の文に行動が1つだけある
- 出どころ：会員サイト「目からウロコの結論」。1か所だけ

## 確認表

書き上がった台本で、各技の「目印」を上から確かめる。とくに次の4つは、えるさんが「AIの台本はすぐ分かる」と言って直した文と同じ形なので、1つでも残っていたら直す。
- [ ] 弱気な言葉（少し・以前より・かもしれません・〜も関係するけど）
- [ ] 型どおりの共感（〜で悩んでいませんか・気持ちは分かります）
- [ ] 答えが全員「はい」になる問いかけ（〜だと思いませんか？）
- [ ] 中身の無い励まし（大事なのは一歩踏み出すこと）
