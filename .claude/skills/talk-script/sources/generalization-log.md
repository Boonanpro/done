- 技: 次の6つ。形は thumbnail.md に「何を・どこに・どういう形で・なぜ効くか・良い例・悪い例」で書く。 1. 一番大きく見せる言葉を10文字以内に削る：言いたい語を全部書き出し、①同じことを別の言い方で言っている語と動画の中身に無い語を消し、②残りに順位を付け、③1位の語を一番大きい行（10文字以内）にし、補足の行を入れても全体で2〜3行までにする（たいき20枚の形）。 2. 文言は言い方を2つ以上重ねる：断定・命令、逆説、損失回避、数字と手軽さ（「たった1つ」「5分」）、ベネフィット（見た後の体験）、強調（「絶対」「確実」。広告や商品説明では使わない）から2つ以上を1枚に入れる。否定する文言を使う時は、代わりにやる行動をサムネかタイトルに入れる（保留）。 3. タイトルはサムネと別の言葉にする：サムネとタイトルを並べ、同じ語が両方にあればタイトル側を言い換え、タイトルには期限・誰の話か・何が分かるか・検索で打つ言葉を入れる。 4. 要素3つ・色3色までにして、一番の語を飛び抜けて大きくする：要素は文字・話し手の顔・話の物1つ。色は文字の塗りの色で数え（黒い縁は数えない）、3色まで。一番の語だけを強い色（赤か黄）にし、文字の高さを2番目の語の2倍以上にする。お金や専門家の話で信用を優先するチャンネルは1.5倍ほどにとどめる。 5. 文字は極太のゴシックに黒い太い縁を付ける：光彩・グラデーション・金属風は使わない。強調する語だけ白と黒の二重の縁にする（保留）。設定として、YouTubeは一覧でサムネの右下に再生時間を重ねるので、右下には何も置かない。 6. 出す前に4つ確かめ、文言だけ変えた3案を出す：①タイトルを隠して何の動画か分かるか（保留） ②上半分だけで気になるか ③一覧の大きさ（私の目安で幅360pxと168px）に縮めて同じ分野のサムネと並べ、目に留まるか ④動画の中に無いことを言っていないか。
