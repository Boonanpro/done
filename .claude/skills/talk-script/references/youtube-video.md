# YouTube動画の型

YouTubeで検索やおすすめから来た人に見せる、話す動画。目的は、最後まで見てもらい、チャンネル登録かLINE登録をしてもらうこと。

見る人がすでに知っていること：タイトルとサムネの内容だけ。話し手が誰か、信じてよい人かはまだ知らない。だから冒頭の1分で、見る理由と信じる理由の両方を渡す。ここがLINE特典の型と違う所で、LINE特典では冒頭で自分の話をしない。

元にした物：おさる（英語コーチ）のYouTube動画2本（「英語を速く読みたいなら英語は読むな」`2qB_pZidadI` 9分44秒、「英語学習の始め方はこの2冊だけでOK」`reQ7BpYIA0Q` 38分10秒）と、オンクラス「4-6 台本」の台本作成テンプレート（1本目の台本が見本として入っている）。2本は同じ順番で話している。読み取りの記録は `sources/generalization-log.md` の 2026-10-20 の項。

状態（2026-10-20）：本人の台本で合格した実例はまだ無い。最初の1本を書いたら、本人の判定とあわせてここに足す。

## 書く前に決めること

テーマ（タイトル・サムネの言葉）、見る人の今の思い込みか悩み、解決策（1つ）、見終わった時に手に入る結果（数字か場面）。この4つを「前提と狙い」のメモに書いてから書き始める。

## 話の順番

**冒頭（1分前後）**

1. 挨拶は名前だけ。
2. 今回のテーマを、タイトルの言葉で一言。
3. 見る人の思い込みを代弁する（技1）。
4. 話し手の昔の同じ失敗（技2）。
5. その考えのままだと起きる損（技3）。
6. 今日の方法で手に入る結果を、数字か場面で。
7. 話し手と教えた人の実績を数字で（技4）。
8. 登録の呼びかけは1文だけ。すぐ本題に入る。

**本編（話題ごとに繰り返す）**

9. 言い切りと反論の代弁で始める（技5）。
10. 根拠を、見る人の身近な場面か例で見せる。
11. 具体的なやり方（手順・数字・使う物）。
12. 結論を言い直す（技6）。

**終わり**

13. 励まし：見る人がもう他の人より進んでいることを言う（「今この動画を見ている時点で、〜なんてまずありえない」）。
14. 復習：結論を1文で言い直す（技6）。
15. LINE登録かチャンネル登録の呼びかけ。登録すると何が手に入るかを具体的に。
16. 挨拶は短く。

## 技

### 1. 思い込みを代弁する
- 何を：見る人が当たり前だと思っている考え
- どこに：冒頭、テーマの一言の直後
- どういう形で：「〜って思ってませんか？」「〜した方がいいって思いますよね？」の問いかけの1文。中身は、よく来る質問や、検索すると最初に出てくる答えから取る
- なぜ効くか：自分の考えを言い当てられた見る人は、その答えを知りたくて続きを見る
- 良い例：「寝る前にスマホをやめれば眠れる、って思ってませんか？」
- 悪い例：「今日は睡眠のコツを解説します」（見る人の考えに触れないので、聞く理由が生まれない）
- 出どころ：上の2本（2026-10-20）

### 2. 話し手の昔の失敗を言う
- 何を：話し手が同じ考えで実際にやって失敗した行動
- どこに：代弁の直後
- どういう形で：「僕も過去に〜していました」の1〜2文。行動は名詞ではなく、何をしていたかの動詞で書く
- なぜ効くか：話し手も同じ所でつまずいたと知り、見る人が自分にもできそうだと思う
- 良い例：「僕も3年間、夜9時以降はスマホを触らないようにしていました。でも寝つきは全く変わらなかった」
- 悪い例：「僕も昔は睡眠に悩んでいました」（何をして失敗したかが無いので、見る人の経験と重ならない）
- 出どころ：上の2本（2026-10-20）

### 3. 知らないと起きる損を言う
- 何を：その考えのままだと最後にどうなるか
- どこに：昔の失敗の直後
- どういう形で：期間か割合を入れた1文（「一生〜できない」「99%の人が〜でやめる」）
- なぜ効くか：見ないと損をすると感じて、離れにくくなる
- 良い例：「この考えのままだと、何年たっても眠れないままです」
- 悪い例：「睡眠不足は体に良くありません」（誰でも知っている一般論で、この動画を見る理由にならない）
- 出どころ：上の2本（2026-10-20）

### 4. 実績を数字で言う
- 何を：話し手の結果1つと、教えた人の結果1つ
- どこに：冒頭の終わり、登録の呼びかけの前
- どういう形で：どちらも数字を入れる（期間・人数・点数・割合）
- なぜ効くか：数字で「この人の話は聞く価値がある」と判断して、本編へ進む
- 良い例：「僕は今、布団に入って10分で眠れていて、相談に来た200人のうち8割が2週間で同じようになっています」
- 悪い例：「睡眠指導歴5年の僕が解説します」（年数は結果ではないので、信じる理由にならない）
- 出どころ：上の2本（2026-10-20）

### 5. 本編は言い切りと反論の代弁で始める
- 何を：普通と逆の結論と、それを聞いた見る人が言いそうな反論
- どこに：本編の最初、話題ごとに
- どういう形で：「いきなり結論なんですけど」で結論を1文で言い切る。次の1文で「〜じゃないの？って思いますよね」と反論を言う
- なぜ効くか：驚いた直後に浮かんだ反論を言い当てられるので、離れずに理由を聞く
- 良い例：「いきなり結論ですが、夜の過ごし方は関係ありません。起きる時刻を毎日同じにしてください。いや、休日くらいゆっくり寝たいよって思いますよね」
- 悪い例：「まずは起床時刻を固定しましょう。ほかにも、日光を浴びる、カフェインを控えるなどがあります」（言い切らず、反論にも触れないので、普通のまとめ記事と同じに聞こえる）
- 出どころ：上の2本（2026-10-20）

### 6. 結論を言い直す
- 何を：本編の結論
- どこに：本編の最後と、終わりの復習の2か所
- どういう形で：最初に言った時と同じ言葉で1文にする
- なぜ効くか：長い本編の後でも、何を持ち帰ればいいかが分かる
- 良い例：本編の最後と復習で「眠れるかは、起きる時刻で決まります」
- 悪い例：最後に「いろいろ話しましたが、できることから始めてみてください」（何を持ち帰ればいいかが分からない）
- 出どころ：上の2本（2026-10-20）

## 締めでやらないこと

- 本編と関係ない近況や長い挨拶で終える（見終わった満足が下がる）
- 登録の呼びかけを冒頭で長く話す（本題を待たせて離脱される）
