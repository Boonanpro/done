# YouTubeのサムネとタイトル

YouTube動画とLINE特典動画の台本を書く前に、テーマを決める所で読む。サムネとタイトルは、一覧の中で見る人が手を止めて押すかを決める所で、台本の1行目はその続きになる。サムネとタイトルが決まってから、台本の1行目と冒頭を合わせる。

元にした物：える会員サイト「6. クリック率が爆上がりするサムネ設計方法」（`dan-workspace/marketing-reference/youtube-producer-l/master_kit/lessons/48〜63`）、たいき（@taiki007）の再生上位20枚とそのタイトル（`dan-workspace/fukurou-clients/xenomagic/thumbs-v4/taiki_sheet.jpg`・`taiki_list.tsv`）、YouTubeの中の人の動画 `jdYNSpXdxF4`（2026秋版）、スヤさんの1本目で本人がA案を選んだ理由（2026-10-29）。まとめは `dan-workspace/script-craft/サムネ_ルール.md`。読み取りの記録は `sources/generalization-log.md` の 2026-10-29 の項。「保留」は出どころが1か所だけの技で、本人の判定で確かめたら外す。

大前提として、サムネは動画の中身を正しく伝える物にする。動画に無いことを言うと、一度は押されても、見る人は「このチャンネルは釣りだ」と覚えて次から押さなくなる（える「クリック率の高いサムネの要素」）。

## 技

### 1. 一番大きく見せる言葉を10文字以内に削る
- 何を：サムネに載せる言葉
- どこに：サムネの文言を決める最初
- どういう形で：言いたい語を全部書き出す。①同じことを別の言い方で言っている語と、動画の中身に無い語を消す ②残りに順位を付ける ③1位の語を一番大きい行（10文字以内）にする。補足の行を入れても、全体で2〜3行までにする
- なぜ効くか：見る人は一覧で一瞬見て押すかを決めるので、一番大きい言葉が一瞬で読めると手が止まる
- 良い例：書き出した語「節約・やめていい・固定費・1つ・年8万円・誰でも・簡単」→ 重なる「やめていい」「簡単」を消す → 一番大きい行「節約やめろ」、補足の行「固定費1つで年8万円」
- 悪い例：「誰でも簡単！節約はやめていい！固定費を1つ見直すだけで年8万円」を1枚に全部載せる（字が小さくなり、一覧で読めない）
- 出どころ：える「①文字数を少なくする」、たいき20枚（一番大きい行は「絶対無視するな」「完全敗北」など4〜8文字）

### 2. 文言は言い方を2つ以上重ねる
- 何を：残った文言の言い方
- どこに：技1で残した語
- どういう形で：次から2つ以上を1枚に入れる。断定・命令（「〜しろ」「〜するな」）、逆説（常識と逆のことを言い切る）、損失回避（得する話も、損する側から言う）、数字と手軽さ（「たった1つ」「5分」）、ベネフィット（物の良さではなく、見た後に見る人が得る体験）、強調（「絶対」「確実」。サムネだけに使い、広告や商品の説明では使わない）。何かを否定する文言（「〜はやめろ」）を使う時は、代わりにやる行動をサムネかタイトルに入れる（この部分は保留）
- なぜ効くか：常識と逆の言い切りで「え？」と思い、数字で自分の得か損が見えるので、押す理由が2つできる。代わりの行動があると「何をすればいいか」まで分かる
- 良い例：「ネット料金は普通に払うな！／10年で50万円も節約」（命令＋損失回避＋数字）。「AIの勉強はやめろ」に「事業を持て」を並べる
- 悪い例：「ネット料金の見直し方」（言い方が何も重なっていない）。「AIの勉強はやめろ」だけ（ただの否定に見える）
- 出どころ：える「②人間の心理傾向」〜「⑧断定文、命令文にする」、たいき20枚。否定と代わりの行動は 2026-10-29 本人がスヤさんの3案からA案を選んだ理由（常識の破壊と、具体的に何をするかが両方ある）だけ

### 3. タイトルはサムネと別の言葉にする
- 何を：タイトル
- どこに：サムネの文言を決めた後
- どういう形で：サムネとタイトルを並べ、同じ語が両方にあればタイトル側を言い換える。タイトルには、サムネで言えなかった期限・誰の話か・何が分かるかと、見る人が検索で打つ言葉を入れる
- なぜ効くか：2か所で別の理由が見えるので、どちらかで手が止まる。タイトルの言葉は検索からも見つけてもらえる
- 良い例：サムネ「突然の警告／絶対無視するな」、タイトル「【7月30日まで】Googleが利用規約を大きく変えます」。サムネ「節約やめろ／固定費1つで年8万円」、タイトル「【貯金が増えない人へ】スマホで10分、毎月の支払いを減らす方法｜通信費の見直し方」
- 悪い例：サムネ「AIの勉強はやめろ」、タイトル「AIの勉強はやめろ」
- 出どころ：える「タイトルとセットで考える」、たいき20枚（サムネは驚きの一言、タイトルは期限と何の話か）

### 4. 要素3つ・色3色までにして、一番の語を飛び抜けて大きくする
- 何を：サムネの並べ方と色
- どこに：文言が決まった後、画像を作る時
- どういう形で：要素は文字・話し手の顔・話の物1つ（キーボード、ロゴ、通帳など）までにし、それ以外は消す。色は文字の塗りの色で数え（黒い縁は数えない）、3色まで。一番の語だけを強い色（赤か黄）にし、文字の高さを2番目の語の2倍以上にする。お金や専門家の話で信用を優先するチャンネルは1.5倍ほどにとどめる（倍率は私の目安で、本人の判定で直す）
- なぜ効くか：一番の語が飛び抜けていると、一覧の中で一瞬で何の動画か分かる。色や要素が多いと、何を一番言いたいのかが分からなくなる。大きさの差を抑えると、落ち着いて信用できる見た目になる
- 良い例：要素は文字・話し手・通帳の3つ、文字の塗りは白・黄・赤、「節約やめろ」だけ赤で、お金の話で信用を優先するので補足の行の1.5倍の高さ
- 悪い例：電卓・豚の貯金箱・矢印・✕を足し、全部の行を同じ大きさで6色にする
- 出どころ：える「高確率で視聴者の目を引くサムネデザインの作り方」（優先順位・ジャンプ率・色は2〜3色）、たいき20枚

### 5. 文字は極太のゴシックに黒い太い縁を付ける
- 何を：サムネの文字の作り
- どこに：画像を作る時
- どういう形で：極太のゴシック（ヒラギノ角ゴ W9 など）に、黒い太い縁を付ける。光彩・グラデーション・金属風の文字は使わない。強調する語だけ白と黒の二重の縁にする（この部分は保留）。文字は2倍の大きさで描いてから縮める。矢印などの記号は画像生成に任せず、図形で描く。YouTubeは一覧でサムネの右下に再生時間を重ねるので、右下には何も置かない
- なぜ効くか：縁がはっきりした文字は、背景が何色でも、小さい一覧でも読める。光彩や色の段差は縮めるとにじんで読めなくなる
- 良い例：黄色の極太ゴシックに黒の太い縁、右下は空ける
- 悪い例：金色のグラデーションに光彩を付けた文字（2026-10-29 の作り直しの前、縮めるとぼやけて読めなかった）、右下に数字を置いて再生時間で隠れる
- 出どころ：たいき20枚、える「文字を目立たせる方法」、2026-10-29 スヤさんのサムネの作り直し

### 6. 出す前に4つ確かめ、文言だけ変えた3案を出す
- 何を：できたサムネ
- どこに：本人に見せる前
- どういう形で：①タイトルを隠し、サムネだけで何の動画か分かるか（保留）②上半分だけで気になるか（テレビでは上半分しか見えない）③YouTubeの一覧の大きさ（私の目安で幅360pxと168px）に縮め、同じ分野のサムネと並べて目に留まるか ④動画の中に無いことを言っていないか。そのうえで、見た目は同じで文言だけを変えた3案を作って本人に見せる（YouTubeの比べる機能に入れられるのが3枚まで）。公開後は、その機能で入れ替えて比べる
- なぜ効くか：作った本人には読めても、一覧の大きさでは読めないことが多い。3案あると、言い方の違いだけを比べられる
- 良い例：3案「節約やめろ」「節約は意味ない」「我慢するな」を、一覧の大きさで同じ分野のサムネ3枚と並べた画像で見せる
- 悪い例：大きいサイズの1案だけを見せる
- 出どころ：YouTubeの中の人 `jdYNSpXdxF4`（文言を変えた案を比べる・テレビの見え方）、える「サムネの重要性」「クリック率の高いサムネの要素」（一覧で一瞬で判断される・釣りの害）、たいき20枚と並べた比べ方

### 7. 話し手は本人の実際の写真を使い、本人のチャンネルのサムネに見た目を合わせる
- 何を：サムネの人物と背景
- どこに：画像を作る最初
- どういう形で：①話し手のチャンネルのサムネを20〜40枚並べ、人物の写真の撮り方（ポーズ・表情・服）、背景、文字の色と言い回しの癖を見る ②人物は、本人のサムネ用の写真（`https://i.ytimg.com/vi/<動画ID>/maxresdefault.jpg`）から、内容に合う表情とポーズの1枚を選ぶ。動画の途中の画面は話している途中の顔で、サムネには向かない ③写真に元の文字が載っていれば、画像生成の編集で文字だけを消し、顔と手の周り（元の文字が重なっていない所）は元の写真の画素に戻す。消した所に体が重なっていて形が崩れたら、その範囲だけマスクで作り直す ④文字と小物は自分で描く（`fukurou-clients/nakamura/line-gift/thumb_v2/make.py`）。生成で作った別人の顔は、仮でもお客さんに見せない
- なぜ効くか：見る人は、いつも見ているチャンネルの顔と見た目で「あの人の動画だ」と気づいて手を止める。別人の顔だと、本人が見ても使えないので、撮り直すまで何も決まらない
- 良い例：中村さんのサムネの「指を立てる」「頭を抱える」写真から文字を消し、同じ教室の背景のまま、白と赤の文字と健康診断の紙を載せた2案
- 悪い例：画像生成で「眼鏡の30代男性」を作り、「撮影の時に同じ構図で撮ってください」と添える（2026-10-28 中村さんのLINE特典の第1稿）
- 出どころ：2026-10-30 本人「実際の中村さんの顔が使われていないし、サムネ品質自体もしょぼい」

## 確認表

- [ ] 一番大きい行が10文字以内で、全体が2〜3行まで
- [ ] 言い方が2つ以上重なっていて、否定した時は代わりの行動がサムネかタイトルにある
- [ ] タイトルにサムネと同じ言葉が無い
- [ ] 要素は3つまで、文字の塗りは3色までで、一番の語が飛び抜けて大きい
- [ ] 文字に黒い太い縁があり、光彩・グラデーションが無い。右下が空いている
- [ ] 一覧の大きさで、同じ分野のサムネと並べて確かめた
- [ ] 動画の中に無いことを言っていない
- [ ] 人物は本人の実際の写真で、本人のチャンネルのサムネと並べて同じ人の動画に見える
