# YouTube動画を伸ばす決まり（どの案件でも使う）

YouTubeに出す動画の、ネタ・題名・サムネ・台本・編集のどれかをする時に読む。お客さんの動画でも本人の動画でも同じ。ここにあるのは「見る人が押すか、最後まで見るか」を決める考え方で、案件ごとの見た目の好み（書体・色・参考にするチャンネル）は入れない。それは案件の決まり（`talking-demo-editing/references/<案件>.md` など）にある。サムネの作り方の細かい技は [thumbnail.md](thumbnail.md)、台本の段の順番は [references/youtube-video.md](references/youtube-video.md)。この決まりはその2つの上に重ねて使う。

元にした物：MrBeast のインタビューをまとめた動画「I Watched Every MrBeast Interview」`5wvmDSMH9AM`（27分、2026-11-12 に字幕で全文を読んだ）。本人の指示「今後作っていくYouTube動画作成全てにおける伸ばし方の学びとして学習してください」「サムネと冒頭の何秒かで視聴者をグッと惹きつける編集が重要です」（2026-11-12）。話しているのは1人なので、本人の判定や公開後の数字で確かめたら、ここを直す。

## 一番の物差し：YouTubeは「押されて、最後まで見られた」動画を広める

YouTubeがやっているのは、見る人が押して最後まで見た動画を、もっと多くの人に出すことだけ。「アルゴリズムに嫌われた」は「見る人が押さなかった・途中でやめた」と読み替える。押されるかはサムネと題名で決まり、見続けるかは冒頭と、退屈な所が無いかで決まる。迷ったら「見る人はこれで押すか」「ここで離れないか」の2つで決める。

## 1. ネタを出す

### 知識を広げてから、関係ない言葉をきっかけに増やす
- 何を：動画のネタの候補
- どこに：ネタ出しを頼まれた時、台本の前
- どういう形で：①話し手の分野の最近の話題・ニュース・よそで伸びている動画を読み、知っていることを先に増やす ②分野と関係ない言葉（辞書の適当なページ、無作為な単語）を1つ取り、その言葉と話し手の分野をつなげたネタを3〜4個出す ③これを何回か繰り返して候補を並べる
- なぜ効くか：同じ頭の中からだけ出すと、毎回似たネタになり、チャンネルが同じことの繰り返しに見える。新しく知ったことと関係ない言葉があると、まだ出していない組み合わせが出る
- 良い例：「宇宙」という言葉から「宇宙で核を爆発させたら」「月に行った」「火星に行った」の3つが出る
- 悪い例：話し手の過去の動画の題名だけを見て、言い方を変えたネタを並べる

### ネタは「見る人に面白い・まだ誰もやっていない・極端」で選ぶ
- 何を：候補の中から作るネタ
- どこに：候補を並べた後
- どういう形で：候補ごとに、①見る人（そのチャンネルを見る人）にとって面白いか ②同じ分野でまだ誰もやっていないか ③極端か（金額・人数・期間・高さ・結果の大きさが、普通の話より桁が違うか）を見る。3つとも当てはまる物を選ぶ。普通の話は、③を足して極端にできないかを考える
- なぜ効くか：普通の話はよそで見たことがあり、押す理由が無い。極端な話は一目で「どうなるの？」と思わせる
- 良い例：「最初にゴールした人に1,000万円」より「最初に山の頂上に登った人に1,000万円」（崖を登る人のサムネが描けて、それだけで緊張がある）
- 悪い例：「副業の始め方」「時短レシピ5選」（よそに同じ題名が何千本もある）

## 2. 題名とサムネは、撮る前に決める

### 題名とサムネは撮影・台本の前に作り、良い物が作れないネタはやめる
- 何を：題名とサムネの下書き
- どこに：ネタを決めた直後、台本を書く前、撮影の前
- どういう形で：①サムネはラフでよいので先に描く（何をどこに写すか）②題名と組んで見て、押したくなるかを確かめる ③良いサムネか題名が作れなければ、そのネタは作り直すか、やめる ④撮影では、そのサムネの絵が撮れるように撮る（サムネに載せる場面・物・表情）。撮り終えた後に頼まれた時は、素材の中から一番近い場面を探し、足りない物（実物の写真・背景）を足して作る
- なぜ効くか：先に撮ると、後でサムネを作る時に良い絵が無く、撮り直せないまま妥協することになる。サムネが作れないネタは、どれだけ中身が良くても押されない
- 良い例：「ジェット機から最後に手を離した人がもらえる」は、人が小さくて見えなくならないように、ジェット機と人の両方が写る構図を撮る前に描いて決めた
- 悪い例：撮り終えた素材の中から、サムネに使える顔を探すだけで、構図を考えない

### 題名は短く、強い意見で、動画の長さに見合う話にする
- 何を：題名
- どこに：サムネの文言を決めた後（サムネと同じ言葉にしないのは [thumbnail.md](thumbnail.md) の技3）
- どういう形で：①短く、端末で「…」に切れない長さにする。英語では50文字を超えると切れる。日本語は1文字の幅が広いので、スマホの一覧で切れない目安は全角30字前後（推定。出す前にスマホの一覧の大きさで確かめる）。超える時は、一番大事な言葉を前半に置き、後ろが切れても何の動画か分かる並びにする ②「〜が好き」程度の意見でなく、「〜は地球上で一番うまい」くらいの強い言い切りにする ③読んだ人が「どうなったのか知りたい」と頭から離れなくなる中身にする ④動画の長さに見合う話にする。20分の動画に「虫を踏んだ」では押されない（5秒の動画なら押される）
- なぜ効くか：切れると何の動画か分からず押されない。弱い意見はよそと区別がつかない。長い動画は、見る人が「それなら20分見たい」と思う大きさの話でないと押されない
- 良い例：「バナナは地球上で一番うまい食べ物だ」
- 悪い例：「バナナが好きです」「YouTubeで1億回再生される方法」（強さが足りず「え？」とならない）

### サムネは、題名と組んで期待を作り、一瞬で何の動画か分かる絵にする（thumbnail.md に足す5つ）
- 何を：サムネの中身
- どこに：[thumbnail.md](thumbnail.md) の技4〜7で画像を作る時
- どういう形で：①一覧を流し見している人が、一瞬で何の動画か分かるか ②好奇心・驚き・感心のどれかの気持ちが起きるか ③写っている物を1つずつ指さし、それぞれが話の中で何の役か言えるかを確かめる。言えない物は消すか、話に合う物に替える ④写っている物どうしが同じ色で溶けていないか（旗と旗竿が同じ色、何色もある服で人の輪郭が分からない）⑤暗い絵より明るい絵にする
- なぜ効くか：役の分からない物や、溶けて見分けられない物があると、一瞬で話が伝わらない。MrBeast は、知人のサムネで要素を4〜5つ直せば再生が7倍になっただろうと見立てた
- 良い例：警察に追われる場面なら、追う人は警官の制服、後ろの車はパトカーにする
- 悪い例：追う人が黄色いベストで警官に見えない、後ろの車がただの乗用車

## 3. 冒頭：最初の5秒と30秒で決まる

### 最初の5秒は、サムネと同じ絵で、サムネと題名の約束をそのまま言う
- 何を：動画の0〜5秒の絵と言葉と字幕
- どこに：台本の1行目と、編集の最初の5秒。台本・撮影の前に「サムネ → 最初の5秒 → 最初の30秒」の順に決めておく
- どういう形で：①最初の5秒の絵は、サムネと同じ物・同じ構図にする（サムネに載せた実物、サムネの写真を撮った場面）②言葉は、題名とサムネで約束したことをそのまま言う（題名が「〇〇は嘘」なら「〇〇は嘘です。その理由を話します」）③字幕を最初から付ける（音を消して見ている人がいる）④明るい絵にする ⑤挨拶・名乗り・前置きは約束を言った後に回す。[youtube-video.md](references/youtube-video.md) の冒頭の1行目（悩みの代弁か山場の一言）は、この約束に合う物にする
- なぜ効くか：ホームではサムネより先に動画が自動で流れ始めるので、最初の数秒がサムネの代わりに押されるかを決める。押した人は約束が本当か確かめに来ているので、最初の数秒で約束が見えないと「思っていたのと違う」と戻る。多くの動画は約束を言うまでに20秒かかり、そこで離れられる
- 良い例：「FBIの捜査官を縛った。この鞄には1,500万円。ナイフはここ。頑張って」で走り去る（10秒で、何が起きるか・何がもらえるか・緊張が全部ある）。日本語なら、サムネ「節約やめろ」の動画の1行目「節約、今日でやめてください。固定費を1つ変えるだけで年8万円残ります」
- 悪い例：「どうも、〇〇です。今日は〜について話していこうと思います。その前に〜」で20秒（約束が出てこない）

### 約束を言ったら、すぐ上乗せする
- 何を：5秒〜30秒の中身
- どこに：約束を言った直後
- どういう形で：「それだけでなく、〜も見せます」と、題名とサムネで約束した以上の物（この先に出てくる場面・実物・数字）を2〜3個、短く並べる。無駄な言葉を入れない。最初の30秒は、絵（カット・画角・差し込む実物）を多く変える
- なぜ効くか：約束が本当だと分かった上に、もっともらえると分かると、最後まで見る理由が増える。最初の30秒で3割が離れるのが普通で、ここを15〜20%に抑えるだけで、動画の中身を変えなくても再生回数が何倍も変わる
- 良い例：FBIの動画の最初の40秒で「NFLのスタジアム」「自家用ジェット」「迷路」とこの先に出る場面を並べる
- 悪い例：約束を言った後、話し手の経歴を1分話してから本題に入る

## 4. 維持率：70%を目標に、退屈な所を全部消す

### 退屈な所を全部探して消す
- 何を：書き出した動画の全編
- どこに：粗編集が終わった後と、渡す前
- どういう形で：①見る人になったつもりで通しで見て、新しい情報も絵の変化も無い区間（言い直し・同じ話の繰り返し・長い間・前置き）を全部拾い、消すか詰める ②同じ画角が10秒続く所は、文の切れ目で寄り・引き・別のカメラ・話している実物の絵に替える（3秒ごとに替えれば、言っていることは同じでも見ていられる）。替える絵は話に合う物にし、顔が続く所を埋めるためだけの絵は入れない（[talking-demo-editing](../talking-demo-editing/SKILL.md) の「絵を付ける前に、その文に絵が要るかを決める」）③目標は平均で70%見られること
- なぜ効くか：見る人は、同じ画面で話が10秒続くとスマホを触り始める。退屈な所が1か所でもあると、そこで離れる
- 良い例：カメラ1台で話す動画で、文の切れ目ごとに引きと寄りを替え、数字や物の名前が出た所でその実物を見せる
- 悪い例：話し手が正面を向いて話す同じ画角が30秒続く

### 最後に見返りを置き、長い動画は途中にもう一度引き込む山を作る
- 何を：動画全体の組み立て
- どこに：台本と構成を決める時。編集で並べ替える時
- どういう形で：①動画の最後に、見る人が待っている物（答え・結果・誰が勝つか）を置き、冒頭でそれがあると言っておく ②10分を超える動画は、1本の話だけで最後まで引っ張れないので、数分ごと（例えば3分・6分）に新しい展開・意外な事実・脇筋を入れて、見る人をもう一度引き込む ③前半ほど手間をかける。長く見た人ほど続けて見るので、離れやすいのは前半
- なぜ効くか：途中で中だるみしても、最後に知りたい物があれば見続ける。1本の話が続くだけだと、10分を過ぎると飽きる
- 良い例：「追いかけっこで捕まえたら1,000万円」だけで15分は持たない。3分で熊が出てくる、6分で湖を飛び越える、と山を足すと最後まで見る
- 悪い例：結論を冒頭で全部言い切り、後半はその補足だけになる

## 5. 公開した後：毎回1つ直す

- 公開後、維持率のグラフで大きく落ちた時刻と、クリック率を見て、何が原因だったかと次の動画で直す1つを、その案件の記録に書く。次の動画を作る前にそれを読む。
- 毎回、何か1つ新しいことを足して比べる（台本・編集の技・声の抑揚・サムネの技・題名の付け方）。最初の100本はうまくいかなくて当たり前で、毎回1つずつ直した人が伸びる。
- 決まった曜日に間に合わせるために、質の低い動画を出さない。並の動画を何本出しても広まらない。出す本数を減らしても、1本ずつを広まる質にする。
