# 確認項目

完了と言う前に実物で確かめる項目。点数は付けない。
「成果物のどこがどうなっているか」を実ブラウザ・実レスポンスで確認し、欠陥は直す。
直せない・判断が分かれるものは理由を添えて報告する。

---

## 全用途共通

| 項目 | 確認方法 |
|---|---|
| 3 幅で崩れない | 390 / 768 / 1280px のスクリーンショット。横溢れ・重なり・極小文字が無い |
| 文字が読める | 見出し・本文・ボタンのコントラストと大きさ。写真の上の文字が背景に沈んでいない |
| 写真の切れ方 | 顔・商品・文字が不自然に切れていない。object-position を確認 |
| 編集 ID | 編集対象に `data-edit-id` があり、重複が無い（`editable_artifact.py audit`） |
| 公開済み編集との整合 | `release.gen.json` に載る editId を JSX で上書きしていない（SKILL.md 1-2） |
| 素材が本物 | ユーザー提供の写真・ロゴ・文言を使っている。AI 生成で置き換えていない。実在しない数字・出典が無い |
| 公開URL | `share_url` に到達し、最新内容が初回 HTML に出ている |
| モーション | `prefers-reduced-motion` で内容が読める。スクロールで戻れる |

## A. ダッシュボード / 管理画面

| 項目 | 確認方法 |
|---|---|
| ダン UI 体系 | セマンティックトークン・shadcn/ui・Lucide（SKILL.md 1-7）。既存画面と操作感が同じ |
| 3 状態 | ローディング / エラー / 空 が全て実装されている |
| API | 全エンドポイントに curl。正常レスポンスとエラー時のステータスコード |
| 操作一巡 | ブラウザで作成 → 表示 → 編集 → 削除 |
| 型の一致 | フロントが期待する型と API が返す型が一致。表示データが正しい |
| 導線 | サイドバーから辿れる。認証が通る |

---

## B. クライアント HP / LP / ツール

| 項目 | 確認方法 |
|---|---|
| ファーストビュー | 3 秒で何のサイトか分かる。主要 CTA が見える |
| CTA 到達 | モバイルで全セクションから問い合わせ・電話・予約に到達できる |
| 編集動作 | 手動編集ONで見出しを長文に変更・改行 → 崩れない。画像差し替え・余白変更 → 再読み込み後も残る |
| 内容追従 | 文量変更で隣のセクションを覆わない（座標固定でない） |
| 速度 | ヒーロー媒体の重さ、LCP。重い技法はモバイルフォールバックがある |
| 機能（あれば） | API に curl、操作一巡、3 状態（A と同じ） |
| 比較元（あれば） | ユーザー提供の参考・元画像と同じ幅で並べて差分を確認 |
