# Anti-Bias Checklist（保守バイアス防止）

見積もり出力前に以下を全てチェックする。1つでも該当すれば修正せよ。

## チェック項目

- [ ] **人間チーム前提**: 人間3-5名チーム前提で見積もっていないか → AIツール利用料ベースで再計算
- [ ] **スプリント計算**: スプリント（2週間単位）で計算していないか → AI実行時間ベースで再計算
- [ ] **過大な期間**: 「事業コンセプト確定: 1週間」等、AIなら1日でできるタスクを長く見積もっていないか → 各タスクのAI実行時間を個別に見積もる
- [ ] **逐次実行前提**: タスクを逐次実行前提で並べていないか → AIは並列実行可能。依存関係のないタスクは同時実行として期間を短縮
- [ ] **安易な【要操作】**: 「ドメイン取得」「アカウント登録」等を【要操作】としているが、AIに委任できないか検討したか → ブラウザ自動化で可能ならAIタスクに変更
- [ ] **人件費ベースのコスト**: 人件費をベースにコスト計算していないか → AIツール利用料（API費用、SaaS月額等）+ 最小限の人的コストで算出
- [ ] **月単位の期間**: 期間が月単位になっていないか → 日単位で再計算。AI-firstなら多くのプロジェクトは日〜週単位で完了する
