# Source Policy

Use fresh, high-signal sources. Capability claims without sources are low confidence.

## Priority Order

1. Official model/tool docs, release notes, changelogs, pricing pages.
2. Official company announcements or engineering blogs.
3. Independent benchmark reports and reproducible technical writeups.
4. Social posts or secondary commentary (supporting only, not primary evidence).

## Recency Rules

- Fast-changing capability claims: prefer evidence published within 30 days.
- 31-90 days old: usable with caution and lower confidence.
- Older than 90 days: treat as stale unless no alternative exists.

## Evidence Quality Rules

- Prefer sources that include concrete feature behavior, limits, or APIs.
- Prefer primary sources over summaries.
- If multiple credible sources conflict, state conflict explicitly and lower confidence.
- If no reliable source exists, mark the unit uncertain and request follow-up constraints/tests.
