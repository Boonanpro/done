# search - キーワードで商品を検索する

## 目的

楽天市場の検索機能を使って、キーワードで商品を探す。

## 前提条件

- **認証要件**: なし（未ログインでも検索可能）
- **ページ状態**: 特になし（楽天市場トップページを開くところから開始）

## 画面の見つけ方

### 楽天市場トップページ

- `browser_open` で `https://www.rakuten.co.jp/` にアクセスする
- ページ上部に赤いヘッダーバーがあり、「楽天市場」のロゴが左上に表示される

### 検索バーの場所

- ページ上部の赤いヘッダーバー内にある
- 横長の白い入力欄で、ヘッダーの中央付近に配置されている
- 入力欄の右端に赤い虫眼鏡アイコンの検索ボタンがある
- 要素一覧で「検索」に関連するinput要素を探す

## 操作手順

### 1. 楽天市場にアクセスする

1. `browser_open` で `https://www.rakuten.co.jp/` を開く
2. 赤いヘッダーバーと「楽天市場」ロゴが表示されることを確認する

### 2. 検索バーにキーワードを入力する

1. 要素一覧からヘッダー内の検索用テキスト入力欄を見つける
2. `browser_type` で検索キーワードを入力し、`press_enter=True` で検索を実行する
   - 例: `browser_type` ref=@eXXX, text="ノートPC", press_enter=True

### 3. 検索結果を確認する

1. 検索結果ページに遷移する
2. ページタイトルが「【楽天市場】○○の通販」に変わる
3. 商品がカード形式で一覧表示される

### 4. 目的の商品を探す

1. 検索結果を上から確認する
2. 「PR」マーク付きのスポンサー商品が最初に表示されることがある
3. 各商品カードには以下の情報が表示される:
   - 商品画像
   - 商品名（リンクテキスト）
   - 価格（赤字で「○○円」）
   - ポイント倍率（「ポイント○倍」など）
   - レビュー評価（星マーク）
   - 送料情報
4. 目的の商品が見つからない場合は `browser_scroll` で下にスクロールして探す

## 成功条件

以下が確認できれば成功:

1. **検索結果ページ**: ページタイトルに検索キーワードが含まれている（例: 「【楽天市場】ノートPCの通販」）
2. **商品一覧**: 検索キーワードに関連する商品がカード形式で表示される

## 失敗時の対処

### 検索結果が0件の場合
- キーワードのスペルを確認する
- より一般的なキーワードで再検索する
- カタカナ/ひらがな/英字の表記を変えて試す

### 期待した商品が見つからない場合
- キーワードを変更して再検索する
- ブランド名やメーカー名を追加する
- サイズや容量、型番を追加する

### 検索バーが見つからない場合
- `browser_screenshot` でページの現在の状態を確認する
- ポップアップやモーダルが検索バーを覆っている場合は、閉じるボタンをクリックする
- ページを再読み込みする

## 注意点

- 検索結果の並び順はデフォルトで「標準」。価格順やレビュー順への変更も可能
- 同じ商品が複数のショップから出品されていることがあり、価格が異なる場合がある
- 検索結果ページのレイアウトは画面サイズにより変わることがある
