# login - 楽天市場にログインする

## 目的

楽天市場にログインして、カート操作・購入・注文履歴確認など認証が必要な機能を利用できるようにする。

## 前提条件

- **認証要件**: 楽天アカウント（ユーザID/メールアドレスとパスワード）が必要。`get_credentials` ツールでサービス名 `rakuten` の認証情報を取得する
- **ページ状態**: 特になし（楽天市場トップページからログインページに遷移する）

## 画面の見つけ方

### 楽天市場トップページのログインリンク

- `browser_open` で `https://www.rakuten.co.jp/` にアクセスする
- ページ上部の赤いヘッダーバー内に「ログイン」のテキストリンクがある
- 要素一覧で「ログイン」というテキストのリンク要素を探す

### ログインページ（ユーザID入力画面）

- URLが `login.account.rakuten.com` を含む
- ページタイトルが「ログイン - 楽天」
- 「ユーザIDまたはメールアドレス」と書かれたテキスト入力欄がある
- 入力欄の下に「次へ」ボタンがある

### パスワード入力画面

- ユーザID入力後、同じ `login.account.rakuten.com` ドメインのまま画面が遷移する
- ページタイトルは引き続き「ログイン - 楽天」
- 「パスワード」と書かれたパスワード入力欄がある
- 「パスワードを表示する」チェックボックスがある
- 入力欄の下に「ログイン」ボタンがある

## 操作手順

### 1. 楽天市場トップページにアクセスする

1. `browser_open` で `https://www.rakuten.co.jp/` を開く
2. 赤いヘッダーバーと「楽天市場」ロゴが表示されることを確認する

### 2. ログインページに遷移する

1. 要素一覧から「ログイン」というテキストのリンクを見つける
2. `browser_click` でログインリンクをクリックする
3. ログインページ（`login.account.rakuten.com`）に遷移する
4. 「ユーザIDまたはメールアドレス」の入力欄が表示されることを確認する

### 3. ユーザIDを入力する

1. 要素一覧から `[input, type=text]` で「ユーザIDまたはメールアドレス」のプレースホルダーがある入力欄を見つける
2. `browser_type` でユーザID（メールアドレス）を入力する
   - 例: `browser_type` ref=@eXXX, text="user@example.com"
3. 入力欄の下にある「次へ」ボタンを要素一覧から見つける
4. `browser_click` で「次へ」ボタンをクリックする

### 4. パスワードを入力する

1. パスワード入力画面に遷移する
2. 要素一覧から `[input, type=password]` で「パスワード」のプレースホルダーがある入力欄を見つける
3. `browser_click` でパスワード入力欄をクリックしてフォーカスする
4. `browser_type` でパスワードを入力する
   - 例: `browser_type` ref=@eXXX, text="password123"
5. 入力欄の下にある「ログイン」ボタンを要素一覧から見つける
6. `browser_click` で「ログイン」ボタンをクリックする

### 5. ログイン成功を確認する

1. 楽天市場トップページにリダイレクトされる
2. URLが `www.rakuten.co.jp` に戻っていることを確認する
3. ヘッダーに「ログイン」リンクではなくユーザー名や「ログアウト」が表示される

## 成功条件

以下が確認できれば成功:

1. **リダイレクト**: ログイン後、楽天市場トップページ（`www.rakuten.co.jp`）にリダイレクトされる
2. **ログイン状態**: ヘッダーの「ログイン」リンクが消え、ユーザー名や「ログアウト」リンクが表示される

## 失敗時の対処

### ユーザID入力後にエラーが表示される場合
- 入力したユーザID/メールアドレスが正しいか確認する
- `get_credentials` で取得した情報を再確認する
- タイプミスがないか確認し、入力欄をクリアして再入力する

### パスワードが間違っている場合
- 「パスワードが正しくありません」等のエラーメッセージが表示される
- `get_credentials` で取得したパスワードを再確認する
- パスワード入力欄をクリアして正確に再入力する

### 2段階認証やキャプチャが表示される場合
- 画像認証（CAPTCHA）が表示された場合は、ユーザーに手動操作を依頼する
- SMS認証コードが求められた場合は、ユーザーにコードの入力を依頼する

### ログインページが表示されない場合
- `browser_screenshot` で現在のページ状態を確認する
- ポップアップやモーダルが表示されている場合は閉じる
- `browser_open` で `https://www.rakuten.co.jp/` に直接アクセスし直す

## 注意点

- 楽天のログインは **2段階入力方式**（ユーザID入力 → 次へ → パスワード入力 → ログイン）
- ユーザID入力画面とパスワード入力画面は別の画面として遷移する（同一ページ内でのフォーム切り替え）
- 「次へ」ボタンをクリックした後、パスワード入力画面に遷移するまで少し待つ場合がある
- ログイン成功後は元のページ（トップページ）にリダイレクトされる
- セッションが切れている場合、カート操作や注文手続き中にログイン画面に遷移されることがある。その場合も同じ手順でログインする
