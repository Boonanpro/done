# 楽天市場スキル

楽天市場での商品検索・商品詳細の確認・ログインを自動化するスキル。キーワードで商品を探し、価格・スペック・レビューなどの詳細情報を確認できる。ログインすればカート操作や注文履歴など認証が必要な機能も利用可能。

## 対象サイト

- **URL**: https://www.rakuten.co.jp
- **言語**: 日本語
- **商品詳細URL**: `item.rakuten.co.jp/ショップ名/商品ID/`
- **ログインURL**: `login.account.rakuten.com`

## 認証要件

- **検索・商品閲覧**: ログイン不要
- **カート操作・購入・注文履歴**: ログイン必要
- **認証情報取得**: `get_credentials` ツールでサービス名 `rakuten` を指定
- **ログイン方式**: 2段階入力（ユーザID → 次へ → パスワード → ログイン）

## パラメータ一覧

| パラメータ | 型 | 必須 | 説明 | 使用アクション |
|-----------|-----|------|------|---------------|
| query | string | search時必須 | 検索キーワード | search |
| username | string | login時必須 | ユーザID/メールアドレス（get_credentialsから取得） | login |
| password | string | login時必須 | パスワード（get_credentialsから取得） | login |

## 実行フロー

### 基本フロー（検索→商品確認）

```
search → view-product
```

### 認証付きフロー（ログイン→検索→商品確認）

```
login → search → view-product
```

## ブラウザ操作の注意

- 操作には `browser_open`, `browser_click`, `browser_type`, `browser_scroll`, `browser_screenshot` 等のツールを使用する
- 各ツール実行後にスクリーンショットと要素一覧（@e1, @e2...）が返される
- 要素をクリック/入力する際はref番号（例: @e3）で指定する
- 要素一覧からボタンやリンクのテキストを確認し、正しい要素を選択する

## 画面の視覚的特徴

### 楽天市場トップページ
- ページ上部に**赤いヘッダーバー**、左上に「楽天市場」ロゴ
- ヘッダー中央付近に**横長の白い検索入力欄**、右端に赤い虫眼鏡アイコンの検索ボタン
- 未ログイン時はヘッダー内に「ログイン」テキストリンクが表示される

### 検索結果ページ
- 商品が**カード形式**で一覧表示される
- 各カードに商品画像・商品名（リンク）・価格（赤字）・ポイント倍率・レビュー星マーク・送料情報
- 「PR」マーク付きのスポンサー商品が先頭に表示されることがある

### 商品詳細ページ
- 左側に大きな商品画像、右側に商品名・価格・ポイント情報
- 価格は赤字の大きなフォントで「○○円（税込）」と表示
- 各ショップが独自にデザインしているためレイアウトは商品ごとに異なる

### ログインページ
- URLが `login.account.rakuten.com` を含む
- ユーザID入力画面: 「ユーザIDまたはメールアドレス」入力欄 + 「次へ」ボタン
- パスワード入力画面: 「パスワード」入力欄 + 「ログイン」ボタン

## 注意事項

- 検索結果には同じ商品が複数ショップから異なる価格で出品されていることがある
- 商品詳細ページは情報量が多いため、`browser_scroll` で複数回スクロールが必要な場合がある
- ポップアップやクーポンバナーが表示された場合は「閉じる」ボタン（×マーク）で閉じる
- `browser_back` よりも `browser_open` で明示的にURLを開く方が安全
- ログイン時にCAPTCHAや2段階認証が表示された場合はユーザーに手動操作を依頼する
