# login - Amazonにログインする

## 目的

Amazonアカウントにログインして、カート操作や購入などの認証が必要な機能を利用可能にする。

## 前提条件

- **ページ状態**: amazon.co.jp のいずれかのページを表示していること
- **必要な情報**: メールアドレス（または携帯電話番号）とパスワード

## 画面の見つけ方

### ログインリンクの場所
- 画面最上部の黒いナビゲーションバー内
- 右寄りに「こんにちは、ログイン」というテキストがある
- その下に小さく「アカウント&リスト」と表示されている
- 未ログイン時は「こんにちは、ログイン」、ログイン済みは「○○さん」と名前が表示される

## 操作手順

### 1. ログインページを開く

1. 画面右上の「こんにちは、ログイン アカウント&リスト」の文字をクリックする
2. ログインページに遷移する

**注意**: セッション状態によっては、最初に「ショッピングを続ける」という黄色いボタンが表示されることがある。その場合はボタンをクリックしてからログイン操作を行う。

### 2. メールアドレスを入力する

1. 「サインインまたはアカウントを作成」というタイトルのページが表示される
2. 中央に「携帯電話番号またはメールアドレスを入力」と書かれた入力欄がある
3. 入力欄をクリックしてフォーカスを当てる
4. メールアドレスを入力する
5. 入力欄の下にある黄色い「次に進む」ボタンをクリックする

### 3. パスワードを入力する

1. パスワード入力画面に遷移する
2. 画面上部にメールアドレスが表示されている（正しいアカウントか確認）
3. 「パスワード」と書かれた入力欄にパスワードを入力する
4. 入力内容は●●●●のようにマスクされる
5. 黄色い「ログイン」ボタンをクリックする

## 成功条件

以下のいずれかで成功を確認できる:

1. **ナビゲーションバーの表示変化**
   - 「こんにちは、ログイン」が「○○さん」（アカウント名）に変わる

2. **トップページへの自動遷移**
   - ログイン後、Amazonのトップページに戻る

## 失敗時の対処

### 「パスワードが正しくありません」エラー
- パスワードを再確認して入力し直す
- CapsLockがオンになっていないか確認

### 「このメールアドレスは登録されていません」エラー
- メールアドレスのスペルを確認
- 別のメールアドレスで登録していないか確認

### 二段階認証が要求された場合
- SMSまたはメールで届いた認証コードを入力する必要がある
- 「コードを入力」画面が表示される

### CAPTCHA（画像認証）が表示された場合
- 表示された文字を入力する必要がある
- 自動化では対応困難なため、手動介入が必要

## 注意点

- ログインは2段階で行われる（メール入力 → パスワード入力）
- 一度ログインするとセッションが保持され、しばらくはログイン状態が維持される
- 不審なアクセスとみなされると追加の認証（二段階認証、CAPTCHA）が要求されることがある
- パスワードを複数回間違えるとアカウントがロックされる可能性がある
