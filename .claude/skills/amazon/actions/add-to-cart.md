# add-to-cart - 商品をカートに追加する

## 目的

Amazonの商品をショッピングカートに追加する。

## 前提条件

- **認証要件**: なし（未ログインでも追加可能。ただしログイン後にカートが統合されないことがある）
- **ページ状態**: 以下のいずれかのページを表示していること
  - 検索結果ページ → [search](search.md) アクションで遷移可能
  - 商品詳細ページ

※購入を完了するにはログインが必要。

## 画面の見つけ方

### 検索結果ページからの追加

検索結果ページでは、一部の商品に「カートに入れる」ボタンが直接表示されている:

- 商品カード内にオレンジ色または黄色の「カートに入れる」ボタン
- ボタンがない商品は商品名をクリックして詳細ページに移動する必要がある
- 複数の出品者がいる商品は検索結果から直接追加できないことがある

### 商品詳細ページからの追加

商品詳細ページでは:

- 画面右側に購入オプションのボックスがある
- オレンジ色または黄色の「カートに入れる」ボタン
- ボタンの上に価格と在庫状況が表示されている

## 操作手順

### パターン1: 検索結果から直接追加する場合

1. [search](search.md) アクションで商品を検索する
2. 検索結果をスクロールして対象商品を探す
3. 対象商品のカードに「カートに入れる」ボタンがあるか確認する
4. 商品名、価格、画像で正しい商品であることを確認する
5. 「カートに入れる」ボタンをクリックする

**注意**: 検索結果ページには複数の「カートに入れる」ボタンが存在する。必ず対象商品の行にあるボタンをクリックすること。視覚的に商品画像と商品名を確認してから操作する。

### パターン2: 商品詳細ページから追加する場合

1. 検索結果または商品リンクから商品詳細ページを開く
2. 商品名と画像で正しい商品であることを確認する
3. サイズ・カラーなどのバリエーションがある場合は選択する
4. 数量を確認する（デフォルトは1）
5. 「カートに入れる」ボタンをクリックする

### 追加完了を確認する

#### 検索結果ページから追加した場合
1. ボタンが数量表示（「1」など）と「-」「+」ボタンに変わる
2. これはカートに追加されたことを示す
3. 画面右上のカートアイコンの数字が増える

#### 商品詳細ページから追加した場合
1. 「カートに追加しました」の確認画面が表示される
2. または、カートページに自動遷移することがある
3. 画面右上のカートアイコンの数字が増える

## 成功条件

以下のいずれかが確認できれば成功:

1. **ボタンの変化**: 「カートに入れる」ボタンが数量表示に変わる
2. **確認メッセージ**: 「カートに追加しました」と表示される
3. **カート数の増加**: 画面右上のカートアイコンの数字が1増える

## 失敗時の対処

### 「在庫切れ」と表示される場合
- その商品は現在購入できない
- 「入荷通知を受け取る」ボタンがあれば入荷時に通知を受けられる
- 別の出品者を探す（「新品」「中古」の選択肢があれば確認）

### 「配送オプションを選択してください」と表示される場合
- 配送オプションを選択してから「カートに入れる」をクリック

### サイズ・カラーの選択が必要な場合
- 商品詳細ページに移動してバリエーションを選択する
- 選択しないと「カートに入れる」ボタンがクリックできない

### 「この商品はカートに追加できません」と表示される場合
- マーケットプレイス出品者の設定で制限されている可能性がある
- 別の出品者から購入を試みる

### 複数のボタンがあり正しい商品を選べない場合
- 商品名をクリックして詳細ページに移動し、そこから追加する
- 商品画像を確認して正しい商品であることを確認する

## 検索結果での商品特定のコツ

検索結果ページでは同じ「カートに入れる」ボタンが多数存在する。正しい商品を選ぶために:

1. **商品名を確認**: 容量（50ml、150gなど）、ブランド名が正しいか
2. **商品画像を確認**: パッケージの見た目が期待通りか
3. **価格を確認**: 期待する価格帯か
4. **評価を確認**: レビュー数と星評価
5. **スポンサー表示を確認**: 広告商品でないか（必要に応じて）

## 注意点

- 検索結果には同じセレクタを持つ「カートに入れる」ボタンが多数存在する（ログでは57個のボタンが検出された例あり）
- 必ず視覚的に正しい商品であることを確認してからボタンをクリックする
- スポンサー商品（広告）は検索結果の上部や途中に混在している
- カートに追加しても購入が確定するわけではない（レジに進むまでは変更可能）
- 同じ商品を複数回追加すると数量が増える
