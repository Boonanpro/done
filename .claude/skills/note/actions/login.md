# noteログイン手順

## 手順

1. `browser_open` で `https://note.com/login` を開く
2. ログインフォームが表示されたら:
   - `get_credentials` でサービス名 `note` の認証情報を取得
   - メールアドレス欄に `login_id` を入力
   - パスワード欄に `password` を入力
   - 「ログイン」ボタンをクリック
3. ログイン成功の確認:
   - URLが `/login` から変わったことを確認
   - ユーザーアイコンやユーザー名が表示されていることを確認
4. 既にログイン済みの場合:
   - ログインフォームが表示されずホーム画面が出たらスキップ

## 注意
- 2段階認証やCAPTCHAが出た場合はユーザーに確認
- ログインページのまま変わらない場合はパスワードが間違っている可能性あり
