# Platform Notes

Use these as launch-prep heuristics. Verify current platform UI names before live setup if exact clicks matter.

## Instagram / Meta

Best for beauty, local service, visual proof, and mobile-first funnels.

Prepare:
- Campaign objective: leads, traffic, or messages. Use leads/messages when the funnel is not yet robust.
- Placement: Instagram Feed, Stories, Reels. Start automatic placements only if creative fits all placements.
- Creative: before/after workflow, screenshot-style demo, short phone screen recording, or direct founder message.
- Targeting: Japan, hairstylist/beauty salon related interests, hair/beauty creators, or local city if testing one area.
- CTA: "登録する", "詳しくはこちら", or "メッセージを送信".

Minimum launch package:
- 3 hooks
- 2 primary texts
- 1 short headline
- 1 mobile landing/form URL with UTM
- budget cap and end date

## TikTok

Best when the product can be demonstrated in a quick process video.

Prepare:
- Campaign objective: traffic, lead generation, or conversions if tracking exists.
- Creative: 9:16 video showing "photo -> AI draft -> posting work reduced".
- First 2 seconds must show the pain or outcome.
- Use native-feeling captions. Avoid polished SaaS ad tone for early tests.

Minimum launch package:
- 3 video scripts, 15-25 seconds each
- on-screen text
- caption
- CTA
- landing/form URL with UTM

## X

Best for founder-led testing, professional discussion, or direct outreach plus light paid amplification.

Prepare:
- Organic post first when possible.
- Paid test can amplify a concrete demo thread or waitlist post.
- Target by keywords/accounts/interests if available.

Minimum launch package:
- 3 short posts
- 1 longer explanation post
- 1 DM reply template
- landing/form URL with UTM

## Metrics

Track at minimum:
- spend
- impressions
- clicks
- CTR
- landing/form views
- signups or DMs
- qualified leads
- cost per qualified lead
- notable objections and exact language from replies

## Approval Gate

Before live spend, present:
- final URL
- all ad copy
- targeting
- budget cap
- schedule
- payment account to be used
- kill condition

Ask for explicit approval in plain language. Do not proceed from implied approval.
