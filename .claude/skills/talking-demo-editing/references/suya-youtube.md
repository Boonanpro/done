# スヤさん（ふくろうPのお客さん）YouTube のテイストと決定

スヤさん（東大数学科・AIで事業を作って売る人）の YouTube 本編。ふくろうPが台本・撮影・編集をする。見る人は、毎日 AI の動画を見ている30〜40代の男性。1本目は「AIの勉強より先に事業を持て」（11/7 撮影、C0291、83分。カメラは正面1台、カンペを読む撮り直し込み）。2本目は事業を実際に買う回。この案件の物はほかの案件に持ち込まない。

台本の型は talk-script（references/youtube-video.md）、伸ばし方の考え方はどの案件でも [../../talk-script/youtube-growth.md](../../talk-script/youtube-growth.md)（本人が 11/12 に渡した MrBeast の動画 `5wvmDSMH9AM` から作った）。ここにはこの案件の見た目と編集の決まりだけを書く。

## 本人の指示（11/12）

- 狙いは視聴維持率。題材に合った編集で、最後まで見てもらう（01:42）。
- 最初は粗編集から: 撮り直しの中から使うテイクを選び、間を詰める（04:31）。
- サムネと冒頭の数秒で見る人を引き込むのが一番大事（04:31・04:32）。
- 見本の品質が低すぎると叱られた。テイストを決める見本3枚（方針の説明用）は、左半分の色の板に見出しと金額を並べただけで、太陽光発電所の事例も「事例：太陽光発電所を買って売る／5,000万円／200万円／6,000万円」の文字だけだった。本人「視覚的に表現した方が伝わりやすい部分もただのテキストになっており最悪。太陽光発電所の話をするなら太陽光発電所の画像を出すべき」。→ 話に出る物・場所・事例は、実際の画像・映像を取ってくるか生成して見せる。見本も完成と同じ水準の素材で作る。
- 参考はサムネと編集。「特にサムネはバイエンスを参考にしたい。丸パクリではなく参考にする」。

## 話に出る物と、見せる物（1本目）

文字の板で済ませず、下の物を絵で出す。金額はその物の絵の上に短く載せる。

| 話 | 見せる物 |
|---|---|

| ラッコM&Aで72件に交渉、買ったのは12件 | ラッコM&Aの実際の案件一覧のページ（撮影） |

| 遺品整理は亡くなった方の部屋を片付ける仕事 | 片付ける前の実家の部屋の写真 |
| LINEで部屋の写真を送ると AI が見積もる・朝 LINE を開いて見積もりのズレを見る | LINE の見積もりのやり取りの画面（作ってでも実物の画面で撮る） |

## サムネ（参考: VAIENCE バイエンス）

見た物: `G09-M0HHkuw`「おもしろすぎて眠れなくなる宇宙の話｜理論物理学者/野村泰紀」のサムネと、同じチャンネルのサムネ8枚（死・睡眠・ピラミッド・毒殺・水中洞窟・天才・毒生物・魚突き）。

参考にする作り:
- 話題そのものの絵を画面の左〜奥いっぱいに大きく置く（ピラミッド・遺体の足の札・スズメバチの巣・アインシュタイン・マグロ）。絵だけで何の話か分かる。スヤさんなら太陽光発電所・お金・会社の売買の書類など、その回で一番強い事例の物。
- 右に話し手の実写を大きく。黒っぽい背景に横からの光で陰影を付け、話している途中の手振りや表情のコマを使う（指で示す・手を上げる・口が開いている）。正面で止まって座っている顔は使わない。
- 文字は左下に2段。上の段は短い引き（「おもしろすぎて眠れない」「一度の判断ミスで死ぬ」）を小さめに、下の段は話題の言葉を一番大きく。太い明朝、話題に合わせた色の光（死は赤、睡眠は青、ピラミッドは金、毒は紫）。
- 話し手の横に、名前（大きめ）と肩書き（小さめ）の札。金色の明朝。
- 全体は暗めの映画のような色。
- 左上にチャンネル名の小さいロゴ。

写さない物: 「おもしろすぎて眠れない〜の話」という言い回し、VAIENCE TALK のロゴ、同じ文字の効果をそのまま重ねた物。文言は talk-script の thumbnail.md の決め方で、この回の約束から作る。

## 冒頭（参考: VAIENCE と NMS STUDIO の最初の1分）

見た物: `G09-M0HHkuw` の 0:00〜1:05、`GH6wqSFaNVI`（NMS STUDIO「世界一の天才物理学者『木村建次郎』が語る世界の真理とは？！」）の 0:00〜1:03。どちらも本編の強い言葉だけを集めた約1分の予告から始まる。

- 本編の中から強い一言（数字・言い切り・意外な事実）を集め、1つ2〜4秒でつなぐ。話し手の寄りと、その言葉が指す物の全画面の絵（VAIENCE は宇宙のCG・NASA の映像、NMS はアポロ計画の記録映像・月の断面・お札が降る合成・調査車両の実写）を交互に出す。
- 絵の上に、言葉そのものを大きな文字で出す（「宇宙はいかにして誕生したのか？」「月の中がスカスカじゃないと計算合わない」「1000億円かかる」）。問いの形の見出しを挟む。
- 最後にテーマの見出しと、名前と肩書きの札を出して本編へ（VAIENCE は約1:00）。
- 音は暗めの映画風のBGMで、見出しが出る所に低い「ドン」。
- スヤさんの1本目に当てはめると、最初のカットはサムネと同じ太陽光発電所の絵と、題名・サムネの約束（youtube-growth.md の3）。続けて「5,000万円で買って6,000万円で売った」「72件交渉して買ったのは12件」「1億円で売る」のような本編の強い言葉を、その物の絵と一緒に並べる。

## 本編（参考: VAIENCE・NMS STUDIO の中盤、ひらかわ `JqCPtXsVLsE`）

- 話し手の画は 3〜5秒ごとに替える（VAIENCE は引きと寄りを交互）。カメラが1台なので、引きと寄り（拡大）を文の切れ目で替える。
- 抽象的な話にも、その言葉が指す物の写真・映像を差し込み、2〜5秒で話し手に戻る。記録がある物（その人の大学の外観、昔の写真）は本物を出す。
- 字幕は全部の言葉に付ける（VAIENCE は画面の下の中央に白の明朝と薄い影。NMS は予告の間、言葉を大きな白い太字で話し手の横や絵の上に置く）。書体と色はまだ本人と決めていない。
- 左上に、今どの章の話かの札を出し続ける（VAIENCE「２｜現在の宇宙 ダークマター＆ダークエネルギー」、NMS「/: 様々な透視依頼」、ひらかわ「②メンバーシップで『毎月更新』に追われる」）。
- ひらかわの動画（顔出し無し・明るい白背景）から使うのは、組み立てだけ: 数字の言い切りを全幅の帯で大きく出し「ドン」を合わせる、仕組みの説明は図の箱を話に合わせて1つずつ足す、章の変わり目に「第〇章」の画面を挟む、見る人の疑問（「それはあんたが特別だからでしょ？」）を吹き出しで代弁する。白背景・イラストの似顔絵・パステルの色は使わない（スヤさんは顔出しで、本人がサムネの参考に選んだのは VAIENCE の暗い映画調）。
