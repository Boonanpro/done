# スヤさん（ふくろうPのお客さん）YouTube のテイストと決定

スヤさん（東大数学科・AIで事業を作って売る人）の YouTube 本編。ふくろうPが台本・撮影・編集をする。見る人は、毎日 AI の動画を見ている30〜40代の男性。1本目は「AIの勉強より先に事業を持て」（11/7 撮影、C0291、83分。カメラは正面1台、カンペを読む撮り直し込み）。2本目は事業を実際に買う回。この案件の物はほかの案件に持ち込まない。

台本の型は talk-script（references/youtube-video.md）、伸ばし方の考え方はどの案件でも [../../talk-script/youtube-growth.md](../../talk-script/youtube-growth.md)（本人が 11/12 に渡した MrBeast の動画 `5wvmDSMH9AM` から作った）。ここにはこの案件の見た目と編集の決まりだけを書く。

- 参考はサムネと編集。「特にサムネはバイエンスを参考にしたい。丸パクリではなく参考にする」。

## 話に出る物を絵で見せる

文字の板（色の背景に見出しと金額だけ）で済ませず、話に出る物・場所・事例を絵で出す。金額はその物の絵の上に短く載せる（例: 太陽光発電所の写真の上に「5,000万円で買う」）。お金の流れや仕組みを図にする時も、箱と文字だけにせず、箱に業者・お客さん・会社の写真を付ける。手元に実物が無い一般の物（業種・場所）は、公開の写真・ストック映像、無ければ生成した写真で見せ、生成は実績の証拠として見せない。スヤさんの実際の案件の写真・書類があれば最優先でもらう。その回の「話と見せる物」の表は、その回の作業フォルダの計画に作る（1本目は `dan-workspace/fukurou-clients/xenomagic/edit1-20261112/PLAN.md`）。

気持ちや雰囲気だけの所（「自由な人生」「不安」）は、スヤさんの顔のままにする。

- 右に話し手の実写を大きく。黒っぽい背景に横からの光で陰影を付け、話している途中の手振りや表情のコマを使う（指で示す・手を上げる・口が開いている）。正面で止まって座っている顔は使わない。

- 話し手の横に、名前（大きめ）と肩書き（小さめ）の札。金色の明朝。
- 全体は暗めの映画のような色。
- 左上にチャンネル名の小さいロゴ。

VAIENCE の作りに沿って作ったサムネは「参考にするだけじゃダメ、安っぽい」と言われた（11/12）。作りが合っていることを合格の理由にせず、並べた時に VAIENCE と同じ仕上がりの質（写真の質・光・文字の作り込み）に届いているかで決める。

## 本編（参考: VAIENCE・NMS STUDIO の中盤、ひらかわ `JqCPtXsVLsE`）

- 話し手の画は 3〜5秒ごとに替える（VAIENCE は引きと寄りを交互）。カメラが1台なので、引きと寄り（拡大）を文の切れ目で替える。
- 抽象的な話にも、その言葉が指す物の写真・映像を差し込み、2〜5秒で話し手に戻る。記録がある物（その人の大学の外観、昔の写真）は本物を出す。
- 字幕は全部の言葉に付ける（VAIENCE は画面の下の中央に白の明朝と薄い影。NMS は予告の間、言葉を大きな白い太字で話し手の横や絵の上に置く）。書体と色はまだ本人と決めていない。

- ひらかわの動画（顔出し無し・明るい白背景）から使うのは、組み立てだけ: 数字の言い切りを全幅の帯で大きく出し「ドン」を合わせる、仕組みの説明は図の箱を話に合わせて1つずつ足す、章の変わり目に「第〇章」の画面を挟む、見る人の疑問（「それはあんたが特別だからでしょ？」）を吹き出しで代弁する。白背景・イラストの似顔絵・パステルの色は使わない（スヤさんは顔出しで、本人がサムネの参考に選んだのは VAIENCE の暗い映画調）。

## 編集の水準と雰囲気（11/12〜11/13 の本人の言葉から）

- **水準はナオキマン（NMS STUDIO）くらいの細かさ。** 写真を出してゆっくり動かし、文字を載せる、を繰り返しただけの編集は「安っぽい」「全くダメ」（11/12）。テロップの出し方・動き・モーショングラフィックを、場面ごとに言っている中身に合わせて作り込む。本人が「悪くない」と言った作り（NMS「月の中を知る男」の冒頭の予告と同じ動きをスヤさんの話に当てた物）: 明朝の文字が1字ずつぼけた状態から出る、大きい数字が強く出て画面が一瞬光る、決め言葉を縁取りだけの文字で出す、走査線と横ずれのノイズ、お札が上から舞い落ちる、映像がモザイクで崩れて文字に色ずれ。ただし「まだクオリティが届いていない」ので、コードで作った動きだけで止めず、Envato のテンプレート・グラフィック・効果音で上げる。
- **雰囲気は暗い版（ナオキマン寄り）が基本。** 11/12 に「明るさは TAIKI さんの動画（AIの歴史）くらい、編集はナオキマン寄り、少しビジネス寄り」と言ったが、明るい版を見て「全くダメ」「暗い方の編集スタイルの方が好み」（11/13）。明るい版は TAIKI さんの図解の画面（ベージュの紙の背景に写真のカード・吹き出しを並べる作り）まで取っていて、絵の説明が字幕と同じ中身になり、太陽光発電所の写真もカードの中で小さかった。参考の動画から取るのは、本人が言った所（TAIKI さんなら明るさ）だけにする。
- **実写は全画面か画面の大半で出す。** 話に出る物・場所（太陽光発電所・シロアリ駆除の作業・会社のページ）を、カードや小窓に小さく入れない。
- **図は、字幕で言っていない関係（お金の流れ・時系列・比べ）だけ。** 話している言葉をそのまま図に並べない。
- **使える素材**: Envato Elements の Core（11/12 から月払い、shub6923 のアカウント）。本人が価値を感じているのはビデオテンプレート・グラフィックテンプレート・効果音・3D。ただの写真・映像は無料の素材でもよい。テンプレートを開くのに After Effects・Premiere・DaVinci Studio のどれが要るかは、使うテンプレートを選んだ時に分かる（本人の DaVinci は Studio 版）。品質のためなら Adobe の月々の契約もよいと本人は言っている（契約する時は本人に聞く）。

## 作り方で分かったこと（1本目の粗編集・サムネ・冒頭の予告から）

### サムネ
- 左6割に話題そのものの大きな写真（その回で一番強い事例の物）。実物が無ければ写真風に生成してよい（生成した物を実写とは呼ばない）。
- 右に話すスヤさん（撮影のコマから切り抜く。macOS の被写体の切り抜き `dan-workspace/tools/lift_subject.swift`）。後ろから金色の縁の光。右と下を暗くして人と文字を立てる。カンペを読む撮影では手振りのコマがほとんど無いので、話している途中の手振りのコマは撮影の時にサムネ用に撮っておく。
- 左下に2段の文字。上は白い明朝の小さい行（前置き）、下は太い明朝の大きい行（言い切り）。書体は凸版文久見出し明朝 ExtraBold。大きい行は上から下へのグラデーション（金→橙、または白→赤）、白い縁、外に暗い縁、色の光。
- 名前の札: 金色の明朝で「スヤ」、細い線、下に白い小さい肩書き。人の胸のあたり。

### 冒頭の予告
- 本編の強い一言を、話に出る物の絵と一緒に約20秒の予告にして先頭に置く。最初の数秒はサムネと同じ絵にする。最後に題名と低い「ドン」で本編へ。
- 予告の大きい文字は数字と物の名前だけ。下に同じ言葉の字幕を重ねない。仮の話（計算の例）を、実際に起きたことのように言い切らない。
- 切り替えに小さい風切り音。

### 粗編集
- 撮り直しは、最後まで言い切った最後のテイクを残す。撮影中のやり取り（数字の確認・カンペ待ち・言い方の相談）は全部外す。
- 文字起こしは、すぐ続けて読み直した文を1つにまとめてしまう。粗編集の音を聞き取り直して、近くで同じ言葉が繰り返す所（6文字以上の同じ言葉と4文字の言い直し）を探して外す。
- スヤさんはカンペのスマホに手を伸ばして送る。手が画面に大きく映る所は外す。話しながら手を伸ばした所は、絵を重ねて隠す。
- 0.32秒より長い間は0.16秒に詰める。
