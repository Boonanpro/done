# 解説動画 / ドキュメンタリー調動画の制作

ナレーション音声（または台本）を軸に、映像・画像・テロップを載せて解説動画を作る手順書。
2026-08-20 に参考動画3本（RKJ VIDEO / 無限の機 / 無敵おじさん）をフレーム実測して抽出した文法に基づく。

## 0. 入口の判定（必ず最初に）

- **新規の動画制作はチャット内で完結させない。** 制作ルームに素材を入れ、タイムラインとして組み立てる（`import_media` で音声投入 → タイムライン構築）。ユーザーが後から手動編集できる形が納品形態。
- チャットでやってよいのは軽作業のみ（既存動画への簡易字幕・ぼかし・トリム等）。
- 着手前にユーザーと合意すること: ①尺 ②視覚スタイル（下記A/B/混合） ③声をそのまま使うか変換するか ④公開先。

## 1. 視覚語彙は2系統（+対象外1系統）

| スタイル | 実体 | 作り方 | 向く内容 |
|---|---|---|---|
| **A: AI画像ドキュメンタリー** | 実写調のAI生成スチルを一貫トーンで連ねる。暗部基調・単一光源・顔を映さない構図が定番（例:「闇バイト」再現風） | GPT Image 2（`scripts/gpt_image.py`）で生成。**1枚目をスタイルアンカーにし、2枚目以降は `--image` 参照で統一**（image-first LPと同じ複利ズレ防止） | 体験談・実話再現・シリアスな題材・匿名性が要る話 |
| **B: ストック＋図解解説** | 実写B-roll/報道写真/地図＋図解カード（アイコン+矢印）＋大テロップ | B-rollはAI生成静止画/短尺動画で代替、図解カードはHTML/PILで作画して画像クリップ化 | 仕組み解説・データ・時事・方法論の説明 |
| ~~C: フル3DCG~~ | Blender級の一貫3D空間（無限の機式） | **現有手段では再現不可。受けない。** 似せたい場合はAへ誘導 | — |

1本の中で混ぜてよい。定番構成: 導入(A・体験の再現) → 方法解説(B・図解) → CTA(A)。

## 2. 編集文法の実測値

### カット密度（1文=1ビジュアルが原則）
- 解説パート: **9〜14カット/分**（中央値ギャップ 4〜6秒）。ナレーションの1文ごとに絵を替える。
- ドキュメンタリーパート: ゆっくり可。ただし同一画像を8秒以上見せるならズーム/パン（ケン・バーンズ）を付ける。

### テロップ（2層を区別する）
| 層 | 用途 | 様式 |
|---|---|---|
| ナレ字幕（下部） | 発話の逐語 | 1行4〜7語（日本語は〜20字）、文単位で改行、白＋黒縁取り（黒帯禁止）、画面下部余白広め（MarginV 60〜80相当） |
| 強調テロップ（中央/大） | キーワード・数字・章題 | 極太ゴシック、白基調＋強調語だけ色替え（黄/赤）、1画面1メッセージ。全画面テキストカード（黒地に白抜き大文字）も章の区切りに有効 |

### 音声起点のカット規律（音から切る）
- カット位置は**語境界**に必ずスナップ（語の途中で切らない）。
- **400ms以上の無音が最優先のカット点**。150ms未満は切らない。
- カット端に 30〜200ms のパッドを残し、境界には 30ms のオーディオフェード（プツ音防止）。
- 言い直し・フィラーの扱いは post-production スキルの編集ポリシーに従う（言い直しだけ切る・文末を切らない・息継ぎ0.3〜0.5s残す）。

### 構成の型
`HOOK（結論/衝撃の一言・冒頭2秒で伝わる） → 問題提起 → 体験/証拠 → 方法（番号付き） → 反論への回答 → まとめ → CTA`
台本が既にある場合も、この型に対して章立てをマッピングしてから絵を割り当てる。

## 3. 制作手順

1. **文字起こし**: ナレーション音声を語タイムスタンプ付きで文字起こし（部屋の transcript ツール）。以後の全カット判断はこのタイムスタンプ基準。
2. **章立て＋ショットリスト**: 台本を章に割り、1文ごとに「何の絵か（スタイルA/B、生成プロンプト or 図解内容）」を表にする。**この表をユーザーに見せて合意してから生成に進む。**
3. **画像・クリップ生成**: スタイルアンカー方式で一括生成。B-roll動画が要る所だけ Seedance/Kling の短尺生成（〜15秒）。
4. **タイムライン組み立て**: 音声トラックを敷く → ショットリスト通りに画像/クリップを配置 → ナレ字幕 → 強調テロップ。
5. **BGM/SE**: 著作権フリー実音源のみ（サイン波仮BGM禁止）。BGMはナレーションの -18dB 目安。
6. **検証**: コンタクトシート（冒頭/中盤/終盤）＋通し視聴で、①字幕と発話の同期 ②絵替わりの取り残し（同じ絵が2文以上続く）③冒頭2秒のフック成立、を確認してから書き出し。
7. **書き出し**: 必ず制作ルームの export ジョブ（studio スキル参照。ffmpeg自作でのタイムライン再現は禁止）。

## 4. プライバシー・匿名性

- 個人情報の映り込みぼかしは post-production スキルの「Privacy Blur And Redaction」に従う。
- 投稿者の匿名化（声色変換）は着手前の合意事項。変換して使う場合、文字起こし→カット確定は**変換後の音声**で行う（タイミングがずれるため）。
