# 動画の下書きと部分修正（video-draft）

**本体はエディタ。** 動画は ffmpeg で組まない。タイムラインのクリップとして組み、ユーザーが手で触れる形で出す。
2026-09-04 の吉川特装の動画（v1〜v8 が全とっかえ→v9 で全部クリップ化）から確定した規律。

## 原則（ユーザー確定）

1. ユーザーの意図とテイストを会話で掘り下げ、技術・スキル・プロンプトはAIが選ぶ。作品に応じて絵コンテ、Vコンテ、全レイヤー入りの下書きを使い、判断できる形で見せる。2026-09-05のユーザー訂正を優先する。
2. **承認はカット単位。** 直すときは指示されたカットだけ。上手くいっている所を触らない。
3. **画面に映るものは全部クリップ。** 枠・ぼかし・字幕を画像に焼き込まない（焼き込むと手で直せない）。
4. **素材は元ファイルの範囲参照。** ナレーションを切り出しwavにしない（伸ばせなくなる）。元動画の音声を音声レーンに source_start/end で置く。
5. レーンは映像か音声かだけ。映像レーンは層（lane 0 が奥）。役割レーンは作らない。
6. 見積もりは実測だけ。同じGPUを使う重い処理は直列にし、独立した調査・編集や別の計算資源を使う作業は並行できる。Qwenは使用しない。

## 道具（timeline MCP / チャット・音声から）

| 目的 | ツール |
|---|---|
| 今どこを見ているか | `editor_state`（再生位置・選択・その時刻のクリップ） |
| 構造を読む | `timeline_outline`, `clips_at(t)`, `list_assets`, `timeline_transcript` |
| 絵を置く | `add_clip`（任意レーン・speed・position）, `append_clip`, `insert_freeze`, `import_image`, `generate_image` |
| 枠・ぼかし | `add_region`（style=frame/gaussian/mosaic/marker/spotlight, keys で追従）, `set_region` |
| 声 | `generate_speech`（本人の複製声。読みは readings で指定）→ `add_audio(role='narration')` |
| 字幕 | `auto_captions(segments=[{t0,t1,text}])`（正確な台本を渡す。発話時刻に整列） |
| 部分修正 | `split_clip` → `set_clip_props`（差し替え・位置・速度・音量） / `trim_clip` / `move_clip` / `remove_clip` |
| 目 | `render_frame(ts=[...])`（合成後の静止画）, `watch_render(t0,t1)`（合成後の映像をGeminiが視聴＝検品） |
| 検証 | `validate_draft`（空になるまで） |

編集と保存・検証の仕様は `editor_help(topic='saving')` を参照する。音声会話で合意した目的・素材・修正内容を維持し、制作側で別の依頼に置き換えない。

## ヒアリング（理解に必要な内容を会話で掘り下げる。質問数は固定しない）

1. 目的と視聴者（何をしてもらう動画か）
2. 素材（あるもの全部: 収録・写真・画面・ロゴ・台本の有無）
3. 尺と出口（HP埋め込み/SNS、縦横）
4. 隠すもの（ナンバー・番号・社名・顔）

意図・テイスト・参考・制約を確認し、必要なら案を見せて方向を合わせる。ユーザーに技術選びやプロンプト作成を求めない。合意した内容は作品の creative_brief に保持し、下書きと仕上げまで引き継ぐ。

## 下書きの組み方

- 合意した意図・参考の表現を基に、今回ユーザーが判断したい点を形にする。構成やタイミングの判断には全編の通し下書き、実写の質感や特定演出の判断には短い品質見本など、適した試作を選ぶ。
- 絵の数、レイヤーの数、字幕の有無、音声と文字の配分は作品に応じて決める。説明文と静止画を順番に並べる形式を既定にしない。
- 元収録の台詞に合わせる場合は測定した発話時刻を使う。枠・ぼかし・字幕は独立した編集可能な要素として置く。
- 操作ごとにタイムラインへ反映される。下書きの途中でも本人が見て判断できる。新しい全編の下書きがそろったら通しで見聞きして、構成・同期・音・見た目を確認する。
- 有料生成は今回合意した予算・工程に従う。安価な試作をそのまま本番品質と報告しない。

## 部分修正の作法

- 指示の「ここ」= `editor_state` の再生位置/選択。時刻で言われたら `clips_at(t)`。
- 触るのは対象クリップだけ。差し替えは `split_clip` で断片にしてから。
- 見た目の修正は対象フレーム、音・動き・カットの修正は対象区間を確認する。全編に影響しない変更のたびに全編の解析や書き出しをやり直さない。
- 修正が終わったら、何をどこに変えたかだけ短く報告（全体の説明はしない）。
