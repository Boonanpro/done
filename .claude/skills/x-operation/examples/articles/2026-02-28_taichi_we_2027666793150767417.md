# あなたが休んでいる間に、AIが仕事してくれる
2026年、AIをうまく使っている人たちは 「すごいプロンプト」を書いている人ではありません。
本当に差がついているのは、 AIと一緒に働く「仕組み」を作った人です。
プロンプトを頑張る時代は、もう終わりに近い。 これから必要なのは、 「AIに何を渡せば仕事が進むか」を整えることです。
その仕組みを作れるツールが、Claude Coworkです。
この記事を保存して、30分だけ時間を取ってみてください。 その30分が毎日の数時間を短縮することになります。

## そもそもClaude Coworkとは？
最近話題になっている「Claude Code」は聞いたことある人が多いと思います。
それの使いやすくなったバージョンだと思ってください。
**コードを書く仕事** → Claude Code
**コード以外の仕事全般** → Cowork

## Coworkはチャットボットではない
ChatGPTのようなチャットAIだと思っている人も多いと思います。
文字を打つと返事がくる。 それが普通のAIです。
でもClaude Coworkは違います。
パソコンの中に入り、フォルダを読み、ファイルを直接作り、ExcelやWordも作ります。
しかも、情報が足りないときは勝手に進めません。
「これ教えて」とちゃんと聞いてくれます。
これは小さなことではなく、
今までのAIは 「質問に答えてくれる道具」でした。
Coworkは 「一緒に仕事を進める存在」です。
主な使い方はこうです。
やってほしいことを伝える
↓
いくつか質問される
↓
答える
↓
席を離れる
↓
戻ると完成している
仕事の半分以上をCoworkに任せることも可能です。

## Coworkの機能
Coworkの機能は大きく分けて5つあります。
1. ファイルの読み書き
2. 質問してくれる機能
3. プラグイン
4. 指示メモ（インストラクション）
5. コネクター（外部ツール連携）
重要な順に説明します。

## 1. ファイルの読み書き
普通のAIだと、ファイルを書き出す→チャットにアップロード→待つ→ダウンロード→元の場所に戻す
正直、面倒です。
ただCoworkは違います。
フォルダを1つ選ぶだけ、その中を全部読めます。
作ったものはそこに直接保存されます。
この違いが本当に大きいです。
「AIを使いに行く」のではなく、 「AIが自分の職場で働く」状態になります。
具体的に何ができるか、例を出します。
たとえばあなたが毎月レポートを作っているとします。
先月のレポートがフォルダにある。テンプレートもある。今月のデータもある。
普通のAIなら、3つ全部コピペしてチャットに貼る必要があります。
Coworkは、フォルダを指定するだけで3つとも読みます。
「先月と同じ形式で、今月のデータを使ってレポートを作って」
これだけで完成します。しかも保存先も同じフォルダです。ダウンロードして移動させる手間はゼロ。
ほかにも、
・過去の提案書を参考に新しい提案書を作る
・既存のExcelにデータを追加して再計算する
・社内ルールのファイルを読みながら文書を作る
・複数のCSVを読み込んで1つのレポートにまとめる
全部、フォルダを正しく選ぶだけで可能です。
ポイントは「フォルダの整理」です。
Coworkに見せたいファイルを1つのフォルダにまとめておく。
たったこれだけで、AIの仕事の精度が劇的に変わります。
フォルダ構成がそのまま「AIへの指示」になる。
これがCoworkのを使う上での考え方です。

## 2. インストラクション
Coworkは会話をまたぐと記憶が消えます。 昨日伝えたことを今日は覚えていません。
でも「インストラクション」を設定すれば解決します。
・自分は誰か
・どう答えてほしいか
・どの形式で保存するか
・避けてほしい表現
・優先してほしいこと
これを設定すると、毎回の会話で自動的に読み込まれます。
つまり、毎回ゼロから説明し直す必要がなくなります。
これは必ず設定してください。
設定するかしないかで、体感の便利さが3倍は変わります。
「いいプロンプトを書こう」ではなく、「いい情報を用意しておこう」です。
具体的なやり方を説明します。
まず、Claude Contextというフォルダを作ります。
中に3つのファイルを入れます。
**about-me.md
**自分は誰か、どんな仕事をしているかを記載します。
例：「私はIT企業のマーケティング担当です。BtoB SaaSの集客を担当しています。チームは5人で、週次でレポートを提出しています。」
**brand-voice.md
**どんな言葉づかいをするか、嫌いな表現を記載します。
例：「カタカナ語は最小限にしてください。『ソリューション』『シナジー』などの難しい言葉は使わないでください。中学生でも分かる日本語で書いてください。」
**working-style.md
**どう動いてほしいか。先に質問してほしいかなどを記載します。
例：「作業に入る前に必ず確認の質問をしてください。ファイルはMarkdown形式で保存してください。箇条書きより文章を優先してください。」

この3つのファイルは、最初に15分かけて書くだけで構いません。
完璧でなくていいです。 使いながら「これも追加しよう」と育てていけばいい。
大事なのは、 プロンプトを毎回頑張るより、 このファイルを一度整える方が圧倒的に効果があるということです。
毎回100点のプロンプトを書くのは正直疲れます。
でもインストラクションを整えておけば、 雑な指示でも80点の結果が返ってきます。
ここが「仕組み化」の本質です。

## 3. 質問してくれる機能
普通のAIは、あいまいな依頼でも進めます。 だからズレます。
「なんか違うな…」と感じて、やり直し。
結局、自分で書いた方が早かったという経験がある人も多いと思います。
ただCoworkはわからないときは止まり、そして質問してきます。
「公開対象は社内ですか、顧客向けですか？」
「データの期間は今月だけですか、過去3ヶ月ですか？」
「グラフは必要ですか？」
これが本当に強い。
なぜなら、仕事のズレは最初の1歩で起きるからです。
方向が少しでも違うと、成果物は大きくズレる。
最初に質問で方向を合わせるだけで、やり直しが激減します。
使い方は簡単、最初にこう書くだけです。
「すぐに作業を始めないでください」
「まず質問してください」
「OKが出てから始めてください」
これをインストラクションのworking-style.mdに書いておけば、 毎回伝える必要すらありません。
完璧なプロンプトを考える必要はありません。 ざっくり伝えて、Coworkと一緒にすり合わせればいい。
「プロンプトが下手だから使えない」 そんな時代は終わりです。
質問に答えるだけで、精度の高い仕事が返ってきます。
## 
Coworkには分野ごとの専門モードがあります。
・営業
・マーケティング
・データ分析
・法務
・カスタマーサポート
・プロジェクト管理
など
入れるだけで、その分野の考え方を理解した状態になります。
何が変わるのか。
普通のAIに「売上データを分析して」と頼むと、 平均値や合計を出して「まとめ」で終わります。
データ分析のプラグインを入れた状態だと、「異常値の検出」「前月比の変化率」「改善案」「次のアクション提案」ここまで出します。
見ている深さが全く違います。
営業プラグインなら、顧客リストを渡すだけで優先度の高い見込み客を整理してくれます。
法務プラグインなら、契約書のリスクポイントを指摘してくれます。
自分の仕事に合ったプラグインを1つ入れるだけで、AIの出力レベルが一段階上がります。
まずは自分の職種に近いものを1つだけ試してみてください。
「あ、これ人間のアシスタントじゃん」と思う瞬間が来ます。
## 
Slack、Googleドライブ、Notionなど 外部ツールと直接繋ぐことができます。
これまでのAI活用で一番面倒だったのは 「データの移動」です。
例えばNotionの内容をコピーして、AIに貼って、 結果をまたNotionに貼り直す。
Googleスプレッドシートの内容をダウンロードして、 AIに渡して、結果をまたアップロードする。
コネクターを使えば、これらの往復がすべて消えます。
「先週のSlackの重要決定をまとめて」「Googleドライブの売上データから月次レポートを作って」「Notionの議事録から来週のTODOを抽出して」
これだけで動きます。 コピペ作業が不要になります。
チャンネルの会話を全部読んで、 決定事項だけを抜き出してくれます。
月曜の朝、先週の流れを5分で把握できる。 一度使うと、もう手動には戻れません。

## この後の30分でやること
1. インストール
2. インストラクションを設定する
3. 小さな仕事を任せてみる
4. プラグインを1つ入れてみる
5. ツールを1つ繋いでみる
これだけです。
この30分が今後の毎日の数時間を短縮してくれます。

## 結局なぜ乗り換えるべきなのか
AI時代の格差は、もう始まっています。
プロンプトがうまいかどうかではありません。 仕組みを作ったかどうか。
毎回ゼロから指示を書く人と、 整えた環境で任せる人。
半年後、圧倒的に差が出ます。
プロンプト力はそのうち価値が下がります。
ただ ・情報を整理する力 ・任せる力 ・仕組みを作る力
これは価値が上がり続けます。
Claude Coworkは、その第一歩です。
この記事を保存し、30分だけ試してください。 あなたが休んでいる間にAIが働きます。
AIを「使う側」で終わるか。 AIと「働く側」に回るか。
選ぶのは、今です。
