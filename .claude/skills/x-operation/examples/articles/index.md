## 探し方と分かったこと

- 候補の出どころ: X顧問のメモなどに出てくるポスト35件を照会したあと、伸びた記事を書いた16人の記事を全期間検索で取った（2026-07-25以降の190件）。X全体のキーワード検索も2回試したが、並び順が反応の多さと関係なく、伸びた記事がほとんど出てこなかったのでやめた。
- **保存の割合の条件で残るのは、ほとんどが「手順・設定・プロンプトを配る、保存して後で使う記事」だった。** 10本中8本がAIツールの使い方や設定の記事。本人の読者に近い事業の体験談や営業ノウハウの記事（例: @owl_pukuro_「売れる営業マンほど商品の説明をしない理由」は490万表示で保存/1000が0.46）は、表示は大きいが保存の割合が1を切るものが多く、条件に入らない。
- このため、10本は本人の記事（YouTubeで商品を売った体験談）とジャンルが離れている。YouTube・マーケに近いのは、顔出しなしYouTube、LLMO記事、X運用、AI動画の販売、税理士の事業の5本。
- 探した範囲は16人の2026-07-25以降の記事と、メモにあった2〜3月の数本だけで、日本語の記事全体を網羅してはいない。
- 本文は X API の article.plain_text で全文が取れる。見出し・太字・画像の位置は API では取れないので、ダンのブラウザで記事ページを開いて取り出した。空行は記事の中の空の段落をそのまま残した（Xの記事は段落の間に最初から余白があるので、空行は「さらに間をあけた所」）。
- 動画は再生しておらず、サムネイル（最初の1コマ）だけを見て説明を書いた。
- 費用: X API の照会は計約265件（1件 $0.005）で約 $1.3（約200円）。
