## 共通の設定

書き方の技は作業ごとの資料にある。ここには、どの作業でも守る本人の好みとアカウントの事実だけを書く。

- **実績・数字は言い切る。** 「〜と考えています」「把握している範囲で」「一部です」「※」を付けない。期間や数え方の条件は、証拠の画像の説明文に書く（記事は article-writing.md の技7）。
- **言い方は強くしてよいが、事実は材料から。** 数字は読みやすく丸めてよい（973人→約1,000人）。材料に無い出来事・数字・「AだからBになった」は書かず、足りない時は【要確認：〜】と残す（2026-10-14 本人「時には多少盛ってでも言い切って、その発言に責任を取る。嘘は一つもない」。盛るのは言い方と数字の丸めまで）。
- **主張・実績の直後に、それを証明する画像かURLを置く**（本人「言葉より先にもってこい」）。
- 一人称は「僕」。話し言葉を混ぜてよい（「めちゃニッチ」「〜してます」）。
- **素材は私が取りに行く。** 画像・スクショ・動画のURLは、本人に送ってもらう前に自分で探して撮る。見つからない時だけ、何をどこまで探したかを添えて聞く。ふくろうPの記事なら、動画のサムネ・再生数のスクショ・特典動画・LINEの増加グラフを、本人のYouTube（0aw325171@gmail.com のアカウントの YouTube Studio。限定公開の動画もここ）、固定投稿の画像、LINE公式の分析画面から取る。
- 日本語は SOUL.md の「日本語の書き方」に従う。

### 記事を投稿したら LINE グループに知らせる（ふくろうP）

ふくろうP（@FukurouKantoku）の記事がXに出たら、毎回 LINE グループ「【辛口注意】記事タイトルアドバイス」に次の文面を送る。文面は固定で、本人が送ってよいと決めている（2026-10-18）。毎回の承認カードは出さない。引用・通常投稿の時は送らない。

```
お世話になります
記事作成しました
よろしくお願いいたします
[記事URL]
```

`[記事URL]` は投稿した記事の x.com のURL（運用室の行の「公開した投稿を開く」と同じ）に置き換える。

送り方（道具は `scripts/line_group_post.py`。LINE の窓は別の仮想デスクトップにあり、`desktop` の窓の一覧にも部品の文字にも出ないので、この道具で動かす。各段で写しを保存するので、次の段の前に必ず Read で見る）:
1. `compose_message`（action=propose・channel=line・to=「【辛口注意】記事タイトルアドバイス」・approved=true・body=文面）で記録し、続けて action=send で本文を受け取る。本文をファイルに保存する。
2. `python line_group_post.py open --query 記事タイトルアドバイス` → 写しの上の名前が「【辛口注意】記事タイトルアドバイス」か見る。違えば restore して止める。
3. `python line_group_post.py paste --file <本文のファイル>` → 写しの入力欄に4行がそのまま入っているか見る。違えば clear して止める。
4. `python line_group_post.py send` → 写しの最後のメッセージが文面どおりか見る。
5. `python line_group_post.py restore` で窓を元の仮想デスクトップに戻し、`compose_message`（action=mark_sent）で確定する。送れなかった時は action=release で戻し、本人に知らせる。

文字はキーで打たずに貼る（打つと日本語入力が割り込み、カタカナがひらがなになる。入力欄では Enter で送られる）。2026-10-18 に 2・3 と入力欄を空にして戻す所までは確かめた。4 の送信は本番の1回目が初めてなので、その時の写しは特に見る。
