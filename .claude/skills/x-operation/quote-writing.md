# 引用を書く・直す

引用（他の人の記事・ポストへの引用と、本人が自分の記事を後から引用するセルフ引用）を書く時に読む。

## 前提

引用は、タイムラインで止まってもらい、下に付いた引用元の札をタップしてもらうためのポスト。読む人は引用文と添付を一瞬見て、自分に関係があり、続きが記事にあると分かった時だけタップする。だから引用文は「誰向けか」と「何が分かるか」を見せ、答えは記事に残す。

伸びやすさは「通常ポスト < 引用 < 記事への引用 < 記事への動画付き引用」（X顧問 Notion 第6章、メモ `D:\dan-workspace\x_komon_videos\notes_roadmap_ch6_quote.md`）。実例 [examples/quotes/index.md](examples/quotes/index.md) でも、上位3本はすべて動画付きだった。

## 技

### 1. 記事の中身が実際に動いている場面を、動画で添える
- 何を：引用する記事のテーマが実際に動いている場面（人が作業している・道具が画面を操作している・数字が増えていく・話し手が要点を話している）を1つ。
- どこに：引用ポストの添付に1本。
- どういう形で：30秒〜3分の動画。素材は記事で使った動画、記事が扱った元動画の切り出し（`scripts/clip_scene.py`）、道具を動かした画面の録画から選ぶ。記事の章番号や見出しが画面に入っていれば、記事のどこの場面かも伝わる。動画にできる場面が無い時だけ、数字か結果が一目で分かる静止画を1枚にする（文字の説明だけの図や、表紙の使い回しにはしない）。
- なぜ効くか：動いている物はタイムラインで目が止まり、本物が動いているのを見た人は、そのやり方が書いてある記事を開きたくなる。
- 良い例：作り置きの記事を引用して、日曜に1週間分を作り終える場面を早送りした1分の動画を付ける。
- 悪い例：同じ記事を引用して、完成した料理の写真を1枚だけ付ける。
- 出どころ：examples/quotes/index.md #1〜#3（動画30秒〜約3分）と #7・#8（画像1枚で伸びていない）

### 2. 本文は、添付の場面への反応か、見ると何が分かるかを1〜3行
- 何を：添付の場面を見た書き手の反応（驚き・感想）か、その場面・記事を見ると読む人に何が分かるか。
- どこに：引用文の全部。
- どういう形で：1〜3行。記事の結論・手順・答えの数字に当たる語は書かない（書いたら消す）。記事の中で作られた言葉（造語・章の名前）は、記事を読んでいない人にも通じる言い方に置き換える。他人の記事なら、誰向けか（読む人の今の状況）と、引用するアカウント自身の立場からの一言を入れる。
- なぜ効くか：自分に関係がある問いの答えが伏せてあると、確かめるために札をタップする。答えまで書くと、タップする理由がなくなる。
- 良い例：「日曜の40分でこれ全部できるの、自分でもまだ驚く」（作り置きの記事に、作っている場面の動画を付けて）
- 悪い例：「主菜3品・副菜4品を日曜にまとめて作るのがコツです」（答えを書いている）
- 出どころ：examples/quotes/index.md #1〜#3、本人の指摘 2026-10-15（sources/generalization-log.md）

## 試してよいこと（実例2本ずつ・保留）

- セルフ引用の1本目は、記事の当日か翌日に出す。
- 1本目が伸びたら、同じ記事の別の場面の動画で2本目を出す。同じ動画・同じ文は繰り返さない。

（examples/quotes/index.md #1・#2、#3・#5。結果が分かったら技に上げるか消す）

## 確認表（書き終えた引用で目で確かめる）

- [ ] 添付があり、記事の中身が動いている場面の動画か、数字・結果が一目で分かる画像になっている
- [ ] 引用文が1〜3行で、記事の結論・手順・答えの数字が書かれていない
- [ ] 記事の中でしか通じない言葉が残っていない
- [ ] 主張や数字を書いたなら、添付か引用元でそれが確かめられる（SKILL.md の共通の設定）
- [ ] 煽り語・絵文字の連打がない。一人称は「僕」

## 運用室での形

- 引用の原稿は運用室の「引用候補を追加」で作る。添付の動画・画像は attach_image で保存し、本文の最後に `![説明](/api/v1/files/〜.mp4)` の1行で置く（運用室はその行を動画・画像として表示する）。Xに出す時はその行を添付にして、文からは外す。
- 引用はAPIで送れない（Enterprise 契約が要る）ので、ダンのブラウザで x.com のそのアカウントから「引用」で出す。出した後は運用室の「投稿したので記録する」で、Xの投稿をその原稿に結びつける。
- Xへの送信は本人の承認の後だけ（SKILL.md の送信の項）。
