# 汎化の手順

腕のスキル（記事・台本・LP・デザイン・判断など）を作る・直す時に読む。1つの案件で得た指摘や実例を、別の案件でもそのまま手を動かせる技に変える手順。

材料は2種類あり、扱いが違う。

- **本人の指摘・修正**: 私がどこでずれるかが分かる。→ A
- **合格した実例**: うまくいく技が入っている。→ B

どちらも最後は C の具体度に合わせ、D の型で書く。

## A. 指摘を汎化する

指摘1つを、次の5段に書き直す。

1. **具体の指摘**: 本人が言ったこと、直したこと。
2. **受け手に起きていなかったこと**: 指摘の前の版で、読む人・見る人に何が起きず、何をされたか（読み飛ばされた、離脱された、信じてもらえなかった、など）。
3. **一般則**: 2が起きないようにするための原則と、なぜ効くか。
4. **技**: 3を実行する手の動かし方。C の「ちょうどいい」具体度で書く。
5. **別テーマでの例**: 材料と違うテーマで、4を使った1例。ここで例が作れなければ、4がまだ写しのままなので書き直す。

**例1（X記事）**

1. 「無料プレゼントのサムネ画像置いて」
2. 特典がどんな物か言葉でしか分からないので、価値を判断できず読み飛ばされる。
3. 主張や紹介をするたびに、受け手が自分の目で確かめられる物を出す。見て確かめた物は信じられ、信じた物は次も読まれる。
4. 主張・実績・特典を書いたら、その直後に、それを証明する画面を1枚置く。数字か中身が写っている画面を選ぶ。
5. ダイエットの記事なら、「3か月で8kg落ちた」の直後に体重記録アプリの推移の画面を置く。

**例2（話す動画の台本）**

1. 「冒頭の自己紹介いらない」
2. 視聴者は最初の数秒で自分に関係ある話かを判断する。自己紹介ではそれが判断できないので、離脱される。
3. 冒頭は、受け手が「自分の話だ」と判断できる情報から始める。
4. 最初の1文に、受け手の今の状況か、見終わった時に得られる結果を入れる。話し手の紹介は、その後に実績として1文で入れる。
5. X記事なら、1行目に「何の誰の話か」と実績の数字を置き、経歴は後ろに回す。

**まとめ方**

- 複数の指摘が同じ「受け手に起きていなかったこと」に当たるなら、1つの技にまとめる。元の指摘は、その技の出どころとして下に付ける。
- 汎化しないものもある。本人の好み（一人称、使わない言葉）と、案件の事実（URL、商品名、合格ラインの数字）は技ではない。スキルの「設定」の項に、事実としてそのまま書く。

## B. 合格した実例から技を取り出す

1. 実例を区切り（段落・場面・画面の1ブロック）ごとに読む。各区切りについて、「受け手がここで次へ進む理由」を1行で書く。次へ進むとは、読み続ける、保存する、タップする、などのこと。理由が書けない区切りは、技がない所として飛ばす。
2. 理由を書いた区切りについて、具体的に何をしているかを「何を・どこに・どういう形で」で書く。
3. 実例を横に並べる。2本以上で同じ働きをしているものを技の候補にする。1本だけのものは「1本だけ」と書いて保留にする。
4. 合格しなかった物（本人の過去作や私の下書き）があれば比べる。合格した物にだけある技を優先する。
5. A の結果と突き合わせる。私がずれやすい所に当たる技は、確認表に入れる。

数字で合格を決めた実例は、数字（表示・保存・反応率など）と一緒に examples に残す。技の出どころとして、どの実例から来たかを書けるようにするため。

## C. ちょうどいい具体度

| 具体度 | 例 | 問題 |
|---|---|---|
| 具体すぎ（写し） | 無料プレゼントのサムネを置く | その案件でしか使えない |
| 抽象すぎ（目標） | 読む人の時間をもらう | 何をすればいいか分からない |
| ちょうどいい（技） | 主張の直後に、それを証明する画面を1枚置く。数字か中身が写った画面を選ぶ | 別のテーマでもそのまま手を動かせて、できたかを目で確かめられる |

書いた技ごとに、次の3つを確かめる。

- 別のテーマを1つ決めて、この技だけを読んで手を動かせるか。
- 出来上がった物を見て、この技を使ったか使っていないかを判定できるか。
- 良い例と悪い例が、同じテーマで並んでいるか。違いが技の部分だけになっているか。

目標（抽象すぎ）は、スキルの前提として数行書くのは構わない。その場合も、目標の下に、それを実現する技を必ず並べる。

## D. 技の書き方の型

```
### 〈技の名前：やることを短く〉
- 何を：
- どこに：
- どういう形で：
- なぜ効くか：受け手に起きること（1文）
- 良い例：
- 悪い例：（良い例と同じテーマで）
- 出どころ：実例ファイル名、指摘の日付
```
