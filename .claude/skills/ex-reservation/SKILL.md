# EX予約（新幹線）Skill

## サービス概要
SmartEX/エクスプレス予約で新幹線を検索・予約するサービス。
JR東海・JR西日本の東海道・山陽新幹線に対応。

## アクションファースト原則

**重要**: このスキルは「アクションファースト原則」に従う。

- 「どれがいいですか？」と複数候補を提示して選ばせない
- 「これを予約します」と1つの具体的な提案をする
- ユーザーは白紙から選ぶより、具体的な提案に対して訂正する方が楽

**フロー例**:
```
ユーザー: 明日19時頃東京から新大阪の新幹線を予約して

ダン: [search実行 → 確認画面まで進む]
      のぞみ263号 19:00発 → 21:29着
      普通車指定席 3号車12A（窓側）
      ￥13,870

      これを予約します。よろしいですか？

ユーザー: 通路側がいい

ダン: [再検索 → 通路側で確認画面まで進む]
      のぞみ263号 19:00発 → 21:29着
      普通車指定席 3号車12C（通路側）
      ￥13,870

      通路側に変更しました。これでよろしいですか？
```

## ツールの使い方

スキル名: `ex-reservation`

### 利用可能なアクション

| アクション | 説明 |
|-----------|------|
| `search` | 新幹線を検索し、確認画面まで進んで1つの提案を返す |
| `cancel` | 予約をキャンセル（払戻） |

**注意**:
- `login`アクションは存在しない。ログインは`search`の中で自動的に行われる
- `execute`（購入）は安全のため無効化。SmartEXサイトで手動購入
- 認証情報はシステムがDBから自動取得する。ユーザーに聞かない

### search（検索→提案）の呼び出し方

```
[TOOL: ex-reservation search]
departure: 東京
arrival: 新大阪
date: 2026-01-20
time: 19:00
seat_position: 通路側
```

パラメータ:
- `departure`: 出発駅（必須）
- `arrival`: 到着駅（必須）
- `date`: 乗車日 YYYY-MM-DD または "tomorrow"（必須）
- `time`: 希望時刻 HH:MM（任意、指定なしなら直近の列車）
- `seat_position`: 座席位置（任意）
  - "窓側" / "window" → 窓側A席
  - "通路側" / "aisle" → 通路側C席
  - "指定なし" / "any" → おまかせ（デフォルト）
- `product_type`: 座席タイプ（任意）
  - "regular" → 普通車指定席（デフォルト）
  - "green" → グリーン車

**返却値**: 1つの具体的な提案
- 列車名、時刻、座席番号、価格
- 確認画面のスクリーンショット

### cancel（キャンセル）の呼び出し方

```
[TOOL: ex-reservation cancel]
departure_date: 2026-02-10
train_name: のぞみ37号
```

または予約番号を直接指定：
```
[TOOL: ex-reservation cancel]
reservation_id: 12345678
```

パラメータ:
- `reservation_id`: 予約番号（任意 - 指定なしなら自動検出）
- `departure_date`: 出発日（任意 - 複数予約がある場合のマッチング用）
- `train_name`: 列車名（任意 - 複数予約がある場合のマッチング用）
- `confirm`: 実際にキャンセルを実行するか（デフォルト: true）

**自動検出ロジック**:
- 予約番号を指定しない場合、予約一覧を確認
- 予約が1件のみ → 自動選択
- 予約が複数 + 文脈情報（日付・列車名）あり → マッチして選択
- 予約が複数 + マッチなし → 一覧を表示してユーザーに確認

## できること
- 新幹線の検索→座席確認→1つの提案
- 予約キャンセル（払戻）

## できないこと（安全のため）
- 購入の自動実行（確認画面で停止、手動購入を案内）

## 必要な情報

### ユーザーに確認すること（最小限）
- 出発駅・到着駅
- 乗車日
- 希望時刻（大体でOK）

### ユーザーに確認しないこと
- 認証情報（自動取得）
- 細かい座席指定（まず提案してから訂正を受ける）

## 認証フロー

### ログイン
自動実行。OTP認証もSMS Forwarder→Gmail経由で自動取得。

### 認証情報
システムがDBから自動取得。未登録の場合のみシステムが確認。

## ユーザーへの応答例

### 検索成功時
```
のぞみ263号 19:00発 → 21:29着を予約します。
- 東京 → 新大阪
- 普通車指定席 3号車12C（通路側）
- ￥13,870

確認画面に到達しました。
購入する場合はSmartEXサイトで「予約する（購入）」を押してください。
変更が必要な場合はお知らせください。
```

### 訂正を受けた時
```
了解しました。窓側に変更して再検索します。
```

## エラーハンドリング
- 「満席」→ 別の時間帯で再検索
- 「ログイン失敗」→ セッション切れの可能性、再試行
- 「OTPタイムアウト」→ SMS Forwarder設定確認を案内

## 注意事項
- 予約は乗車日の1ヶ月前から可能
- キャンセル料は乗車日2日前から発生
- 購入は手動で行う（安全のため自動実行しない）
