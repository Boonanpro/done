# 編集ポリシー（カット・テロップ・間・実操作）— UGC/操作デモ動画

このポリシーは制作タブ(dan_edit)の編集時に必ず読み込まれる。チャットでの編集にも適用してよい。
「合格点」の基準は、人間の編集者が手で詰めた時の自然さ。短さやメトリクス(clean=true)ではない。

## 1. カット原則 — 切るのは「言い直し」だけ

- **切ってよいのは言い直し（同じ内容を二度言い直した、前の不採用テイク）のみ。** 採用テイク(後の言い直し)を残し、前のテイクを落とす。
- **フィラー（えー / あの / えっと）は切らない。** 自然な喋りはそのまま。指示が「言い直しのみカット」なら、それ以外は触らない。
- **文の途中・語尾を絶対に切らない。** 各発話は文末（助詞・句点）まで含め、最後の音が鳴り終わってから **0.3〜0.5秒のブレス（余韻）** を残してからカットする。語尾が食われて「最後が聞こえない」状態は不合格。
- **カット点は無音/単語境界ではなく「文の境界」に置く。** 単語タイムスタンプで文末語の終了時刻を取り、そこ＋ブレス分を out 点にする。
- **「短くする」を目的化しない。** 尺が伸びても、必要な内容・実操作は全部残す。**疑わしい時は残す。**

## 2. 実操作（画面録画）— 頭から最後まで一連を見せる

- 操作デモは **アプリ起動（ホーム/アプリを開く）から完了まで、一連の流れを頭ごと全部** 見せる。途中から始めない。「アプリを開く→トップ→写真選択→AI解析→自動入力→投稿→完了→結果」のような手順を飛ばさない。
- **組む前に、画面録画のコンタクトシートを作って中身を地図化する**：等間隔(例:5〜10秒間隔)でフレーム抽出→1枚のタイル画像に montage → Read で確認し、「何秒で何の操作画面か」を把握してから構成する。これを省くと必要な操作を取りこぼす。
- ナレーションに合わせて、対応する実操作をノーカットで見せる（操作シーンは無言の間があってもよい）。

## 3. 間（無音）の詰め方

- **詰めるのは「話者(トーキングヘッド)が喋る区間どうしの間の無音」だけ。** 発話内部の自然な抑揚・呼吸は触らない。
- **操作デモ区間（実操作を見せている間）の無音は詰めない。** ナレーションが止まって操作を見せる時間は意図的に残す。音声チェックの dead_air がこの区間を指していても、それは正常。
- 話者区間どうしの間の不自然な沈黙は、自然な間（およそ 0.3秒前後）まで圧縮する。ゼロにはしない。1秒を超える話者間の沈黙は特に詰める。
- 無音を詰めるためにクリップを分割・連結する時は、**タイムスタンプの不連続で位置がずれないよう、連結結果を再エンコードして時間軸を連続させる**（concat の copy ではなく re-encode）。

## 4. テロップ（字幕）— 具体レシピ（必ずこの設定で焼く）

「黒い箱をやめてフチ＋影」はポリシー文だけでは伝わらない（デフォルトの箱で焼いてしまう）。必ず以下の具体設定で描画すること。

- **ASS字幕を使い、不透明箱を禁止する。** ASS の Style 行で `BorderStyle=1`（縁取り＋影）を使う。`BorderStyle=3`（不透明箱）は禁止。`drawbox` や半透明帯をテロップ背景に敷くのも禁止。
- 推奨 Style（白文字＋黒フチ＋影＝箱が消える）:
  `Style: Default,<FontName>,<FontSize>,&H00FFFFFF,&H000000FF,&H00000000,&H64000000,1,0,0,0,100,100,0,0,1,3,1.5,2,40,40,<MarginV>,1`
  （要点: 末尾付近の `BorderStyle=1`, `Outline=3`, `Shadow=1.5`、`Bold=1`、`PrimaryColour=&H00FFFFFF` 白、`OutlineColour=&H00000000` 黒フチ）
- **フォント**は端末にある日本語対応フォントを `FontName` で明示する（例: `Yu Gothic UI` / `Meiryo` / `MS Gothic`）。焼いた後フレーム抽出で豆腐文字(□)が出ていないか必ず確認する。
- **絵文字は字幕に入れない。** これらのフォントは絵文字を描けず □ になる。テロップ文言から絵文字・特殊記号は除去する（書き起こしや brief に絵文字があっても字幕には入れない）。
- 位置は下寄せで左右に余白（`MarginV` は画面高の ~12〜18%）。
- **小窓(PiP)＋背景動画（実操作）のパートはテロップ無し。** 操作画面を全面で見せる。テロップは話者(トーキングヘッド)パートにのみ置く。
- 焼いた後、必ずフレーム抽出で「**背景の箱が無い・フチと影が出ている・豆腐文字が無い**」の3点を目視確認する。出ていたら直して焼き直す。

## 5. 完成後の自己確認（メトリクスを鵜呑みにしない）

`clean=true` は床上げの目安であって合格ではない。完成動画について以下を必ず確認：

- **語尾切れが無いか**：各発話の最後の語が途中で切れていないか（カットが文末の手前で落ちていないか）。
- **必要な内容・実操作が残っているか**：アプリ起動など手順の頭が飛んでいないか。
- **言い直しの取りこぼしが無いか**：同じ文言の重複が残っていないか。
- **間が自然か**：詰めすぎ（語尾食い）でも、放置（不自然な沈黙）でもないか。
- **テロップ仕様**：黒箱でない／フチ＋影／豆腐文字なし／PiPパートはテロップ無し。

不合格項目があれば、該当箇所だけを直して再レンダする。
