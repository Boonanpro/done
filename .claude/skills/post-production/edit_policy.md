# 収録・操作デモの編集判断

ユーザーの今回の目的・指示・合意した表現を優先する。以下は判断の観点であり、作品の形式を固定するレシピではない。

- カット前に、対象部分の内容と前後のつながりを把握する。広い範囲を再構成する場合は全体の内容も確認する。既存の文字起こし・分析は再利用する。
- 言い直し・フィラー・沈黙を残すかは、本人の指示、伝わる内容、自然さ、尺で判断する。発話を切る際は実際の音と境界を確認し、意図せず語尾や必要な説明を落とさない。固定の余韻秒数を全カットへ適用しない。
- 操作デモは視聴者が必要な操作と結果を理解できる構成にする。アプリ起動からすべて見せる必要があるか、途中を省略できるかは目的による。
- 字幕の有無、背景、縁取り、位置、書体、ワイプの有無は作品ごとに選ぶ。元の合意や参考があるなら引き継ぐ。画面上の重要情報との重なりと文字の表示を確認する。
- ダンのエディターでは、元素材の範囲参照と編集可能な字幕・領域クリップを用いる。字幕焼き込みやカット済み中間動画を作ることを編集の必須工程にしない。保存・検証・書き出しの仕様は editor_help(topic='saving') を参照する。
- 変更区間の音・動き・見た目と前後のつながりを確認する。作品全体を作ったり再構成した場合は通しで確認する。検査値だけで品質の合否を決めない。
