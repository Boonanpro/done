# スマホを操作する

スマホの操作で時間を失うのは、ほとんどが「画面を見ずに押す」「違う端末を触る」「本人に何度も手を出させる」の3つだった。この3つを避ける順番で進める。

## 最初に決めること: どの端末か

| 端末 | 使い道 | 見分け |
|---|---|---|
| 本人の Galaxy S25 | 本人の日常・録音（ライフログ）・ポルノブロッカー本番 | serial `RFCY205CPNM`（無線は `adb-RFCY205CPNM-…`） |
| 開発用 Galaxy S24 | ダンの試験・LINE（サブ端末）・X（@PornoAnti_JP）・録画 | serial `RFCXB0MSSTD`、Mac mini に USB 常時接続 |
| エミュレーター | 壊してよい画面試験 | `emulator-5554` は別作業用で触らない。試験は `nsfwtest`（-read-only） |
| 借りた iPhone | iPhone 版の実機試験・設定画面の撮影 | `xcrun devicectl list devices` で UDID を確認 |

- S25 と S24 を取り違えない（10/30 に録音停止の原因を S24 のせいにして誤った）。結論を言う前に serial で確かめる。
- adb は常に `-s <serial>` を付ける。エミュレーターが同時につながっていることがある。
- S24 は他の部屋も LINE 等で使う。指を送る前に今の画面を読み、別の作業の画面なら触らない。

## どの端末でも守ること

1. **画面を見ながら1手ずつ押す。** 押したら、押した後の画面を読んでから次を決める。押す順番を先に全部書いて流す形にはしない。ログイン・設定・ダイアログは、次に何が出るか決め打ちできない。
2. **本人の手は1回にまとめて頼む。** ケーブルの挿し直し、確認コードの入れ直し、何度もの往復を本人は嫌う。自分で直せる道（保存済みの認証、無線の再接続、設定の切替）を先に使い、どうしても要る物だけを一覧にして1回で頼む。
3. **変える前に元の値を控える。** 特に借りた端末と S24 の本人好みの設定（画面消灯10分・おやすみモード等）。試験が終わったら戻す。
4. **ログインは1画面ずつ判断する。** 初めての端末では、サービスがパスワードの前に確認コードを求めることが多い（X はメールのコード）。コードは `lookup` で受信箱から読んで入れる。保存済みの認証情報は画面やログに出さない。
5. **確定操作は承認がある時だけ。** 購入・送信・削除・確定は本人がその操作を承認した時だけ押す。自動審査に拒否された操作（「blocked by policy」等）は別の経路で回り込まず、本人に頼む。
6. **固まったら止めて画面を見る。** 待ちは短く（存在確認は数秒）、同じ操作を長く待ち続けない。

## 借りた端末

持ち主のデータの消去と、元に戻せない変更はしない。触る前にアプリ一覧と変える設定の元の値を控え、返す前に次を1つの一覧で済ませる。

- ダンが入れたアプリを全部消し、消えたことを端末の一覧で確かめる。
- ダンが変えた設定を元の値に戻す。
- 本人の手が要る戻し（iPhone のデベロッパモードのオフ、自動ロックの時間など）を、控えた元の値と一緒に1回で渡す。
- 持ち主の履歴が残る操作（Safari で特定サイトを開く等）はしない。撮影で要るなら本人の端末で撮る。
