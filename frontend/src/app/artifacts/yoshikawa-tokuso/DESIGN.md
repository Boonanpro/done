## レイアウト方針

- **ヒーロー**: 大きな特装車の作業写真（AI生成）上に深い青のグラデーション。ロゴバッジ＋「新明和工業 認定修理工場」の認定プレート＋見出し＋電話番号大表示＋CTA
- **セクションリズム**: 白ベース→ネイビー帯→白→薄グレー→白 の交互で緊張感を出す
- **グリッド**: 均等配置ばかりにせず、見出しと本文を非対称に（左寄せ大見出し＋右寄せ説明）
- **アイコン**: Lucide React（Truck, Wrench, Phone, Clock, MapPin, Award, Zap等）
- **角丸**: `--radius: 0.375rem`（シャープ寄り、業務感）
- **アニメーション**: ヒーローのスクロール誘導と、ボタンhover時の微細な浮き上がりのみ

## 必須セクション

### ホーム (`/demo/yoshikawa-tokuso`)

1. **ヒーロー** — 作業写真 + ロゴ + 「新明和工業 認定修理工場」バッジ + H1 + 電話番号 + CTA
2. **数字の強さ** — 創業年数・対応車種数・対応エリア・累計整備台数（プレースホルダ）
3. **対応車種グリッド（9種）** — テールゲートリフタ / ダンプ / 塵芥車 / CBクレーン / ローリ車 / 高所作業車 / ミキサ / 飼料運搬車 / 脱着車
4. **問い合わせフロー図（3ステップ）** — 車両情報準備 → フォーム送信 → 折り返し
5. **3つの強み** — 新明和認定 / 特装車全機種 / 山陰最短対応
6. **取扱メーカー** — 新明和主役、他はプレースホルダ
7. **会社情報 + アクセス** — 地図埋め込み
8. **採用CTA**
9. **フッター** — 住所・電話・フォームリンク

### 事業・サービス (`/services`)

- 車種別の対応内容（整備・修理・架装・点検・検査）
- 保有設備（プレースホルダ）
- 対応エリア地図

### 問い合わせ (`/contact`) ※本サイトの核

- 冒頭に「なぜこの情報が必要か」の説明ブロック
- マルチステップ:
  1. 連絡先（会社名・担当者・電話・メール）
  2. 車両情報（車検証写真アップロード＋車台番号・型式・類別区分番号・登録年・架装メーカー・架装型式）
  3. 不具合内容（部位・症状・画像/動画添付）
  4. 希望納期・連絡方法
- 送信後に受付番号表示

### 会社情報 (`/company`)

- 代表挨拶（プレースホルダ）
- 会社概要（法人番号・設立・代表者・所在地・電話・事業内容）
- 沿革（プレースホルダ）
- アクセス

### 採用 (`/careers`)

- 募集職種（整備士・整備見習い・事務）
- 仕事の魅力
- 給与・福利厚生（プレースホルダ）
- 応募フォーム

## プレースホルダー方針

吉川特装のWebサイトが現存しないため、Web上で公開されていない情報は **「後日差し替え」前提のプレースホルダ** として明記する。

| 項目 | 扱い |
|---|---|
| 法人番号 / 所在地 / 設立日 / 代表者 / 電話 | Gビズインフォの公開情報で確定 |
| 代表挨拶文 | プレースホルダ（代表者からの写真＋100字程度） |
| 沿革 | プレースホルダ（1988年設立→現在の流れを想像で書かない） |
| スタッフ写真 | AI生成 or ストック（後で本人写真に差し替え） |
| 実績事例 | プレースホルダ（「車種 × 症状 × 納期」形式で3件） |
| 採用給与 | プレースホルダ（「ご相談ください」） |
| 取扱メーカー | 新明和は確定、他（極東開発工業・東邦車輛・アイチコーポレーション）はプレースホルダ |

## 既存テンプレの使用

- `<LpShell>` でナビ＋フッター
- `<HeroSection>` split で写真＋文字
- `<Section>` でセクション統一
- `<FeatureGrid>` で対応車種・強み
- `<LocationMap>` で地図埋め込み
