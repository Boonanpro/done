## 1. ビジネスゴールからデザインへの因果連鎖

| ステップ | 内容 |
|---|---|
| ① ゴール | 「暖房は効いているのに足だけ寒い」在宅ワーカーが実在するかを獲得単価で測る |
| ② 行動 | 先行登録（メール）＋出せる金額の選択 |
| ③ 確信 | (a)本当に足が暖まるのか (b)電気代が跳ねないか (c)火事・低温やけどが怖くないか (d)デスク下に置いて邪魔にならないか (e)エアコンの置き換えなのか |
| ④ コンテンツ | 床上10cmと頭の高さの温度差、150W＝1時間4.7円、45℃を超えない設計と転倒自動OFF、3通りの置き方の寸法、そして「部屋は暖まりません」という否定 |
| ⑤ デザイン | 主役は「0（音・風・乾燥）」と「小さい数字（150W・4.7円）」。前作と違い、大きさではなく“小ささ”で信用させる |

**この製品は「エアコンの代わり」ではない。** そこを曖昧にすると登録後の失望で数字が濁る。
LPの中で明確に否定し、「足元だけを解決する道具」として売る。
否定を入れたほうがドライテストの精度が上がる（登録者の期待値が揃う）。

## 2. 置く床暖房LP（`artifacts/oku-yukadanbou`）との関係

同じブランド世界の第2弾として作る。**踏襲するもの**と**必ず変えるもの**を分ける。

### 踏襲する（トーンの共通言語）

- 明るい地（生成り〜白）。暖房商品を暗い画面で見せると「冷たい・安い」に振れる
- Zen Old Mincho の見出し／Barlow Condensed の数値／Noto Sans JP の本文
- アクセント（熾火色）は CTA と温度・電力の数字だけ。面積を絞るほど温度が上がって見える
- ページ内で1か所だけ暗い全幅帯を作り、そこに一番言いたい安全の話を置く
- 角丸は 0.25rem まで。赤字の煽り・吹き出し・◯×表は使わない

### 必ず変える（構造の反復を避ける）

| | 置く床暖房 | 足元パネルヒーター |
|---|---|---|
| ヒーロー | 左コピー／右写真の非対称スプリット | センター寄せのコピー＋その下に全幅の写真帯 |
| 主要ダイアグラム | 部屋の**平面図**（敷設率80%） | 床から頭までの**垂直の温度スケール** |
| 数字の見せ方 | 大きい数字で強さを示す（28℃/1000W） | 小さい数字と 0 の反復で軽さを示す（150W/0dB） |
| 地の色 | 生成り（紙） | わずかに白へ寄せた朝の机上 |

## 3. 配色（4層モデル）

在宅ワークの朝の机。**冷えた白い床と、足元だけの熾火。**

| 層 | 役割 | 値 |
|---|---|---|
| Neutral（88%） | 背景 | `--background` oklch(0.976 0.005 92) / `--card` 白 |
| Primary | 本文 | `--foreground` 炭 oklch(0.215 0.012 55) |
| Secondary | 補助・罫線 | `--muted-foreground` oklch(0.505 0.014 62) / `--border` oklch(0.892 0.008 84) |
| Accent（最小面積） | CTA・電力/温度の数字のみ | `--primary` 熾火 oklch(0.565 0.168 41) |

補助色として「冷え」を示す青 `--ah-cold` oklch(0.52 0.085 245) を、温度スケールの寒い側にだけ使う。
青は必ず熾火と対で出す。単独で使うと家電量販店の「冷暖」ピクトグラムに寄る。

| # | セクション | レイアウト |

## 6. 数字の根拠（LPに書く数値はすべてここから引く）

| 数値 | 根拠 |
|---|---|
| 150W | 設計目標。遠赤外線パネル。 |
| エアコンの約1/7 | 10畳用エアコンの暖房時**定格**消費電力 約1,000W に対して150W。「定格どうしの比較」とLP側に明記する |
| 1時間 約4.7円 | 0.15kWh × 31円/kWh（公取協の目安単価）＝ 4.65円 |
| 月およそ740円 | 1日8時間 × 平日20日 ＝ 24kWh × 31円 ＝ 744円 |
| 表面 45℃ | 面積からの逆算。ΔT=25K、複合熱伝達率 約10W/m²K で 150W を捨てるには約0.6m²。両面放熱で前面0.3m²＝幅65×高さ45cm と整合する |

## 7. 計測

| 項目 | 値 |

| 主要指標 | 先行登録のCPA |

1件あたりの粗利は約3,400円。登録→購入の転換を10%と置くと、登録1件の価値は約340円。よって300円を基準にする。

## 8. 表示してはいけないこと（景品表示法）

- 「エアコンがいらなくなる」「部屋が暖まる」→ 事実に反する。LP本文で明確に否定する
- 「電気代が安くなる」→ 追加でかかる。エアコンの設定温度を下げられる可能性がある、までしか書かない
- エアコンとの電気代比較を、実使用の実測値であるかのように書かない。**定格どうしの比較**と明記する
- 「PSE取得済」→ 未取得。書かない
- 「低温やけどしません」→ 断定しない。素肌を長時間当て続けないよう注意書きを置く
- 価格・発売時期は「予定」と明記する
